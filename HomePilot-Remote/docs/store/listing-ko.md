# Google Play 등록 정보 (한국어)

## 앱 이름 (30자 이내)
HomePilot - 집 PC 원격 조종

## 간단한 설명 (80자 이내)
집 PC 를 휴대폰으로. HD 동영상 원격 화면·파일·소리·AI 작업까지, 가입 없이 무료로.

## 자세한 설명
HomePilot 은 내 휴대폰으로 집이나 사무실 PC 를 조종하는 원격 제어 앱입니다.
회원가입도, 복잡한 공유기 설정도 필요 없습니다. PC 에 HomePilot 을 설치하고 휴대폰에서 PC 를 고르면 끝.

■ 빠르고 선명한 원격 화면
- HD 동영상 전송(H.264): 일반 화면 전송보다 데이터를 1/10 이하로 쓰면서 부드럽게
- 화면이 멈추면 원본 해상도로 다시 그려 작은 글씨까지 또렷하게
- 터치패드·직접 터치, 확대, 스크롤, 한글 키보드, 단축키

■ 게임도 휴대폰으로
- 게임 모드 60fps (Pro): GPU 화면 캡처로 인터넷 너머에서도 초당 50프레임 이상
- 게임 키패드: 조이스틱(WASD/방향키), FPS 시점 패드, 꾹 누르기 버튼, 투명도 조절

■ 주소가 바뀌어도 알아서 연결
- 같은 Wi-Fi 에서는 PC 를 자동으로 찾아 바로 연결
- 밖에서도 PC 가 바뀐 주소를 알려 주어 다시 입력할 필요 없음

■ 파일·클립보드·소리
- PC 폴더 보기, 파일 받기·보내기
- 휴대폰에서 복사한 글을 PC 에 바로 붙여넣기, PC 에서 복사한 글을 휴대폰으로
- PC 에서 나오는 소리 듣기 (Pro)

■ AI 작업 관리 (Pro) — HomePilot 에만 있는 기능
- 휴대폰에서 PC 의 Claude Code·Ollama 에 일을 시키고, 앱을 닫아도 PC 에서 계속 실행
- 끝나면 결과를 휴대폰에서 확인. API 키가 필요 없습니다(PC 에 설치된 도구를 그대로 사용)

■ 철저한 보안
- 휴대폰↔PC 종단간 암호화. 중간 서버도 화면을 볼 수 없습니다
- 새 휴대폰은 PC 화면에서 직접 승인해야 등록, 파일·AI 권한도 따로 승인
- 원격 중에는 PC 화면 위에 표시줄, Ctrl+Alt+F12 로 즉시 차단

■ 가격
- 무료: PC 1대, 원격 화면·조작, HD 동영상, 게임 키패드, 파일·클립보드, 자동 연결
- Pro: 월 1,900원 / 연 14,900원 / 평생 39,000원 — PC 여러 대, 선명 화질, 60fps 게임 모드, PC 소리, AI 작업

PC 프로그램(Windows 10/11): 홈페이지에서 무료로 받을 수 있습니다.
