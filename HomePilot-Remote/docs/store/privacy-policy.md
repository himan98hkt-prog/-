# HomePilot 개인정보처리방침

시행일: 2026-10-13

HomePilot(이하 "앱")은 사용자가 자신의 휴대폰으로 자신의 PC 를 원격 조작하도록 돕는 앱입니다.
앱은 **회원가입이 없으며**, 개발자는 사용자의 화면·입력·파일 내용을 수집하거나 볼 수 없습니다.

## 1. 처리하는 정보와 목적

| 정보 | 어디에 | 목적 | 개발자 서버 전송 |
|---|---|---|---|
| 휴대폰 이름(사용자가 정함), 휴대폰 암호 키 | 휴대폰·사용자의 PC | PC 등록과 본인 확인 | 없음 |
| PC 화면·소리, 마우스·키보드 입력, 클립보드, 파일 | 휴대폰 ↔ 사용자의 PC (종단간 암호화) | 원격 조작 기능 | 없음 |
| AI 작업 요청·결과 | 사용자의 PC 의 AI 도구(Claude Code·Ollama) | AI 작업 기능 | 없음 (Claude Code 사용 시 사용자의 Anthropic 계정 정책을 따름) |
| PC 접속 주소(암호화됨) | 공개 알림 게시판 ntfy.sh | 주소가 바뀌어도 자동 연결 | 개발자 서버 아님. 게시판 운영자는 암호문만 봄 |
| 결제 정보 | Google Play | Pro 구매 | Google 이 처리, 앱은 카드 정보를 보지 않음 |

## 2. 전송 경로와 보안
- 휴대폰과 PC 사이의 모든 데이터는 Noise 프로토콜(X25519·ChaCha20-Poly1305)로 **종단간 암호화**됩니다.
  중간 경로(Cloudflare 터널, 중계)는 암호문만 전달하며 내용을 볼 수 없습니다.
- PC 는 처음 등록할 때 PC 화면의 확인창에서 사용자가 직접 승인해야 하며,
  파일·AI 기능은 각각 PC 에서 따로 승인해야 쓸 수 있습니다.
- PC 에서 언제든 긴급 차단(Ctrl+Alt+F12)·등록 해제할 수 있습니다.

## 3. 보관과 삭제
- 앱 데이터(등록한 PC 목록, 설정, 키)는 휴대폰에만 저장되며 앱을 삭제하면 지워집니다.
- PC 쪽 접속 기록은 사용자의 PC 에만 저장됩니다.

## 4. 제3자 제공
개발자는 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 광고·분석 SDK 를 쓰지 않습니다.

## 5. 아동
13세 미만을 대상으로 하지 않습니다.
