# Play Console "데이터 보안" 양식 답변 초안

코드 기준 (2026-10-13): 권한은 INTERNET 과 결제(BILLING)만. 광고·분석 SDK 없음. 개발자 서버 없음.

| 질문 | 답 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **아니요** | 개발자에게 전송되는 데이터 없음. 화면·입력·파일은 사용자의 휴대폰 ↔ 사용자의 PC 사이에서만 종단간 암호화로 오감 |
| 전송 중 데이터 암호화 | 예 | Noise XX (X25519, ChaCha20-Poly1305), 터널 구간은 TLS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 해당 없음(수집 안 함) / 앱 삭제 시 휴대폰 데이터 삭제 | |
| 결제 | Google Play 가 처리 | in_app_purchase |

주의: ntfy.sh 에 올리는 PC 주소 기록은 PC 공개키로 만든 키로 **암호화**되어 있고 개발자에게 오지 않음.
Google 의 정의상 "기기를 벗어나는 데이터" 로 볼 소지가 있으면 "기기 또는 기타 ID / 기타" 항목을
"수집, 선택 사항 아님, 앱 기능, 암호화됨" 으로 신고하는 것이 안전하다 (출시 전 최종 판단).

## 권한 사용 설명 (심사 질문 대비)
- INTERNET: 사용자의 PC 와 연결
- 접근성 서비스·위치·연락처·카메라·마이크: **사용 안 함**
