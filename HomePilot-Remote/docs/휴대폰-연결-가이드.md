# 휴대폰으로 집 PC 조작하기 — 설치·연결 가이드 (무료 Cloudflare 터널)

필요한 것: 집 Windows PC, Android 휴대폰. 비용: **없음** (공유기 설정 변경도 필요 없음)

```
휴대폰(어디서나) ──인터넷──> Cloudflare ──터널──> 집 PC [HomePilot 에이전트 + 내장 중계]
             └──────────── 종단간 암호화 (Cloudflare 도 내용을 볼 수 없음) ────────────┘
```

## 1단계. 파일 받기
GitHub 저장소 → **Actions → HomePilot Remote → 최신 실행(초록색 체크) → Artifacts**
- `homepilot-windows` → PC 용 (`HomePilot-Agent-Setup-x.y.z.exe`)
- `homepilot-android` → 휴대폰 용 (`HomePilot.apk`)

## 2단계. 집 PC 설정 (처음 한 번)

1. `HomePilot-Agent-Setup-x.y.z.exe` 실행 → 설치
   - "Windows 로그인 시 자동 실행" 에 **체크** (집 밖에서 쓰려면 PC 가 켜질 때 자동으로 떠 있어야 함)
   - SmartScreen 경고가 나오면 [추가 정보] → [실행] (아직 코드 서명 전)
2. **cloudflared 설치** — 시작 메뉴에서 "PowerShell" 을 열고:
   ```powershell
   winget install --id Cloudflare.cloudflared
   ```
   (Cloudflare 공식 프로그램. 계정 가입 불필요)
3. 같은 PowerShell 에서 HomePilot 을 집 PC 단독 구성으로 설정:
   ```powershell
   & "$env:LOCALAPPDATA\Programs\HomePilot Remote\homepilot-agent.exe" setup-home | Out-Host
   ```
4. 트레이(오른쪽 아래)의 HomePilot 아이콘 우클릭 → **종료** 후, 시작 메뉴에서 **HomePilot Remote** 다시 실행
5. 몇 초 뒤 알림에 **휴대폰 연결 주소**(`https://○○○.trycloudflare.com`)가 뜹니다.
   트레이 아이콘 우클릭 → **PC 정보** 에서 주소와 **장치 ID** 를 언제든 다시 볼 수 있습니다.
   (그 창에서 Ctrl+C 를 누르면 내용이 복사됩니다 → 카카오톡 "나에게 보내기" 등으로 휴대폰에 보내면 편함)

## 3단계. 휴대폰 설치
1. `HomePilot.apk` 를 휴대폰으로 옮겨 실행 (카카오톡 나에게 보내기, 구글 드라이브 등)
2. "출처를 알 수 없는 앱" 허용 안내가 나오면 이번 한 번 허용
3. 앱 실행 → **PC 추가**
   - 중계 서버 주소: PC 정보의 `https://○○○.trycloudflare.com`
   - 장치 ID: PC 정보의 20자리
4. **연결하고 등록** → 휴대폰에 6자리 숫자가 표시되고, **PC 화면에 확인창**이 뜹니다
   → 숫자가 같으면 PC 에서 **[예]** (이 단계는 PC 앞에서 해야 합니다)

## 4단계. 사용하기
- PC 목록에서 PC 선택 → 상태(CPU·메모리·GPU·디스크) → **원격 화면 · 조작**
- 조작법 (위쪽 도구 막대)

| 동작 | 방법 |
|---|---|
| 마우스 이동 | 터치패드 모드: 한 손가락으로 문지르기 / 직접 터치 모드: 누른 곳으로 이동 |
| 클릭 | 탭 (빠르게 두 번 = 더블클릭) |
| 우클릭 | 길게 누르기 |
| 드래그 | ✋ 버튼 켠 뒤 한 손가락으로 끌기 |
| 스크롤 | ↕ 버튼 켠 뒤 위아래로 끌기 |
| 확대·축소·화면 이동 | 두 손가락 벌리기/이동 · ⤢ 버튼 = 화면 맞춤 |
| 글자 입력 (한글·영문) | ⌨ 버튼 → 휴대폰 키보드로 입력. 아래 줄에 Enter·Esc·한/영·방향키·Ctrl+C/V 등 |
| 화질·모니터 선택 | 조절 버튼 (모바일 데이터에서는 "절약" 권장) |
| 종료 | ✕ |

- 접속 중에는 PC 화면 위쪽에 **빨간 표시줄**이 뜹니다. PC 앞에서 **Ctrl+Alt+F12** 를 누르면 즉시 끊기고 차단됩니다.

## 꼭 알아 두세요 — 무료 빠른 터널의 한계
- **PC 를 재부팅하거나 HomePilot 을 다시 실행하면 주소(`https://○○○.trycloudflare.com`)가 바뀝니다.**
  그때는 PC 정보의 새 주소로 휴대폰 앱의 PC 를 길게 눌러 → "이름·주소 수정" 하세요. 장치 ID 와 등록은 그대로 유지됩니다.
- 즉, **집 밖에서 PC 가 재부팅되면 새 주소를 알 방법이 없어 연결할 수 없습니다.**
  해결책 (원하시면 진행, 비용 발생 → 승인 필요):
  - 도메인 구입(연 1~2만 원) + Cloudflare "이름 있는 터널" → 주소 고정, 재부팅해도 자동 연결
  - 또는 소형 클라우드 서버(월 5~7천 원)에 중계 서버 운영
- 빠른 터널은 Cloudflare 가 시험용으로 제공하는 기능이라 가동 보장이 없습니다.

## 문제 해결
| 증상 | 확인 |
|---|---|
| 앱: "PC 가 꺼져 있거나 HomePilot 이 실행 중이 아닙니다" | PC 트레이 아이콘이 있는지, 주소가 바뀌지 않았는지 (PC 정보) |
| 앱: "중계 서버에 연결할 수 없습니다" | 주소 오타, 휴대폰 인터넷 연결, PC 의 cloudflared 설치 여부 |
| PC 정보에 "cloudflared 가 설치되어 있지 않습니다" | 2단계 2번 다시 실행 후 HomePilot 재시작 |
| 앱: "등록되지 않은 기기입니다" | PC 트레이 → "새 휴대폰 등록 (5분간 허용)" 누른 뒤 다시 |
| 앱: "PC 에서 원격 제어가 차단되어 있습니다" | PC 트레이 → "원격 제어 다시 허용" |
| 글자가 안 들어감 | 관리자 권한으로 실행된 창이나 UAC 창에는 Windows 정책상 입력할 수 없습니다 |
