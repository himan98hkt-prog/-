# Phase 1 설치 및 시험 가이드 (Windows PC)

Android 앱(Phase 2)이 나오기 전까지는 **같은 PC 안에서** 중계 서버 + 에이전트 + 시험 클라이언트(`hp-cli`)를
함께 실행해서 실제 화면 캡처와 마우스·키보드 동작을 확인합니다. 외부 서버나 비용은 필요 없습니다.

## 0. 준비물 받기

GitHub 저장소의 **Actions → HomePilot Remote → 최신 실행 → Artifacts → `homepilot-windows`** 를 내려받아
`C:\AI-Projects\HomePilot-Remote\releases` 에 압축을 풉니다. 들어 있는 파일:

| 파일 | 역할 |
|---|---|
| `HomePilot-Agent-Setup-0.1.0.exe` | 에이전트 설치 프로그램 (관리자 권한 불필요) |
| `homepilot-agent.exe` | 에이전트 (설치 없이 바로 실행도 가능) |
| `homepilot-relay.exe` | 중계 서버 (시험용) |
| `hp-cli.exe` | 휴대폰 앱 대신 쓰는 시험 클라이언트 |

> ⚠️ 아직 **코드 서명이 없어서** Windows SmartScreen 이 "PC 보호" 경고를 띄울 수 있습니다.
> [추가 정보] → [실행] 을 누르면 됩니다. 상용 배포 전에는 코드 서명 인증서를 적용합니다(유료, 별도 승인).

## 1. 설치 (선택)

`HomePilot-Agent-Setup-0.1.0.exe` 실행 →
- 설치 위치: `%LOCALAPPDATA%\Programs\HomePilot Remote` (현재 사용자만, 시스템 설정 변경 없음)
- "Windows 로그인 시 자동 실행" 은 **기본 꺼짐**입니다. 원격 접속을 항상 받으려면 체크하세요.
- 제거: 설정 → 앱 → HomePilot Remote Agent → 제거 (자동 실행 등록도 함께 삭제, 키·기록 삭제 여부를 물어봄)

## 2. 같은 PC 에서 시험하기

PowerShell 창을 3개 엽니다. 모두 `cd C:\AI-Projects\HomePilot-Remote\releases` 로 이동.

**창 1 — 중계 서버**
```powershell
.\homepilot-relay.exe            # 127.0.0.1:8443 에서 대기 (이 PC 안에서만 접속 가능)
```

**창 2 — 에이전트**
```powershell
.\homepilot-agent.exe config --relay ws://127.0.0.1:8443 --name "내 PC" | Out-Host
.\homepilot-agent.exe info | Out-Host      # "장치 ID" 20자리를 복사해 두세요
.\homepilot-agent.exe                      # 트레이(작업 표시줄 오른쪽 아래)에 아이콘이 생깁니다
```
> 에이전트는 창 없이 트레이로 실행되는 프로그램이라, 명령어 결과를 보려면 뒤에 `| Out-Host` 를 붙입니다.

**창 3 — 시험 클라이언트** (`<ID>` 자리에 장치 ID)
```powershell
.\hp-cli.exe --device <ID> --name "시험폰" connect
```
→ PC 화면에 **"새 기기 등록 요청"** 창이 뜹니다. 창 3에 표시된 확인 코드와 같으면 [예].

## 3. 시험 항목 (결과를 알려 주세요)

| # | 명령 (창 3) | 확인할 것 |
|---|---|---|
| 1 | `.\hp-cli.exe --device <ID> status` | CPU/RAM/디스크/GPU 값이 작업 관리자와 비슷한가 (`gpu_percent` 가 null 이면 알려 주세요) |
| 2 | `.\hp-cli.exe --device <ID> monitors` | 모니터 개수·해상도가 맞는가 |
| 3 | `.\hp-cli.exe --device <ID> shot --out a.jpg` 후 `start a.jpg` | 실제 화면이 찍혔는가 (마우스 커서 포함) |
| 4 | `.\hp-cli.exe --device <ID> stream --secs 10` | 접속 중 **화면 위쪽 빨간 표시줄**이 보이는가, fps 값 |
| 5 | 메모장을 열어 클릭해 둔 뒤 `.\hp-cli.exe --device <ID> type "안녕하세요 HomePilot"` | 한글이 정확히 입력되는가 |
| 6 | `.\hp-cli.exe --device <ID> click 0.5 0.5 --right` | 화면 정중앙에서 우클릭 메뉴가 뜨는가 |
| 7 | `.\hp-cli.exe --device <ID> combo ctrl a` | 전체 선택이 되는가 |
| 8 | (모니터 2개 이상) `shot --monitor 1 --out b.jpg` | 두 번째 모니터가 찍히는가 |
| 9 | `stream --secs 60` 실행 중 **Ctrl+Alt+F12** | 즉시 끊기고 "차단" 메시지가 나오는가. 이후 트레이 → "원격 제어 다시 허용" |
| 10 | 트레이 아이콘 우클릭 | 메뉴(등록, 차단, 자동 실행, 정보, 로그 폴더, 종료)가 정상인가 |
| 11 | `.\hp-cli.exe --device <ID> --key other.key connect` | 다른 키는 등록 대기 중이 아니면 거부되는가 |

결과 기록은 `docs/TEST-RESULTS.md` 의 B 표에 반영합니다.

## 4. 파일 위치

| 내용 | 위치 |
|---|---|
| 설정 (`config.json`), 장치 키(DPAPI 암호화), 등록 기기 목록 | `%APPDATA%\HomePilot\Agent` |
| 실행 로그 (일별) / 접속 기록 (`connections.jsonl`) | `%LOCALAPPDATA%\HomePilot\Agent\logs` |

## 5. 명령 요약
```
homepilot-agent info | clients | revoke <지문|이름> | log
homepilot-agent config --relay <wss://...> --name <이름> --overlay true|false
homepilot-agent autostart on|off|status
homepilot-agent unblock
homepilot-agent trust-client --name <이름> --public-key <base64> [--view-only]
homepilot-agent run --headless --console      (화면 없이 콘솔에서 실행)
```

## 6. 알려진 제한
- UAC 확인창·잠금 화면은 Windows 보안 정책상 보이지 않고 조작할 수 없습니다(정상).
- 관리자 권한으로 실행된 프로그램 창에는 입력이 전달되지 않습니다(UIPI, 정상).
- 이 단계의 중계 서버는 시험용입니다. 외부(모바일 데이터)에서 접속하려면 중계 서버 공개 방식을 정해야 합니다(Phase 3, 승인 필요).
