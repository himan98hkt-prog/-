# 콩쿨 레퍼토리 — 무엇을 넣을 수 있고, 무엇을 넣으면 안 되나

`mr/repertoire/competition.json` 에 지역 피아노 콩쿨 과제곡 **54곡**을 급수별로
모아 두었습니다. 여기에 **악보는 없습니다.** 목록과 저작권 근거만 있습니다.

```bash
cd mr
python3 catalog_cli.py repertoire                 # 현황 — 무엇이 있고 무엇을 더 구해야 하나
python3 catalog_cli.py repertoire --grade 초급     # 급수로 거르기
python3 catalog_cli.py repertoire --book 부르크뮐러
python3 catalog_cli.py repertoire --scores <폴더>  # 악보가 있는 것을 한 번에 넣기
```

## 왜 악보가 같이 안 들어 있나

**곡은 퍼블릭도메인이지만 악보 파일은 누군가 만든 것**이기 때문입니다. 지역 콩쿨
과제곡은 거의 다 작곡가가 죽은 지 백 년이 넘었습니다 — 바이엘·체르니·부르크뮐러·
소나티네·바흐·쇼팽. 이 제품이 성립하는 이유가 그것입니다. 그런데 그 곡의 **MusicXML
파일**은 누가 입력하거나 스캔한 결과물이고, 그건 별개입니다.

그래서 악보는 원장님이 확보하시고, 프로그램은 **넣어도 되는 곡인지 검사**합니다.

## 프로그램이 직접 계산합니다

목록의 곡마다 **작곡가 사망연도**가 적혀 있습니다. 넣을 때 보호기간(사후 70년,
한국 저작권법 제44조 — 사망한 **다음 해 1월 1일**부터)을 코드가 다시 계산합니다.

```
✗ 카발레프스키 «어릿광대» — D. Kabalevsky 는 아직 저작권 보호기간 안입니다
  (사망 1987년 · 2058년에 만료). 지시서 7장: 보호기간이 끝난 곡만 넣습니다.
```

콩쿨에 자주 나오지만 **아직 못 쓰는** 작곡가를 목록에 따로 적어 두었습니다 —
카발레프스키, 하차투리안, 나카다 요시나오. 몰라서 넣는 일이 없게 하려는 것입니다.
`tests/test_repertoire.py` 가 목록 전체를 매번 다시 검사하므로, 나중에 누가
보호기간 안인 곡을 끼워 넣으면 **CI 에서 막힙니다.**

> **판본 주의.** 곡 자체가 퍼블릭도메인이어도 **특정 출판사의 편집판**(운지·페달·
> 아티큘레이션을 넣은 판)에는 그 편집자의 권리가 따로 붙을 수 있습니다.
> 원전판(Urtext), 보호기간이 끝난 옛 판본, 또는 직접 입력한 것을 쓰세요.

## 악보를 넣는 법

1. MusicXML(`.musicxml` · `.mxl` · `.xml`)을 **한 폴더**에 모읍니다
2. 파일 이름을 목록의 **id 로 맞춥니다** — `burgmuller_op100_02.musicxml`
   (이름을 바꾸기 싫으면 목록의 `file` 칸에 실제 이름을 적어도 됩니다)
3. `python3 catalog_cli.py repertoire --scores <폴더>`

제목·작곡가·교재·난이도·편성·템포는 목록에 적힌 값이 그대로 들어갑니다. 한 곡씩
`import` 하며 인자를 치지 않아도 됩니다.
