# 판매 점검 — 왜 안 팔렸고, 무엇을 바꿨나

2026-11 점검 기준. 제품을 처음 받는 원장님 입장에서 **결제 전 → 체험 → 결제 → 첫 사용**을 순서대로 따라가며 확인했습니다.

> **확인 범위에 대해.** 판매 페이지(accelssam.com)와 퍼널모아 관리 화면은 이 작업 환경에서 열 수 없어 **직접 보지 못했습니다.**
> 아래 "제품 안에서 찾은 것"은 실제 화면을 띄워 확인한 사실이고, "판매 페이지에서 확인할 것"은 보지 못한 부분에 대한 점검 목록입니다.
> 판매 수치(방문·체험·결제 수)도 받은 것이 없어, 어느 단계에서 가장 많이 빠지는지는 추정입니다.

## 1. 제품 안에서 찾은 것 — 모두 고쳤습니다

| # | 문제 | 왜 판매를 막는가 | 바꾼 것 |
|---|---|---|---|
| 1 | **첫 화면이 인증키 입력 칸뿐이었다.** 무엇을 해 주는 프로그램인지, 어디서 사는지 한 줄도 없었다 | 주소를 받아 들어온 사람이 "키가 없네" 하고 닫는다 | 첫 화면을 제품 소개 + **"14일 무료로 써 보기"** 큰 버튼 + 구매 링크로 다시 만들었다 |
| 2 | **앱 어디에도 구매하러 가는 길이 없었다** | 체험하다 마음에 들어도 살 곳을 다시 찾아야 한다 | 첫 화면 · 체험 안내 띠 · 설정 · 인증키 입력 창 · 체험 종료 화면에 **구매 버튼**. 어느 버튼에서 왔는지 주소(`?from=app-…`)에 남는다 |
| 3 | **체험을 시작하면 빈 화면**이었다. 반·원생을 직접 넣기 전에는 아무것도 볼 수 없었다 | 가치를 보기 전에 일을 시킨다. 여기서 대부분 그만둔다 | **샘플 학원 둘러보기**(원생 24명·출결·수강료·교재 진도가 들어 있음). 다 보면 버튼 하나로 지우고 내 학원을 만든다 |
| 4 | 내 학원을 만든 뒤 **"다음에 뭘 하지?"** 가 없었다 | 빈 화면에서 멈춘다 | **시작 가이드** — 반 만들기 → 원생 등록 → 출석 체크 → 수강료 청구. 한 가지 끝낼 때마다 다음을 짚어 준다 |
| 5 | **결제하고 키를 받기까지 판매자를 기다려야 했다** (발급기 열기 → 복사 → 메일 작성) | 밤·주말 결제는 다음 날까지 못 쓴다. 환불 문의로 이어진다 | **퍼널모아 자동 발급 플러그인** — 결제 즉시 키 생성·메일 발송 ([설치 안내](../integration/funnelmoa/README.md)) |
| 6 | **12자리 키를 손으로 옮겨 적어야 했다** | 구매 직후 가장 많이 막히는 자리. 0/O, 1/I 를 헷갈린다 | 메일의 **"눌러서 바로 시작하기"** 버튼(입력 없이 인증) · 메일을 **통째로 붙여 넣어도** 키만 골라냄 |
| 7 | **공용키(Pro)로 열면 앱을 열 때마다 번호 4자리를 물었다** — 혼자 쓰는 원장님도 | 매일 쓰는 프로그램이 매번 문을 잠근다 | 계정이 하나이고 번호가 처음 그대로면 묻지 않는다. 번호를 바꾸거나 선생님 계정을 추가하면 그때부터 묻는다 |
| 8 | **새 원생 등록 창이 "모든 반이 선택된 채로" 열렸다** (버그) | 처음 등록한 학생이 전 반 출석부에 다 들어간다. 체험 첫 5분에 "이상한 프로그램"이 된다 | 고쳤다. 자동 검사에 넣어 다시 생기면 바로 잡힌다 |
| 9 | **전문용어** — custom 필드, CSV, 키오스크, 브랜딩, 퍼널, 템플릿, 절사, 미수금, PIN, 이탈 위험 | 뜻을 몰라 누르지 못한다 | 학습 기록 항목 · 엑셀 파일 · 등원 체크 화면 · 학원 이름·로고·색 · 문자 안내 문구 · 끝자리 버림 · 아직 못 받은 돈 · 잠금 번호 · 챙겨 볼 원생 |
| 10 | **피아노 원장님이 매일 쓰는 "교재·진도"가 없었다** | 피아노 관리노트에는 있는 기능이라 "이건 내 것이 아니네"가 된다 | **교재·진도** — 원생 카드와 출결 화면에서 한 줄 적으면 리포트·레슨 안내 문자에 그대로 들어간다. 처음 설정에서도 **피아노·음악이 맨 앞** |
| 11 | 원생 등록 창에 칸이 11개 | 다 채워야 하는 줄 안다 | 이름 · 학부모 번호 · 반만 보이고 나머지는 "더 적기"에 접어 둠 |
| 12 | 체험이 끝나기 전 **아무 예고가 없었다** | 어느 날 갑자기 잠긴다 | 남은 날을 항상 표시. 3일 전부터 색이 바뀌고, "자료는 구매 후에도 그대로"를 계속 알린다 |
| 13 | 디자인 — 밋밋한 회색 화면, 검은 표 머리, 도움말이 어디 있는지 모름 | 돈 주고 살 제품으로 보이지 않는다 | 사이드바·인사 영역·큰 그림 버튼·"하고 싶은 일로 찾는" 도움말로 전면 개편 |

## 2. 꼭 직접 해 주셔야 하는 것

| 할 일 | 이유 |
|---|---|
| **GitHub 저장소를 비공개로 바꾸기** | 지금 저장소가 공개 상태라 검색에 그대로 나옵니다. 안에 인증키를 만드는 규칙과 발급기가 들어 있어 **누구나 키를 만들 수 있습니다.** Settings → General → Danger Zone → Change visibility |
| **구매 주소 넣기** | 앱의 구매 버튼은 지금 `https://accelssam.com/` 을 엽니다. 실제 상품 페이지 주소로 바꿔 빌드하세요: `VITE_BUY_URL=https://…/상품주소 npm run build` |
| **플러그인 설치 후 실제 결제 1건 해 보기** | 우커머스·웹훅 흐름은 점검 스크립트로 확인했지만, 코스모스팜 회원관리 결제는 공개 문서 기준으로 맞춘 것이라 **실제 사이트에서 한 번 확인이 필요합니다** |
| 메일이 스팸함으로 가지 않는지 확인 | 워드프레스 기본 메일은 스팸으로 잘 갑니다. `WP Mail SMTP` 로 네이버/구글 메일을 연결하면 해결됩니다 |

## 3. 판매 페이지에서 확인할 것 (제가 보지 못한 부분)

상품 페이지를 볼 수 없어 **있는지 없는지 모릅니다.** 없는 것이 있다면 순서대로 넣는 것을 권합니다.

1. **맨 위에 "무료로 써 보기" 버튼** — 앱 주소(`…/lite.html`)로 바로 연결. 결제 전에 써 볼 수 있다는 것이 가장 강한 설득입니다. 이제 들어가면 샘플 학원이 바로 열립니다.
2. **실제 화면 3장** — 오늘 화면, 출결, 원생 카드(교재·진도). `node scripts/shots.mjs piano` 로 뽑을 수 있습니다.
3. **"피아노 관리노트를 쓰고 계신가요? 같은 인증키로 열립니다"** — 기존 고객이 가장 쉽게 넘어오는 길입니다.
4. **한 줄 약속** — "내 컴퓨터에만 저장됩니다 · 인터넷 없이도 됩니다 · 한 번 결제" 중 사실인 것.
5. **결제 직후 안내** — "인증키가 메일로 바로 갑니다. 메일의 버튼을 누르면 시작됩니다."
6. **문의 창구** — 카카오톡 채널이 있다면 `VITE_SUPPORT_URL` 로 넣으면 앱 도움말에 버튼이 생깁니다.

## 4. 앞으로 숫자로 보는 법

- 구매 버튼 유입: 상품 페이지 방문 기록에서 `from=app-activation`(첫 화면) · `app-trial`(체험 띠) · `app-expired`(체험 종료) · `app-settings` · `app-keydialog` 를 나눠 볼 수 있습니다.
- 발급 내역: 플러그인의 **발급 내역 → 엑셀 파일로 내려받기**.
- 체험을 시작한 사람 수는 **알 수 없습니다.** 자료가 기기 안에만 있고 밖으로 아무것도 보내지 않기 때문입니다(제품의 약속이라 일부러 넣지 않았습니다).
