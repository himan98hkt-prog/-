## 읽는 법

- **탭 렌더**: 화면 전환(mount) 부터 실제 페인트(rAF 2회)까지. 사용자가 체감하는 시간입니다.
- **dashboard 탭 렌더(집계 캐시 없음)**: 월별 집계 캐시를 모두 지운 최악의 상태.
  현황 화면은 캐시로 먼저 그리고 빠진 달은 백그라운드에서 채우므로 첫 페인트가 느려지지 않습니다.
- **배치**: 월말 마감·집계 새로고침처럼 사용자가 명시적으로 실행하는 작업이라
  화면 기준(1초)이 아닌 별도 기준을 적용합니다.

## 재현

```bash
npm run perf                        # 원생 1,000 / 반 80 / 출결 20만 (더미 생성 포함)
node scripts/perf.mjs --skip-seed   # 이전 데이터 재사용(빠른 재측정)
node scripts/perf.mjs --students 300 --attendance 50000
```

하나라도 기준을 넘으면 종료 코드 1 로 끝나므로 릴리스 체크에 그대로 물릴 수 있습니다.

## 함께 쓰는 시나리오 검증

`npm run smoke` 는 같은 브라우저 환경에서 완료 기준을 시나리오로 확인합니다
(영어학원 ↔ 태권도장 계열 전환, 브랜딩 반영, 리포트 이미지 생성, 백업 왕복, 라이선스 활성화).
성능(perf)과 기능(smoke)을 함께 돌리면 릴리스 전 점검이 끝납니다.
