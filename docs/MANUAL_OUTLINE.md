# 사용설명서 — 집필 규칙

원고는 더 이상 이 파일에 없습니다. **[`scripts/manual-content.js`](../scripts/manual-content.js)
한 파일**이 원고입니다. 만드는 법은 [`DEPLOY.md` 6장](DEPLOY.md#6-사용설명서).

목차를 여기에도 적어 두면 원고를 고칠 때마다 두 곳을 고쳐야 하고, 한쪽만 고치면
**어느 쪽이 맞는지 아무도 모르게 됩니다.** 그래서 목차는 지우고, 원고가 지키는
규칙만 남깁니다.

## 절 하나의 모양

```js
{
  id: '3-1',                      // 겹치면 안 됩니다 (목차가 엉뚱한 곳으로 갑니다)
  title: '출결 체크',
  shot: 'piano-01-출결',          // screenshots/<이름>.png — 없으면 빌드가 실패합니다
  body: ['...', '...', '...'],    // 서너 줄
  table: { head: [...], rows: [...] },   // 필요할 때만
  trap: '자주 하는 실수 ...',              // 필요할 때만
}
```

- **화면 1장 + 서너 줄.** 길면 안 읽습니다.
- **`trap`(자주 하는 실수)은 실제로 겪을 만한 것만** 적습니다. 지어내면 설명서
  전체를 안 믿게 됩니다.
- 굵게는 `**...**`, 코드는 백틱. 그 외 마크다운 문법은 없습니다.
- **원장님이 읽을 글입니다.** `API`·`엔드포인트`·`캐시` 같은 말을 쓰지 않습니다.
- 그림은 손으로 찍지 않습니다 (`npm run manual:shots`). 손으로 찍으면 화면이
  바뀌었을 때 설명서만 조용히 낡습니다.

## 아직 안 쓴 것

- **문의처와 환불 규정** — 전화번호·메일·환불 조건은 **파는 쪽이 정하는 값**이라
  지어낼 수 없습니다. 팔기 전에 15장 끝에 한 절로 넣으세요.
- **화면별 단축 동작 모음** — 원고 초안의 부록 A 였습니다. 각 장에서 그때그때
  설명하는 편이 나아 뺐습니다.
- **계열별 추천 학습 항목 세트** — 1.1 에서 "계열을 고르면 미리 채워집니다"까지만
  적었습니다. 전체 목록은 설정 화면에서 바로 보이므로 종이에 옮기지 않았습니다.
