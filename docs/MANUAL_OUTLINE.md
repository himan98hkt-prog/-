# 학원 관리노트 사용설명서 — 목차 (집필용 구조)

> 실제 원고는 이 목차대로 작성합니다. 각 절은 "화면 스크린샷 1장 + 3줄 설명 + 자주 하는 실수" 구성.

## 1. 시작하기
1.1 어떤 학원에 맞는 제품인가 (교과·어학·예체능·체육·공부방)
1.2 Lite 와 Pro 차이, 어느 쪽을 살 것인가
1.3 설치 방법 — 웹 주소 접속 / 홈 화면에 추가(안드로이드·아이폰·PC)
1.4 라이선스 키 입력과 플랜 활성화
1.5 시작 마법사 3분 설정 (학원명 → 계열 → 색상 → 과목 → 원장 PIN)

## 2. 기본 준비
2.1 과목 만들기와 색상 정하기
2.2 반 만들기 — 요일·시간, 강의실, 정원, 수강료
2.3 강사·데스크 계정과 PIN 권한
2.4 원생 등록과 반 배정
2.5 형제·자매 자동 묶기(학부모 번호 매칭)
2.6 우리 학원 항목 만들기 — 진도 교재 / 띠 급수 / 레벨 점수

## 3. 매일 쓰는 기능

3.2 결석 사유 태그와 보강 예약
3.3 키오스크 자가 체크인 (입구 태블릿)
3.4 원생 검색과 원생 카드 보기
