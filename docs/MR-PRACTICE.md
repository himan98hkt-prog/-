# 피아노 자동 반주 — 연습 기록 되돌리기 (작업 보고)

5단계에서 명단은 **관리노트 → 반주** 한 방향으로만 갔다. 이건 반대 방향이다.

앞 단계 보고는 [MR-ENGINE.md](MR-ENGINE.md) · [MR-CATALOG.md](MR-CATALOG.md) ·
[MR-PLAYER.md](MR-PLAYER.md) · [MR-UPLOAD.md](MR-UPLOAD.md) · [MR-LINK.md](MR-LINK.md).

---

## 1. 왜 하는가

아이가 어떤 곡을 며칠에 몇 번, 몇 분이나 연습했는지는 **반주 쪽에만** 남아 있었다.
그래서 학부모 리포트에 쓸 수 있는 건 출석률과 진도 교재뿐이었다.

출석률만 적힌 리포트와 **"이번 달 집에서 15일, 37번, 4시간 연습했습니다"** 가 적힌
리포트는 학부모가 받는 느낌이 다르다. 이 한 칸이 이 기능의 전부다.

지시서에는 없는 항목이다. 5단계까지 끝낸 뒤 남은 일로 적어 두었던 것을 한다.

---

## 2. 어디서 어디로 가는가

```
  학부모 기기(집 연습 링크)  ─┐
                              ├─→ 연습 기록 파일 ─→ 관리노트 ─→ 원생 카드 · 학부모 리포트
  원장님 기기(플레이어)      ─┘
```

**서버가 없다.** 플레이어는 정적 꾸러미라 어디에 올릴 계정이 없고, 집 연습 링크는
지시서 ⑤-10 이 「설치·로그인 없이 재생」이라고 못 박았다. 거실에서 학부모에게
가입을 시킬 수는 없다.

그래서 명단이 파일로 건너간 것과 같은 방식으로, 연습도 **파일로 건너온다.**
보내는 방법은 학부모 리포트가 이미 쓰는 것과 같다 — 공유 시트가 있으면 카톡으로
바로, 없으면 파일로 내려받아 전달.

### 몰래 올라가지 않는다

기록은 그 기기의 브라우저에만 쌓인다. **「연습 기록 보내기」를 누를 때만** 밖으로
나간다. 로그인이 없어서 몰래 올릴 방법이 없기도 하지만, 있었어도 안 했을 것이다 —
남의 집 거실에서 아이가 뭘 했는지를 묻지도 않고 가져오는 모양이 된다.

오래된 기록은 스스로 지운다(180일). 학부모 기기에 아이 연습 기록이 몇 년씩 남을
이유가 없다.

## 3. 세는 규칙을 좁게 잡았다

이 숫자는 학부모에게 나간다. 한 번 부풀려지면 그 뒤로는 아무도 안 믿는다.

| 무엇 | 규칙 | 왜 |
|---|---|---|
| 시간 | **재생 중인 벽시계 시간**만 | 템포를 늦추면 실제로 더 오래 걸린다. 리포트에 쓰는 건 "몇 분 앉아 있었나"다 |
| 한 번 | 곡을 **끝까지** 쳤을 때 | 이건 확실하다 |
| 한 번 | 끝까지 못 가도 **1분 넘게** 쳤으면 | 구간 반복으로 어려운 데만 파는 것도 연습이다 |
| — | 3분 쳤다고 **세 번은 아니다** | 한 번까지만 센다 |
| — | **30초 미만은 기록조차 안 한다** | 곡을 잘못 눌러 본 것이다 |

`MIN_RUN_SECONDS = 60` · `MIN_KEEP_SECONDS = 30` (`js/practice.js`).

### 누구 건지 모르면 적지 않는다

아이를 안 고른 채로 친 연습은 **보낼 수가 없다.** 받는 쪽에서 누구에게 붙일지
모르기 때문이다. 그런데도 적어 두면 화면에는 "3일 · 12번"이 뜨는데 보내면 빈 파일이
간다 — 실제로 검사([13])가 이 상태를 잡아냈다. 지금은 적지 않고, 연주 화면이
**「아이를 고르면 연습한 날짜와 시간이 남습니다」**라고 말해 준다.

---

## 4. 두 번 넣어도 안 늘어난다

원장님이 같은 파일을 두 번 넣으시는 일도, 학부모가 지난주 파일을 다시 보내시는 일도
실제로 생긴다. 그때 리포트 숫자가 두 배가 되면 그 리포트는 못 쓴다.

**열쇠는 `학생::곡::날짜::기기` 다.** 저장소의 `id` 가 곧 이 열쇠다 — 무작위 id 를
붙이면 같은 연습이 여러 줄이 된다.

### 기기를 왜 따지는가

같은 날 같은 곡을 **학원에서도 치고 집에서도** 치면 기록이 두 벌 생긴다.

| 합치는 방법 | 학원+집 | 같은 파일 두 번 |
|---|---|---|
| 덮어쓰기 (기기 무시) | 하나가 **사라진다** | 그대로 ✓ |
| 더하기 (기기 무시) | 맞다 ✓ | **두 배가 된다** |
| **기기 안에서 덮어쓰고, 기기끼리 더하기** | 맞다 ✓ | 그대로 ✓ |

기기 id 는 설치할 때 만든 무작위 문자열이고 사람을 가리키지 않는다.

한 기기가 보내는 값은 그 날 그 곡의 **누적**이라 큰 쪽이 이긴다. 옛날 파일을 다시
넣어도 최신 숫자가 깎이지 않는다.

---

## 5. 남의 아이 연습이 우리 아이 리포트에 찍히면 안 된다

반주 쪽이 학생 id 를 알면 id 로 붙는다(발표회 큐나 집 연습 링크가 실어 준다).
이름만 아는 경우에는 **이름이 정확히 하나만 맞을 때만** 붙인다.

동명이인이면 붙이지 않고 **버리지도 않는다.** 관리노트가 「이 연습은 누구 것인가요」를
여쭤 보고, 원장님이 고르시면 그때 들어간다.

---

## 6. 형식 파일은 한 벌인데, 사는 곳이 둘이다

`src/core/practice-piano.js` 가 원본이고,
`mr/server/static/player/js/practice-format.js` 는 그 **글자 그대로의 사본**이다.
플레이어는 정적 꾸러미로 따로 배포돼서 관리노트 소스를 불러올 수 없다.

형식을 한쪽에서만 고치면 **원장님 쪽에서 파일이 안 읽힌다.** 우리 화면에서는 안 보이고
현장에서만 보이는 고장이라, 손으로 맞추지 않는다.

```bash
npm run sync:shared           # 맞춘다
npm run sync:shared -- --check   # 다른지만 본다 (CI)
```

두 파일이 한 글자라도 다르면 `npm test` 가 실패한다.

## 7. 표를 새로 만들면 일곱 군데를 고쳐야 한다

`practice` 표 하나를 추가하는 데 고칠 곳이 일곱이었다.

| 어디 | 빠뜨리면 |
|---|---|
| `db.js` 스키마 (v2) | 표가 없다 |
| `backup.js` `BACKUP_TABLES` | 기기를 바꿀 때 **연습만 조용히 사라진다** |
| `repo.js` `SYNCED_TABLES` | Pro 에서 다른 기기에 안 올라간다 |
| `sync.js` `TABLES` · `PG` | 동기화가 그 표만 건너뛴다 |
| `schema.sql` 표 | Pro 에서 저장이 안 된다 |
| `schema.sql` 트리거 배열 | 동기화 커서가 안 움직인다 |
| `schema.sql` RLS 배열 | **다른 학원 자료가 보인다** |

전부 우리 화면에서는 안 보이고 현장에서만 보이는 고장이다. 그래서
`tests/schema-wiring.test.js` 가 스키마에서 표 목록을 읽어 일곱 군데와 대조한다.
네 군데를 하나씩 빼 보며 **실제로 실패하는지** 확인했다.

## 8. 검사

```bash
npm test                          # 관리노트 257건 (연습 형식 30 · 불러오기 11 · 배선 7)
cd mr && python3 -m pytest        # 반주 404건
python3 tools/player_check.py     # 브라우저 13항목
```

브라우저 검사에 두 항목이 늘었다. 둘 다 **서버를 죽인 채로** 본다 — 집 연습은 인터넷이
없는 데서도 일어나고, 그때 기록이 안 남으면 그 연습이 리포트에서 통째로 빠진다.

```
[12] 서버 없이 연습 기록 — 1번 · 95초 (5초만 누른 건 안 셈)
[13] 보낼 파일 282바이트 · 1줄 · 연락처 0건 · 관리노트가 읽는 형식
```

1분 넘게 친 것을 1분 기다리지 않으려고 페이지의 `Date.now` 에 보정값을 넣는다
(기본 0 이라 다른 검사는 영향을 받지 않는다).

## 9. 아직 안 된 것

- **학부모가 직접 보내는 흐름을 실제 휴대폰에서 못 해 봤다.** 공유 시트
  (`navigator.share`)는 헤드리스 크로미움에 없어서, 검사는 파일을 만드는 데까지만
  본다. 아이폰 사파리에서 카톡으로 넘어가는지는 실기기 확인이 필요하다.
- **연습 기록을 반주 쪽으로 되돌려 보내지 않는다.** 관리노트가 원본이 되고 반주는
  계속 자기 기기 것만 안다. 지금은 필요가 없어 보인다.
- **원장님이 여러 학부모 파일을 한 번에 넣는 화면은 없다.** 한 번에 한 파일씩이다.
  받는 파일이 많아지면 그때 만든다.
