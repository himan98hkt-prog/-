# 반주(MR) 다섯 화면의 옷 — 왜 이렇게 생겼나

고칠 때 여기부터 읽으시면 됩니다. 색을 하나 바꾸려다 **오프라인 재생을 깨뜨리는
길**이 이 제품에는 실제로 있습니다.

## 다섯 화면

| 화면 | 주소 | 누가 | 옷 |
|---|---|---|---|
| 카탈로그 | `/static/index.html` | 우리·원장님 | `player/tokens.css` + `app.css` |
| 화성 확인 | `/static/verify.html` | 우리·원장님 | 〃 |
| PDF 올리기 | `/static/upload.html` | 원장님 | 〃 + `upload.css` |
| 발표회 운영 (무대) | `/static/program.html` | 원장님 | `tokens.css` + `hall.css` |
| 플레이어 (곡목록·연주) | `/static/player/` | 원장님·아이 | `tokens.css` + `player.css` |

값은 **한 군데**에 있습니다 — `mr/server/static/player/tokens.css`.

## 정해 둔 것 다섯 가지

**1. 다섯 화면 전부 어둡습니다.** 전에는 제작 도구 셋만 흰 바탕이었습니다. 한
제품 안에 낮과 밤이 같이 있으면 화면을 옮길 때마다 다른 프로그램처럼 보입니다.
연주·발표회 화면은 연주홀에서 쓰는 것이라 어두운 쪽을 못 바꿉니다. 그래서 제작
화면을 그쪽에 맞췄습니다.

**2. 토큰이 `player/` 안에 있습니다.** 이상해 보이지만 이유가 있습니다.
플레이어는 `export_static` 이 폴더째 복사해 원장님 웹호스팅에 올립니다. 토큰을
바깥에 두면 꾸러미에 안 실리거나, 실으려고 사본을 만들어야 합니다. **사본은
반드시 어긋납니다.** 그래서 어차피 실리는 폴더에 두고 제작 화면이 빌려 씁니다.

**3. 웹폰트가 없습니다.** 지시서 ⑤-1 이 「오프라인은 타협 불가」입니다. 구글
폰트를 걸면 비행기 모드에서 글꼴이 무너지고, 한글 폰트는 서브셋을 떠도 꾸러미
전체(지금 161 KB)보다 무겁습니다. 인상은 **크기·굵기·자간·숫자 정렬**로 냅니다.
숫자가 많은 제품이라 `tabular-nums` 하나가 크게 먹습니다.

**4. 플레이어에는 이미지 *파일*이 없습니다.** 꾸러미가 161 KB 입니다. 그림 한 장이
껍데기(83 KB)보다 무거울 수 있습니다. 발표회 무대 화면은 서버에서 뜨니 자유롭고,
거기만 `img/hall.jpg` · `img/hall.mp4` 를 받습니다. 자세한 건 `MR-IMAGES.md`.

그림이 필요한 자리(편성 고르는 일곱 단추)는 **SVG 를 코드 안에** 둡니다. 파일로
나누면 `SHELL_FILES` 에 줄이 늘고, 그중 하나만 빠져도 오프라인이 통째로 죽습니다.
일곱 개 합쳐 1.6 KB 입니다 — 파일로 나눌 만한 크기가 아닙니다.

**5. 강조색은 금빛→와인입니다.** 무대 조명에서 막으로. 흔한 보라-파랑
그라데이션을 안 쓴 이유는 하나입니다 — 이 제품이 있는 곳은 연주홀이지 클럽이
아닙니다. 「좋다/주의/나쁘다」 색은 강조색과 **따로** 둡니다. 상태는 브랜드가
아닙니다.

## 한글에 걸린 함정

`letter-spacing` 은 한글 음절 사이에도 똑같이 들어갑니다. 라틴에서 멋있는
`.16em` 이 한글에서는 글자를 흩어 놓습니다. **작은 라벨은 `.12em` 이 경계**이고,
`♩=` 같은 기호 라벨에는 아예 주지 않습니다 — 기호가 분해돼 보입니다.

`text-transform: uppercase` 는 한글에 아무 일도 하지 않습니다. 같은 라벨에 영문이
섞일 때를 위해 남겨 둔 것이지 한글을 위한 것이 아닙니다.

## 고칠 때 돌려야 하는 것

```bash
cd mr && python3 tools/player_check.py            # 11항목
python3 tools/player_check.py --static /tmp/pkg   # 서버 없이도 같은 11항목
python3 catalog_cli.py package /tmp/pkg           # 꾸러미가 얼마나 늘었나
```

디자인만 바꿨어도 **11항목이 그대로 통과해야 합니다.** 오프라인 재생,
페이드아웃 3초, 카운트인 이어폰 분리는 옷을 갈아입는다고 달라질 일이 아닙니다.
달라졌다면 옷이 아니라 다른 것을 건드린 겁니다.

그림을 다시 찍으려면:

```bash
npm run manual:shots && npm run manual && npm run manual:verify
```

`tools/manual_shots.py` 는 카탈로그 **사본**에서 찍습니다. 원본을 건드리면 다음에
돌릴 때 그림이 달라지고, 남의 작업 카탈로그에 가짜 검수 기록이 남습니다.

## 서비스워커를 잊지 마세요

플레이어 껍데기 파일을 **추가**하면 `player/sw.js` 의 `SHELL_FILES` 에 같이
넣어야 합니다. 빠뜨리면 온라인에서는 멀쩡하고 **비행기 모드에서만** 무너집니다.
파일 내용만 바꿨다면 `VERSION` 을 올려야 기존 기기의 캐시가 버려집니다.

반대 방향이 더 위험합니다 — **목록에 적었는데 파일이 없으면 `cache.addAll` 이 전부
거부해 서비스워커 설치가 통째로 실패합니다.** 오프라인이 조금 부실해지는 게 아니라
아예 안 켜집니다. `tests/test_player_wiring.py` 가 꾸러미를 실제로 내보내 확인합니다.

같은 파일이 편성 키도 봅니다. `orchestration.py` 의 `STYLES` 에 편성을 더하면
플레이어의 `STYLE_LABEL` 과 `STYLE_ICON` 도 같이 늘어야 합니다 — 안 그러면 그
편성만 **고장 표시도 없이** 단추에서 빠집니다.
