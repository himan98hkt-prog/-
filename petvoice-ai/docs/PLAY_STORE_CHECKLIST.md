# Google Play 출시 체크리스트 (2026)

구현으로 끝난 항목(✅)과 출시 담당자가 스토어에서 처리해야 하는 항목(⬜)을 나눠 둔다.

## 1. 보안 아키텍처

- ✅ 클라이언트에 `GEMINI_API_KEY` 없음 — Edge Function 프록시 경유 (`src/api/proxy.ts`)
- ✅ 개발 시작 시 클라이언트 환경변수 유출 검사 (`assertNoAiKeyInClient()`)
- ✅ 사용량 제한을 서버에서 강제 (`consume_quota()` — 클라이언트 카운트는 우회 가능)
- ✅ 업로드 검증: mime 화이트리스트, 5MB 상한, 프롬프트 길이 상한
- ✅ RLS 로 본인 데이터만 접근, 사용량 테이블은 서비스 롤 전용
- ⬜ 릴리스 빌드에 `.env` 가 포함되지 않는지 최종 확인 (`eas build` 환경변수로 주입)

## 2. 필수 제출 항목

- ✅ 개인정보처리방침 초안 (`docs/PRIVACY_POLICY.md`)
- ⬜ 위 문서를 공개 URL 로 게시하고 Play Console 에 등록
- ⬜ `src/ui/links.ts` 의 `privacy` / `terms` 를 실제 URL 로 교체
- ⬜ 데이터 보안(Data safety) 양식 작성 — 아래 "데이터 보안 답변" 참고
- ⬜ 스토어 등록정보(스크린샷 최소 2장, 512×512 아이콘, 1024×500 그래픽)

### 데이터 보안 양식 답변 초안

| 질문 | 답변 |
|---|---|
| 데이터를 수집·전송하나요? | 예 — 오디오/사진(앱 기능 목적, 저장 안 함), 앱 활동(사용 횟수) |
| 데이터가 암호화되나요? | 예 (HTTPS) |
| 삭제를 요청할 수 있나요? | 예 — 앱 내 계정 삭제 및 데이터 초기화 |
| 제3자와 공유하나요? | 예 — AI 분석 처리위탁(Google), 호스팅(Supabase) |
| 필수 수집인가요? | 아니요 — 권한 거부 시에도 나머지 기능 사용 가능 |

## 3. 계정 및 데이터 삭제

- ✅ `설정 ▸ 계정 삭제` — `delete-account` 함수가 `auth.users` 삭제, CASCADE 로 연관 데이터 제거
- ✅ `설정 ▸ 모든 데이터 초기화` — 로컬 데이터 전체 삭제
- ⬜ Play Console 의 "앱 외부 계정 삭제 URL" 항목에 웹 삭제 요청 경로 등록

## 4. 런타임 권한

- ✅ 마이크·카메라·갤러리 모두 **용도 설명 팝업 → 시스템 권한 요청** 순서 (`src/ui/permissions.ts`)
- ✅ 거부 후 재요청 불가 상태면 설정 앱으로 안내
- ✅ `app.json` 에 iOS usage description 과 Android 권한 명시, 불필요한 권한은 `blockedPermissions` 로 차단
- ✅ 권한을 거부해도 앱의 나머지 기능이 동작

## 5. 정책상 주의 항목

- ✅ 의료/건강 오인 방지 문구 — 결과 화면과 온보딩에 "수의학적 진단이 아님" 고지
- ✅ 구독 조건(가격·자동갱신·해지 방법)을 결제 화면에 명시
- ⬜ 인앱 결제는 Google Play 결제 시스템으로만 처리 (외부 결제 링크 금지)
- ⬜ 광고 ID 를 쓰지 않으므로 AD_ID 권한 미선언 확인

## 6. 테스트 트랙

- ⬜ 내부 테스트로 기능 확인
- ⬜ **비공개 테스트: 테스터 20명 등록 후 14일 연속 진행** (프로덕션 승인 전제 조건)
- ⬜ 14일 경과 후 프로덕션 액세스 신청

## 7. 출시 전 실기기 스모크

- ⬜ 마이크 권한 거부 → 안내 문구 확인 → 설정에서 허용 후 정상 녹음
- ⬜ 3초 자동 종료 후 분석 진입, 실패 시 사용자 문구 노출
- ⬜ 카메라 가이드라인 표시, 촬영 → 결과 → 포토카드 공유(인스타/카톡)
- ⬜ 무료 3회 소진 후 페이월 진입, 자정 이후 초기화
- ⬜ 앱 재시작 후 프로필·히스토리 유지(AsyncStorage)
- ⬜ 계정 삭제 후 앱이 초기 상태로 복귀
