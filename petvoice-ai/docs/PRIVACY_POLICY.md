> 실제 배포 전 사업자 정보(상호·주소·대표자·연락처)를 채우고, 법률 검토를 거쳐

회원가입이 없으며 이용자를 개인으로 식별하지 않습니다.

## 2. 제3자 제공 및 처리위탁

| 수탁자                | 위탁 업무                          | 전송되는 정보                                |
| --------------------- | ---------------------------------- | -------------------------------------------- |
| Google (Gemini API)   | AI 감정 분석                       | 분석 요청한 소리 또는 사진, 상황 맥락 텍스트 |
| Supabase Inc.         | 인증·데이터베이스·서버 기능 호스팅 | 익명 계정 식별자, 사용 횟수, 구독 상태       |
| Google (Play Billing) | 구독 결제 및 영수증 검증           | 구매 토큰                                    |
| Apple (App Store)     | 구독 결제 및 영수증 검증           | 영수증                                       |

- 소리·사진은 **분석 응답을 받는 즉시 폐기**되며 어느 서버에도 저장되지 않습니다.
  다이어리 백업에도 사진·녹음은 포함되지 않습니다(분석 결과 텍스트만 저장).
- 정확도 피드백에는 판정값과 분류값(감정·상황·매체 종류)만 담기며, 분석 문장이나 미디어는 보내지 않습니다.
- 오류 보고는 기본적으로 꺼져 있고, `설정 ▸ 오류 보고 보내기` 를 켠 이용자에게만 적용됩니다.
- 위 목적 외의 제3자 제공, 판매, 광고 목적 이용은 없습니다.

## 3. 국외 이전

AI 분석과 서버 기능 이용을 위해 위 수탁자의 해외 서버로 정보가 이전될 수 있습니다.
이전 국가는 수탁자의 리전 설정에 따르며, 이전 항목·목적·보유기간은 위 표와 같습니다.

## 4. 이용자의 권리와 삭제 방법

- **모든 데이터 초기화**: 앱 내 `설정 ▸ 모든 데이터 초기화` — 기기에 저장된 프로필과 분석 기록이 즉시 삭제됩니다.
- **계정 삭제**: 앱 내 `설정 ▸ 계정 삭제` — 익명 계정과 서버에 저장된 사용 기록이 완전히 삭제됩니다.
  (데이터베이스의 `ON DELETE CASCADE` 로 연관 레코드가 함께 삭제됩니다.)
- 웹에서 삭제를 요청하려면 아래 연락처로 문의해 주세요.

## 5. 권한 사용 안내

| 권한         | 사용 목적                           | 거부 시                                        |
| ------------ | ----------------------------------- | ---------------------------------------------- |
| 마이크       | 울음소리 3초 녹음                   | 소리 분석만 이용 불가, 나머지 기능은 정상 사용 |
| 카메라       | 자세·표정 촬영                      | 사진 분석만 이용 불가                          |
| 사진(미디어) | 저장된 사진으로 분석·포토카드 생성  | 갤러리 선택만 이용 불가                        |
| 알림         | 저녁 기록 리마인더·주간 리포트 안내 | 알림만 이용 불가 (기본 꺼짐)                   |

모든 권한은 **필요한 시점에 용도를 먼저 설명한 뒤** 요청하며, 언제든 기기 설정에서 철회할 수 있습니다.

## 6. 아동의 개인정보

만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

## 7. 안전성 확보 조치

- 모든 통신은 HTTPS 로 암호화됩니다.
- AI API 키는 서버 환경변수에만 존재하며 앱에 포함되지 않습니다.
- 데이터베이스는 행 수준 보안(RLS)을 적용해 본인 데이터에만 접근할 수 있습니다.

## 8. 의료 관련 고지

PetVoice AI 가 제공하는 분석과 안내는 **참고용 정보**이며, 수의학적 진단이나 치료를 대체하지 않습니다.
반려동물의 건강이 우려되면 반드시 수의사의 진료를 받으세요.

## 9. 변경 고지

방침이 변경되면 앱 내 공지와 이 문서의 최종 수정일로 알립니다.
