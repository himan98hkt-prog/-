버튼 설명 켬

API 키

키를 넣으면 클로드가 작곡합니다. 넣지 않아도 프로그램은 규칙 기반(무료)으로 전 과정이 돌아가지만, 콩쿨에 낼 품질은 키를 넣어야 나옵니다.

키는 이 컴퓨터의 .env 파일에만 저장되고 밖으로 나가지 않습니다. 한 번 넣으면 다시 보이지 않고, 가린 모양으로만 확인됩니다.

키는 여기서 만듭니다 — console.anthropic.com

작곡가 이름

악보·음원·프로그램북에 나가는 이름은 예명 하나입니다. 실명과 연락처는 저작권 등록 서류에만 쓰이고 이 컴퓨터 밖으로 나가지 않습니다.

API 비용

곡을 만들 때 드는 비용입니다. 규칙 기반(무료)으로 만든 곡은 0원이라 빠집니다.

넣어 둔 돈 · 남은 돈

앤트로픽에 충전하신 금액을 한 번만 적어 두시면, 그 뒤로는 얼마가 나갔고 얼마가 남았는지 프로그램이 대신 셉니다.

솔직히 말씀드립니다. 앤트로픽 계정에 진짜로 남은 잔액은 이 프로그램이 읽을 수 없습니다 — 잔액을 읽는 창구는 관리자 전용 열쇠만 받고, 원장님이 넣으신 보통 열쇠는 거절당합니다. 그래서 여기 숫자는 이 프로그램이 쓴 돈만 셉니다. 다른 프로그램이 같은 열쇠를 썼다면 실제 잔액은 이보다 적습니다. 정확한 잔액은 console.anthropic.com → Billing 에서 보십시오.

곡을 쌓을 폴더

만든 곡이 파일로 쌓이는 자리입니다. 곡마다 폴더가 하나씩 생기고 악보·MIDI·음원·해설이 그 안에 들어갑니다. 원드라이브·구글 드라이브 폴더나 USB 를 정하시면 집 PC 와 학원 PC 에서 같은 곡을 보실 수 있습니다.

프로그램 폴더 안은 정하실 수 없습니다 — 새 판을 받을 때 덮어쓰이는 자리라 곡이 사라집니다. 바탕화면·문서·드라이브 폴더처럼 프로그램 밖을 정해 주십시오. 경로를 모르시면 탐색기에서 그 폴더를 열고 주소창을 클릭해 나오는 글을 복사해 붙여 넣으시면 됩니다.

자동 백업

만든 곡은 컴퓨터의 파일 하나에 들어 있습니다. 그 파일이 지워지면 그동안 만든 곡이 전부 사라지므로, 저장될 때마다 사본을 따로 남깁니다.

사본으로 되돌리려면

    되돌리기는 프로그램이 대신 하지 않습니다 — 잘못 되돌리면 지금 것까지 잃기 때문입니다. 위 순서대로 하시고, 확신이 없으면 원본을 지우지 말고 이름만 바꿔 두십시오.

    이 프로그램은 이렇게 씁니다 — 세 걸음입니다

    1. 의뢰서를 만듭니다 — 급수와 성격을 고르고, 원하시는 것을 체크합니다. 나머지 규정(손 크기·음역·제한 시간·검사 기준)은 프로그램이 다 채웁니다
    2. 복사해서 Claude 대화창에 붙여 넣습니다 — 곡이 옵니다
    3. 받은 파일을 여기 넣습니다 — 검사를 거쳐 보관함에 들어가고, 그때부터 보고 · 듣고 · 고치고 · 곡집 · 판매 꾸러미 · 저작권 서류가 됩니다

    여기까지 API 비용이 한 푼도 들지 않습니다. 프로그램이 직접 작곡하는 길(비용 발생)은 맨 아래에 접어 두었습니다.

    프로그램이 직접 작곡하기 API 를 씁니다 — 곡마다 돈이 듭니다. 눌러서 펼치십시오.

    이 아래는 클로드 API 로 프로그램이 직접 작곡하는 길입니다. 곡 하나에 $0.3~$6 이 들고, 곡을 못 얻고 끝나도 그 돈은 나갑니다. 위쪽 의뢰서 만들기 로 하시면 비용이 들지 않습니다.

    대화창에서 작곡해 오기

    비용 $0 — API 를 쓰지 않습니다

    프로그램이 의뢰서를 만들어 드립니다. 그것을 Claude 대화창에 붙여 넣으면 곡이 오고, 돌아온 내용을 여기 넣으면 검증기·음악성 지표·표절 검사·모의 심사가 그대로 돌고 보관함에 들어갑니다. 그다음은 평소처럼 악보 편집·곡집·판매 꾸러미·저작권 서류가 됩니다.

    1단계

    의뢰서 만들기

    이 곡을 남다르게 만들 것 고르시면 의뢰서에 구체적인 지시로 들어갑니다
    2단계

    받아온 곡 넣기

    둘 중 편하신 쪽으로 하시면 됩니다.

    ① 파일로 넣기 (쉽습니다) 받으신 달음질.json 같은 파일을 고르시면 됩니다. 끌어다 놓으셔도 됩니다.

    ② 글로 붙여 넣기 — 대화창이 돌려준 내용을 통째로 붙여 넣으십시오. 앞뒤에 설명이 섞여 있어도 괜찮습니다 — 코드블록만 골라 읽습니다.

    작곡 비용

    음표가 많은 곡(토카타·피날레·상급)일수록 비쌉니다.

    1단계

    누가 치는 곡입니까

    파는 곡은 얼굴을 모르는 아이들이 칩니다. 그래서 그 급수의 가장 작은 손을 기준으로 만듭니다 — 손이 큰 아이는 작은 곡을 칠 수 있지만, 손이 작은 아이는 큰 곡을 못 칩니다.

    2단계

    성격

    고르지 않으셔도 됩니다. 알아서 고르기를 누르면 그 급수에서 심사에 가장 안전한 성격부터 씁니다 — 형식이 뚜렷하고 클라이맥스가 분명한 곡을 심사표는 후하게 봅니다.
    직접 고르시면 열두 가지가 모두 나옵니다. 그 급수에 권하지 않는 것은 흐리게 표시하지만, 눌러서 만들 수 있습니다.

    급수별로 한 벌 만들기 — 표지까지 붙은 곡집 한 권

    고른 급수마다 한 곡씩 만듭니다. 성격이 겹치지 않게 돌아가며 고르므로, 다섯 곡이 서로 다른 곡이 됩니다. 한 곡이 막혀도 나머지는 계속 만듭니다.

      MusicXML · MXL · MIDI · PDF 를 받습니다. 여러 개를 한 번에 고르셔도 됩니다. 올리면 바로 반영됩니다 — 프로그램을 껐다 켜지 않으셔도 됩니다.

      PDF 는 어디까지 되나요?

      PDF 는 그림이지 악보 데이터가 아닙니다. 그래서 음표 하나하나는 읽지 못하고, 확실한 것만 가져옵니다 — 쪽 수, 제목·작곡가, 그리고 악보에 글자로 찍혀 있으면 박자·빠르기·마디 번호까지입니다.

      그것만으로도 "이 급수의 곡은 대략 몇 마디에 어느 빠르기인가" 를 배웁니다. 모르는 값은 지어내지 않고 비워 둡니다 — 참고 자료에 거짓이 섞이면 없느니만 못합니다.

      선율까지 참고하게 하시려면 MusicXML 이 필요합니다. 무료 프로그램 MuseScore 로 PDF 를 열어 파일 → 내보내기 → MusicXML 하시면 됩니다. 종이를 스캔한 PDF 는 글자층이 없어 쪽 수만 알 수 있습니다.

      저작권 표시가 없는 악보는 저작권곡으로 간주해 길이·난이도 같은 통계만 참고하고 음표는 보관하지 않습니다. 보호 기간이 끝난 곡이라면 악보 파일 옆에 같은 이름의 .json 파일을 만들어 {"copyright_status": "public_domain"} 이라고 적어 두십시오 — 그때만 선율까지 참고합니다.
      레벨별로 한꺼번에 만들기 — 학원에 팔 묶음

      레벨을 쉼표로 적으면 그 레벨마다 한 곡씩 이어서 만듭니다. 컨셉은 겹치지 않게 알아서 고릅니다. 한 곡이 막혀도 나머지는 계속 만듭니다.
