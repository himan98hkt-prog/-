콩쿨 작곡기 - 설치 안내
=======================

1. 이 폴더를 통째로 원하는 곳에 두십시오.
   (바탕화면도 되고, C 드라이브도 됩니다. 한글 폴더 이름도 괜찮습니다.)

2. 폴더 안의  설치.bat (또는 INSTALL.bat) 을 두 번 누르십시오.
   - 파이썬이 없으면 알아서 받습니다.
   - 3~5분 걸립니다. 창을 닫지 마십시오.
   - 끝나면 바탕화면에 '콩쿨 작곡기' 아이콘이 생깁니다.

   ※ 설치.bat 을 눌렀는데 메모장이 열리면:
      install.ps1 을 오른쪽 클릭 -> 'PowerShell에서 실행'

3. 바탕화면의 '콩쿨 작곡기' 아이콘을 누르면 프로그램이 열립니다.

4. API 키는 넣지 않으셔도 됩니다.
   이 프로그램의 중심은 '의뢰서 만들기 -> 대화창에서 작곡 -> 곡 넣기' 이고,
   그 길은 비용이 한 푼도 들지 않습니다.


쓰는 순서 (세 걸음)
-------------------
(1) 의뢰서 만들기 : 급수와 성격을 고르고, 원하시는 항목을 체크합니다.
                    손 크기, 음역, 제한 시간 같은 규정은 프로그램이 다 채웁니다.
(2) 복사해서 Claude 대화창에 붙여 넣습니다. 곡이 옵니다.
(3) 받은 파일을 '받아온 곡 넣기' 에서 고릅니다.
    검사를 거쳐 보관함에 들어가고, 그때부터 보고 듣고 고치고
    곡집 / 판매 꾸러미 / 저작권 서류가 됩니다.

돈이 드는 길(프로그램이 직접 작곡)은 화면 맨 아래에 접혀 있습니다.


만든 곡은 어디에 저장되나
-------------------------
프로그램 폴더가 아니라  %LOCALAPPDATA%\ConcoursComposer  에 저장됩니다.
그래서 이 폴더를 지우거나 새 판으로 덮어써도 만든 곡은 사라지지 않습니다.


새 판으로 올리려면
------------------
프로그램 화면 위쪽에 '새 판이 나왔습니다' 가 뜨면 '지금 올리기' 를 누르십시오.
안 되면 폴더의  업데이트.bat  을 직접 실행하셔도 됩니다.

판 번호는 프로그램 화면 오른쪽 위에 늘 떠 있습니다.
