# tools/notation — 세션 작곡 표기 도구

`GOLDEN_ENGINE=session` 으로 사람(또는 Claude Code 세션)이 직접 작곡할 때 쓰는 도구다.
파이프라인이 프롬프트를 파일로 내놓으면 여기 헬퍼로 응답 JSON 을 만든다.
**서버 코드(검증기·지표·스키마)를 그대로 import** 하므로, 파이프라인을 돌리기 전에
같은 잣대로 미리 재 볼 수 있다.

```bash
cd tools/notation
../../.venv/bin/python score.py g20 19      # 지표·난이도 미리보기 (gid, 손 스팬)
../../.venv/bin/python peek.py g20          # critic_prompt.md 의 지표·경고만
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `_paths.py` | 저장소 뿌리를 찾아 `server` 를 import 경로에 넣는다. 다른 파일이 맨 먼저 import 한다 |
| `nota.py` | 짧은 토큰 표기 → `ScoreEvent` JSON. 마디 길이와 기보 가능한 음길이를 강제 검사 |
| `phr.py` | 프레이즈 응답을 쓰기 **전에** 스팬·음역·손 교차를 검사. 걸리면 파일을 쓰지 않는다 |
| `planner.py` | 설계도를 짧게 쓰고, 쓰기 전에 `check_plan` + 곡 사이 다양성 검사를 돌린다 |
| `score.py` | 파이프라인을 돌리지 않고 응답 파일에서 바로 조립해 음악성 9지표·난이도를 본다 |
| `peek.py` | 비평 프롬프트에서 지표·검증기 경고·실측 텍스처만 꺼내 본다 |
| `deparallel.py` | 병행 5·8도가 난 자리의 왼손 바닥음을 다른 **화음음**으로 바꿔 없앤다 |

## 표기법 (`nota.py`)

```
C4/0.5          한 음, 8분음표
C4+E4+G4/1.0    화음, 4분음표
r/0.5           쉼표
```

접미사: `.` 스타카토 · `>` 액센트 · `=` 테누토 · `^` 마르카토 ·
`(` 슬러 시작 · `)` 슬러 끝 · `~` 타이 시작 · `_` 타이 끝 · `&` 타이 계속

```python
from phr import write
write("g20", "phrase_01_04", [
    ("C5/1.0( D5/1.0 E5/1.0 C5/1.0", "C3+G3/2.0 C3+G3/2.0", {"dynamics": "mf"}),
    ...
], 4.0, 1, span=12)          # 한 마디 4박, 1마디부터 시작
```

## 왜 저장소에 두는가

이 헬퍼 없이 세션 작곡을 하면 마디마다 길이·스팬·음역을 손으로 세게 된다.
20곡을 쓰는 동안 가장 많이 아낀 것이 이것이고, 스크래치 디렉터리에 두면
세션이 끝날 때 함께 사라진다.

## 주의

`deparallel.py` 는 **왼손 반주만** 손댄다. 오른손 선율과 화성은 건드리지 않으므로
안전하지만, 자리바꿈이 음악적으로 최선인지는 사람이 들어 보고 판단해야 한다.
