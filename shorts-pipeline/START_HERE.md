# 여기서부터 — 클릭만으로 쓰는 법

터미널(까만 창)에 명령어를 칠 필요가 없습니다.
**바탕화면 아이콘 두 개**와 **브라우저 화면 하나**면 끝입니다.

---

## 처음 한 번만 (5분)

### 1. 파이썬 설치

https://www.python.org/downloads/ 에서 노란 버튼을 눌러 받고 실행합니다.

> ⚠️ 설치 화면 **맨 아래 [Add python.exe to PATH] 를 꼭 체크**하세요.
> 이걸 놓치면 나중에 "python 을 찾을 수 없습니다" 가 뜹니다.

### 2. ffmpeg 설치

영상을 이어 붙이는 도구입니다. 시작 버튼 옆 검색창에 `powershell` 을 치고 열어서
아래 한 줄을 붙여넣고 엔터:

```
winget install --id Gyan.FFmpeg -e
```

### 3. 프로그램 폴더 준비

받은 zip 을 풀어 `C:\shorts-pipeline` 에 둡니다.
폴더 안에 `main.py` 가 보이면 제대로 된 위치입니다.

### 4. 바로가기 만들기

폴더 안의 **`shortcuts.bat`** 를 더블클릭합니다. 바탕화면에 세 개가 생깁니다.

| 아이콘 | 하는 일 |
|---|---|
| 🔵 **AI DEOKHU 작업실** | 브라우저 관리 화면을 엽니다. 평소엔 이것만 씁니다. |
| 🟡 **AI DEOKHU 업데이트** | 최신 코드를 받습니다. 가끔 눌러주세요. |
| ⚪ **AI DEOKHU 폴더** | 프로그램 폴더를 엽니다. |

세 개 다 채널 로고(네온 터널) 아이콘이 붙습니다. 색으로 구분하세요 —
**하늘색=작업실 · 노란색=업데이트 · 회색=폴더**.

> 아이콘이 안 바뀌고 예전 것으로 보이면 `shortcuts.bat` 를 한 번 더 실행하세요.
> 윈도우가 아이콘을 캐시해 두는 경우가 있습니다.

## 평소 쓰는 법

### **[AI DEOKHU 작업실]** 을 더블클릭

검은 창이 잠깐 뜨고(끄지 마세요), 브라우저에 관리 화면이 열립니다.
처음 실행하면 필요한 것들을 알아서 설치하느라 1~2분 걸립니다.

화면 맨 왼쪽 **[간편 모드]** 탭에는 **지금 눌러야 할 버튼 하나**만 크게 나옵니다.
그것만 따라가면 됩니다.

### 진짜 앱처럼 쓰기 (선택)

브라우저 주소창 오른쪽의 **[앱으로 설치]** 아이콘(⊞ 모양)을 누르면
주소창·탭 없는 **독립 창**으로 뜨고, 작업 표시줄에 AI DEOKHU 아이콘이 박힙니다.

- 엣지: 주소창 오른쪽 **⊞** 또는 `···` → **앱** → **이 사이트를 앱으로 설치**
- 크롬: 주소창 오른쪽 **⊞** 또는 `⋮` → **캐스트, 저장 및 공유** → **페이지를 앱으로 설치**

설치해도 프로그램은 그대로 내 컴퓨터에서 돕니다. 창 모양만 바뀝니다.

### ③ 영상 만들기

**[간편 모드] → [오늘 영상 만들기]**

이미지를 알아서 하나 골라 **끊김 없이 이어지는 30초** 영상을 만듭니다.
5분쯤 걸립니다. 오른쪽에 진행 상황이 뜹니다.

> **10초짜리 클립 3개**로 만듭니다. 5초 6개에서 바꾼 것인데 이유가 둘입니다 —
> 한 장면을 오래 보여줄수록 시청자가 덜 빠져나가고, 지금 쓰는 모델은
> **건당 과금**이라 10초가 5초와 값이 같습니다. 같은 30초인데 **$2.15 → $1.49**.

> 앞 클립의 **마지막 프레임**을 다음 클립의 시작으로 넘겨서 잇습니다.
> 그래서 중간에 원래 자리로 되돌아가지 않습니다.

#### 값을 아끼는 세 가지 버튼

**🔍 먼저 싸게 시험 — 5초 한 클립만**  ($0.25)

본편을 다 만들고 나서 "움직임이 이상하다" 를 알게 되면 $1.47 은 이미
나간 뒤입니다. 먼저 싼 모델로 5초만 뽑아 눈으로 보고, 괜찮을 때만
본편을 만드세요. 세 편에 한 번만 마음에 안 들어도 값이 내려갑니다.

**클립 하나만 다시**  (완성된 영상 아래)

3클립 중 2번만 어긋났을 때 전체를 다시 만들면 멀쩡한 클립 값까지 다시
냅니다. 그 클립부터만 다시 만듭니다. $1.47 → $0.98.

> 이어지는 영상에서 2번을 새로 만들면 3번의 시작 그림이 달라지므로
> 3번도 함께 다시 만듭니다. 그래야 이음매가 안 생깁니다.

**카메라 움직임 고르기**

'앞으로 계속 전진', '뒤에서 따라가기' 처럼 한국어로 고르면 검증된 영어
프롬프트가 채워집니다. 직접 쓰다가 잘못 쓰면 애니메이션이 이상해지고
그 값은 이미 나간 뒤입니다.

> **이미 만든 이미지에는 회색 [이미 만듦] 표시**가 붙습니다. 272장을 눈으로
> 구별할 수 없어서 같은 그림으로 두 번 만드는 일이 실제로 일어납니다.
> 그래도 만들려고 하면 한 번 더 물어봅니다.

## 영상 꾸미기 — 전부 공짜

`config.yaml` 의 `output:` 아래에서 켭니다. **모델을 안 부르니 비용이 0원**
인데 효과는 큽니다.

| 설정 | 무엇 |
|---|---|
| `hook_overlay.enabled: true` | 앞 2초에 훅 문구를 큰 한글로. **첫 3초에 이탈이 결정됩니다** |
| `seamless_loop.enabled: true` | 끝을 첫 장면으로 이어 반복 재생이 안 튐 |
| `look.grade: cinema` | 일정한 색보정 (`warm`/`cool`/`cinema`) |
| `look.logo: 경로.png` | 오른쪽 위에 로고 |

성적표에 **훅 자막을 넣은 편과 안 넣은 편의 평균 조회수**가 따로 나오니,
정말 효과가 있는지 직접 확인하실 수 있습니다.

> **인스타 토큰은 60일이면 만료됩니다.** 만료되면 인스타 업로드만 조용히
> 실패합니다. 남은 날짜가 14일 아래로 내려가면 대시보드에 경고가 뜨고,
> [설정] → **[🔄 토큰 60일 연장]** 한 번이면 됩니다.
> **만료된 뒤에는 연장이 안 되고 새로 발급해야 합니다.**

## 제목을 AI 가 짓게 하기 (선택 · 무료)

안 해도 됩니다. 지금도 이미지 프롬프트에서 제목을 자동으로 뽑습니다.
더 나은 제목을 원하면 **무료 키 하나**만 넣으면 됩니다.

1. [openrouter.ai](https://openrouter.ai) 가입 (카드 등록 없음)
2. **Keys** → **Create Key** → 복사
3. 작업실 **[설정] 탭 → 제목 자동 작성** 칸에 붙여넣기

그러면 두 곳에서 쓰입니다.

| 어디 | 언제 |
|---|---|
| **[1 · 이미지 고르기]** 의 `✨ AI로 제목 3개 뽑기` | 누를 때만. 3개 중에서 고릅니다 |
| **[간편 모드]** 의 `오늘 영상 만들기` | 영상마다 자동으로 한 번 |

**무료 한도는 하루 50회**입니다. 영상 한 편에 1회를 쓰므로 넉넉합니다
(프로그램은 40회에서 스스로 멈춥니다).

> 쓸 모델은 **자동으로 고릅니다.** OpenRouter 의 무료 모델은 수시로
> 없어지기 때문에, 부를 때마다 살아 있는 것 중에서 고르게 해 놓았습니다.
> `OPENROUTER_MODEL` 칸은 비워두세요.

**키가 없거나, 인터넷이 끊겼거나, 한도를 다 썼으면** 지금까지처럼 규칙으로
제목을 짓습니다. 영상 만들기가 이것 때문에 멈추는 일은 없습니다.

## 유튜브 · 인스타 연결

**[설정] 탭**에서 전부 됩니다. 터미널 없이.

### 유튜브

1. [YouTube Data API v3 사용 설정](https://console.cloud.google.com/apis/library/youtube.googleapis.com)
2. [사용자 인증 정보](https://console.cloud.google.com/apis/credentials) →
   **OAuth 클라이언트 ID → 데스크톱 앱** 으로 만들고 JSON 내려받기
3. 그 파일을 [설정] 탭의 상자에 **끌어다 놓기**
4. **[유튜브 연결하기]** → 열리는 창에서 채널 계정으로 로그인

한 번 하면 끝입니다. 다음부터는 자동으로 올라갑니다.

> 처음엔 **비공개**로 올라갑니다. 확인하고 직접 공개로 바꾸세요.
> 바로 공개하려면 `config.yaml` 의 `publish.youtube.privacy` 를 `public` 으로.

### 인스타그램

프로페셔널(비즈니스) 계정이어야 하고, 페이스북 페이지가 연결돼 있어야 합니다.

1. [그래프 API 탐색기](https://developers.facebook.com/tools/explorer/) 에서
   `IG_USER_ID`(숫자)와 장기 액세스 토큰을 받습니다
2. [설정] 탭의 **인스타그램 연결** 칸에 넣고 **[인스타 확인하기]**
3. 계정 이름이 뜨면 성공입니다

> 인스타는 로컬 파일을 못 받고 **공개 URL** 만 받습니다.
> 그래서 [설정] 탭의 **영상 보관함**(Cloudflare R2) 도 채워야 합니다.
> R2 무료 티어면 보관 10GB · 이그레스 무료라 **월 $0** 입니다.
