# 비용 분석 및 운영 시나리오

2026-08 기준 단가. 모든 수치는 `python main.py estimate --compare` 로
재현할 수 있고, 단가가 바뀌면 config.yaml 만 고치면 된다.

---

## 1. 먼저 알아야 할 것 — 재시도 계수

**계획한 클립 수 = 실제 API 호출 수가 아니다.**

레퍼런스 수준의 결과물이 나오려면:
- 모델이 프롬프트를 무시하거나 카메라가 멈추는 경우 (재생성)
- 4~5회차부터 풍경이 무너지는 경우 (해당 지점부터 재시작)
- 얼굴/손 붕괴, 워터마크 환각 (리젝)

실무 기준 **1.6~2.2배**. config 기본값은 `retry_multiplier: 1.8` 이다.
아래 "실질" 컬럼은 전부 이 배수가 적용된 값이다.

> 이 계수를 빼고 계산한 견적은 현실에서 반드시 틀린다. 첨부 영상 같은
> 결과물을 뽑으려면 **버리는 클립 값까지 예산에 넣어야 한다.**

## 4. 운영 시나리오 3안

### A안 — 검증용 (첫 달)
> 포맷이 먹히는지부터 확인한다. 돈을 크게 쓰기 전 단계.

- Higgsfield PLUS 연간 **$39/월**
- 25초 x 주 4편 = 월 16~18편
- 유튜브 쇼츠 + 인스타 릴스 동시 게시
- **월 $39** (편당 약 $2.2)

`config.yaml`:
```yaml
mode: montage          # 열화가 없어 실패율이 낮다
provider: higgsfield
model: kling3_0_turbo
clip_duration: 5
num_clips: 5           # 25초
upscale_between_clips: false
```

### B안 — 본격 운영 (권장)
> 레퍼런스 계정들의 실제 게시 빈도에 근접한다.

- Higgsfield ULTRA 연간 **$99/월** (55편) + fal 종량제 보충
- 하루 2편 = 월 60편 → 55편은 구독, 5편은 fal wan_25_480p ($12)
- chain 과 montage 를 섞어 채널 피로도를 낮춘다
- **월 약 $111** (편당 약 $1.85)

```yaml
mode: chain
provider: higgsfield
model: kling3_0_turbo
clip_duration: 5
num_clips: 6           # 30초
upscale_between_clips: true
loop_back: false
cost:
  retry_multiplier: 1.8
  hard_cap_usd: 8.0    # 편당 상한
```

### C안 — 물량 공세
> @hellopersonality 의 게시물 8,081개를 겨냥한다면.

- Higgsfield ULTRA 연간 $99 + fal 종량제 대량
- 하루 5편 = 월 150편
- 55편 구독분 + 95편 fal wan_25_480p ($220)
- **월 약 $319** (편당 약 $2.13)
- 여기서부터는 계정을 2~3개로 나눠 업로드 한도를 분산해야 한다

## 5. 첨부 영상 수준을 내려면 실제로 얼마가 드나

첨부된 "Infinite peace part 16" (25초, 5장면, 애니메이션 톤)을
그대로 재현한다고 가정하면:

| 항목 | 수량 | 단가 | 금액 |
|---|---:|---:|---:|
| 시드 이미지 생성 (Seedream/Nano Banana) | 5장 x 2회 시도 | $0.04 | $0.40 |
| 영상 클립 (Kling 3.0 Turbo, 5초) | 5개 x 1.8 | $0.198 | $1.78 |
| 음원 (Artlist/Epidemic 구독 분할) | 1곡 | — | $0.30 |
| **합계** | | | **약 $2.48** |

여기에 사람 손이 들어간다: 장면 선별, 컷 순서 결정, 음악 싱크.
**자동화로 대체 가능한 부분이 위 $2.48 이고, 남는 건 "어떤 장면을
고를 것인가" 하나다.**

@odysseyml 스타일 연속 전진 60초는 체이닝 열화 때문에 재시도가 더 붙는다.
현실적으로 **편당 $6~9**, 만족스러운 한 편을 얻기까지 2~3회 실행하면
**$15~25** 을 봐야 한다. `--interactive` 로 4회차에서 끊고 다시 시작하는
운용이 총비용을 가장 크게 줄인다.

## 6. 숨은 비용

| 항목 | 비용 | 비고 |
|---|---|---|
| 음원 라이선스 | $10~25/월 | Artlist, Epidemic Sound. **상업 채널이면 필수** |
| 저장/호스팅 | $1~5/월 | 인스타 API 가 공개 URL 을 요구한다 (S3/R2) |
| 시드 이미지 생성 | $0.03~0.05/장 | montage 모드에서만 |
| 업스케일 | $0.01~0.10/장 | chain 모드 열화 방지 |

**인스타그램은 로컬 파일 업로드를 지원하지 않는다.** 반드시 공개 URL 이
필요하므로 S3/Cloudflare R2 같은 스토리지가 사실상 필수 비용이다.

## 8. 비용을 줄이는 실전 수칙

1. **montage 를 기본으로 쓴다.** 장면이 독립적이라 열화 재시도가 없다.
   chain 은 재시도 계수가 2.2까지 오른다.
2. **`--interactive` 로 4회차에서 끊는다.** 붕괴된 프레임으로 5·6회차를
   돌리는 게 가장 큰 낭비다.
3. **`--no-upscale` 을 먼저 시험한다.** montage 모드에서는 효과가 없다.
4. **480p 로 뽑고 로컬에서 업스케일한다.** wan_25_480p 는 720p 의 절반이다.
5. **`estimate --compare` 를 습관화한다.** API 를 부르기 전에 항상 확인.
6. **실패한 실행도 과금된다.** `resume` 으로 이어하면 이미 만든 클립을
   재사용하므로 다시 만들지 않는다.
