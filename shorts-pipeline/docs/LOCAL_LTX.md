# 내 PC 로 만들기 (LTX-2.5) + 매일 아침 자동 업로드

영상 한 편에 드는 돈을 **$0** 으로 만드는 방법입니다. 대신 내 PC 의 그래픽카드가 일합니다.

## 1. 내 PC 가 되는지

| 그래픽카드 메모리 (VRAM) | 어떻게 도나 |
|---|---|
| 32GB 이상 (RTX 5090 등) | 빠름 |
| 16~24GB (RTX 4090 / 4080 등) | 돕니다. 대신 모델을 시스템 메모리에 두고 조금씩 나눠 돌려서 **느립니다**. 시스템 메모리가 **40GB 이상**이어야 하고 64GB 를 권장합니다 |
| **15GB 미만 (8GB·12GB 카드)** | **내 PC 로는 안 됩니다.** Lightricks 가 만든 LTX Desktop 앱도 이 크기에서는 내 PC 가 아니라 **클라우드(LTX API, 유료)** 로 만듭니다. 작업실도 이 경우 엔진을 바꾸지 않고, 설치 스크립트도 70GB 를 받기 전에 멈춥니다 |

- **NVIDIA 그래픽카드**가 있어야 합니다 (AMD·인텔은 LTX 가 안 돕니다).
- 디스크 여유 **100GB** (모델이 약 66GB).
- 이 수치는 Lightricks 가 LTX-2 소스에 적어 둔 값입니다
  (모델 전부를 그래픽카드에: 약 28GB / 시스템 메모리로 나눠서: RAM 약 36GB + VRAM 약 5GB).

작업실이 알아서 두 메모리를 보고 설정을 고릅니다. 직접 만질 필요는 없습니다.

## 2. 설치 (한 번만)

1. `tools` 폴더의 **`ltx_setup.bat`** 을 더블클릭
2. 허깅페이스 페이지가 열리면 로그인 → **약관 동의(Agree)**
3. https://huggingface.co/settings/tokens → **Create new token → Read** → 만든 `hf_...` 를 검은 창에 붙여넣기
   (토큰은 그 창에서만 쓰고 어디에도 저장하지 않습니다)
4. 끝날 때까지 기다리기. 인터넷 속도에 따라 30분~몇 시간. 끊기면 다시 더블클릭 — 이어서 받습니다
5. 마지막에 Real-ESRGAN(한 번 더 업스케일)을 받을지 물으면 **Y**

## 3. 엔진 바꾸기

작업실 → **[자동 업로드]** 탭 → **영상 엔진** → **내 PC (LTX-2.5 · 무료)**

설치가 덜 됐으면 바뀌지 않고 무엇이 빠졌는지 알려줍니다.
처음 한 편은 **[싸게 먼저 시험하기]** 로 5초만 뽑아 보세요. 내 PC 에서는 이것도 $0 입니다.

## 4. 업스케일은 이렇게 들어갑니다

1. **LTX 안에서** — 절반 크기로 움직임을 잡고, LTX 전용 업스케일러로 2배 키워 다듬습니다 (576x1024)
2. **Real-ESRGAN** — 설치돼 있으면 클립마다 한 번 더 키웁니다
3. **합성할 때** — 유튜브·인스타 기준인 1080x1920 으로 맞춥니다 (lanczos)

## 5. 매일 아침 9시 자동 업로드

**[자동 업로드]** 탭 → 게시 시각 **오전 9시** → 유튜브·인스타 체크 → **[예약 저장]**

- 내 PC 엔진이면 **07:00** 에 시작합니다 (만드는 데 오래 걸려서 두 시간 먼저). 클라우드면 08:30.
- **PC 는 끄지 말고 절전으로 두세요.** 절전이면 그 시각에 깨워서 돌리고, 꺼져 있었으면 켜지는 대로 바로 돕니다.
- 창이 뜨지 않습니다. 결과는 같은 화면의 **마지막 실행** 칸에 사람 말로 나옵니다.
- **[지금 한 번 돌려보기]** 는 아침에 도는 것과 똑같은 경로로 지금 한 번 돌립니다. 예약이 되는지 미리 확인할 때 쓰세요.

### 예전에 예약이 안 돌던 이유

한국어 윈도우에서 예약 실행의 출력은 cp949 로 저장되는데, 로그 첫 줄의 `—` 가 cp949 에 없어서
**영상을 만들기도 전에, 기록 한 줄 남기기도 전에** 멈췄습니다. 작업실에서 누르면 멀쩡했던 것은
작업실이 UTF-8 을 따로 넣어주고 있었기 때문입니다. 지금은 어디서 실행되든 UTF-8 로 돕니다.

업데이트 후 작업실을 한 번 켜면(또는 `update.bat` 이 끝날 때) 예전 방식으로 걸린 예약을 새 방식으로 다시 겁니다.
