# 레퍼런스 정밀 분석

첨부된 스크린샷 5장과 화면녹화 4개를 ffprobe/ffmpeg 로 실측한 결과다.
config.yaml 의 기본값은 전부 이 문서의 수치에서 나왔다.

- 중앙값 약 **130만**, 최고 **2437만**
- 하위권도 15만~20만 — **하한이 존재한다.** 포맷 자체가 일정 수준을 보장한다
- 상위 2편이 전체 조회수의 상당 부분 — **물량으로 대박을 노리는 구조**

올리는 쪽**이 기대값이 높다. 스케줄링과 배치 생성이 핵심 기능인 이유다.

## 3. 영상 실측

첨부 영상은 모두 1080x2520 화면녹화(21:9 폰)이며, 그 안의 릴스가 9:16 이다.

| 파일 | 길이 | fps | 내용 |
|---|---|---|---|
| 7698c163 | 25.5초 | 60 | cyborg.digitalart "Infinite peace part 16" |
| 2f911788 | 38.8초 | 60 | nexyra.visuals 외 |
| 0f9c2f65 | 60.8초 | 60 | lunovia.ai / caelum.waves |
| f0d1b7b3 | 63.9초 | 120 | cyborg.digitalart 프로필 탐색 |

릴스 탭에 표시된 개별 영상 길이: **00:16, 00:23, 00:28**

> **60초가 아니라 16~28초가 주력이다.** 지시서 기본값 60초(6x10초)는
> 레퍼런스보다 길다. config 기본값을 6클립 x 5초 = 30초로 낮춘 근거다.

### 장면 전환 실측 — "Infinite peace part 16"

인스타그램 UI 를 크롭하고 scene threshold 0.12 로 검출:

```
0.648  5.678  10.674  14.4  19.599  23.595   (초)
   └5.03┘ └4.996┘ └3.93┘ └5.00┘ └4.00┘
```

**장면 길이가 5초로 딱 떨어진다.** 이것이 `clip_duration: 5` 의 근거다.
5초는 Kling/Hailuo 계열의 기본 생성 단위이기도 하다.

마지막 장면은 첫 장면과 같은 장소(주유소)로 돌아온다. 첫/끝 프레임
SSIM 은 0.21 로 픽셀 단위 루프는 아니지만, **의도적인 원형 구성**이다.
반복 재생을 유도해 조회수를 끌어올리는 장치다 → `loop_back` 옵션.

### 컷 검출 — 연속 전진형

임계값 0.30 에서 검출된 컷이 영상 하나당 0~3개뿐이다. 그마저도 대부분
화면녹화가 다음 릴스로 넘어가는 지점이다.

**즉 본편 안에는 하드 컷이 사실상 없다.** 라스트 프레임 체이닝 + 크로스페이드로
이음매를 지우는 방식이 맞다는 확인이다.

## 4. 두 가지 포맷 → 두 가지 모드

분석 결과 레퍼런스는 하나의 포맷이 아니라 **둘**이었다.

### chain — 끊기지 않는 전진
@odysseyml, @hellopersonality, @lunovia.ai

- 카메라가 계속 앞으로 나아간다. 컷 없음
- 라스트 프레임 체이닝으로 구현
- 클립 경계에 0.3초 크로스페이드
- 회차가 쌓일수록 화질이 열화되므로 업스케일 필수
- **4~5회차부터 풍경이 무너진다** → `--interactive` 체크포인트가 필요한 이유

@hellopersonality 그리드에서 확인된 소재: 절벽 계곡 비행, 야간 드라이브 POV,
숲 자전거 POV, 조종석 POV, 야간 거리 자전거, 해안 항공샷.
**전부 1인칭 전진 시점이다.**

### montage — 장면 몽타주 후 회귀
@cyborg.digitalart "Infinite peace part N"

- 독립 장면 5~6개, 각 5초, 하드 컷
- 장면마다 시드 이미지가 따로 → **화질 열화가 누적되지 않는다**
- 마지막에 첫 장면으로 회귀
- `part 16` 이라는 제목 = **시리즈 연재**. 팔로워 재방문을 만드는 장치

두 모드 모두 구현했다. montage 는 열화가 없어 안정적이고, chain 은
"어떻게 찍었지?" 하는 몰입감이 강하다.

## 5. 프로그램에 반영한 항목

| 관찰 | 반영 |
|---|---|
| 장면 5초 실측 | `clip_duration: 5` |
| 주력 16~28초 | `num_clips: 6` (기본 30초) |
| 하드 컷 거의 없음 | chain 모드 + 0.3초 크로스페이드 |
| 5초 컷 몽타주 | montage 모드 + `montage_transition: cut` |
| 첫 장면 회귀 | `loop_back` 옵션 |
| "part N" 연재 | 제목 템플릿에 회차 삽입 가능 |
| bio 의 Higgsfield | higgsfield provider 구현 |
| 게시물 8,081개 | 배치 생성 + 스케줄 업로드 |
| 4~5회차 붕괴 | `--interactive` 체크포인트, 리셋 기능 |
| 조회수 하한 존재 | 편당 완성도보다 물량 — 비용 최적화 우선 |
