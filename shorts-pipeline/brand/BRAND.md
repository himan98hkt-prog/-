## 4. 영상 문구 템플릿

### 제목
연재형이 재방문을 만든다. 레퍼런스 @cyborg.digitalart 가 "part 16" 까지 끌고 간 방식.

```
{장면 한 줄} | AI DEOKHU #Shorts
끝나지 않는 여행 part {N} #Shorts
```

예시:
- `비 내리는 네온 골목을 끝없이 달리다 | AI DEOKHU #Shorts`
- `끝나지 않는 여행 part 17 #Shorts`

```
{한 줄 설명}

```

- `여긴 존재하지 않는 곳입니다`

## 6. 적용 순서

### 유튜브 (studio.youtube.com)
1. **맞춤설정 → 프로필** — 사진에 `youtube_avatar_800.png`, 배너에 `youtube_banner_2048x1152.png`
2. 같은 화면에서 이름을 `AI DEOKHU`, 설명을 위 문구로
3. 핸들을 `@aideokhu` 로
4. 오른쪽 위 **게시** 클릭 — 누르지 않으면 아무것도 저장되지 않는다
5. **설정 → 채널 → 기본정보** 에서 키워드 입력

### 인스타그램
1. 프로필 편집 → 사진에 `instagram_avatar_1080.png`
2. 이름 · 소개 · 링크를 위 문구로
3. 프로페셔널 계정인지 확인 (API 업로드에 필요)
