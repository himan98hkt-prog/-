# 감동영상 설명용 예시 사진 — AI 로 만든 것입니다

여기 있는 사진은 **AI 로 만든 예시**입니다. 실제 아이가 아닙니다.

## 왜 두었나

상세페이지·카드뉴스에 「감동영상이 이렇게 나옵니다」를 보여 주려면 **아이 사진이 든
화면**이 있어야 합니다. 빈 양식만 찍어 올리면 설득이 되지 않고, 그렇다고 실제 원생의
사진을 파는 자리에 올릴 수는 없습니다. 그래서 AI 로 만든 얼굴을 씁니다.

## 어디에 쓰이나

`npm run shots:video` 가 이 폴더를 읽어 감동영상 화면을 찍습니다.

- `이름.jpg` … 아이 한 명씩 나오는 장면에 붙습니다 (파일 이름이 곧 아이 이름)
- `연습/NN 설명.jpg` … 「이 무대까지 오는 동안」 묶음이 됩니다.
  파일 이름 앞의 번호가 순서이고, 뒤의 글이 **화면에 뜨는 자막**이 됩니다.

찍힌 화면은 `promo/video/` 에 나오고, `detail/assets/` 로 옮겨 상세페이지와
카드뉴스에 들어갑니다.

## 하지 말 것

- **상품에 딸려 가는 `배포/연습용-사진/` 에 넣지 마십시오.** 그 자리는 원장님이
  사진 없이도 화면을 둘러보실 수 있게 두는 그림 자리이고, 사람 얼굴이 들어가면
  원생 사진으로 오해받습니다.
- 설치본에도 들어가지 않습니다 (`electron-builder.yml` 의 `files` 가
  `desktop/app` 만 싣습니다).
- 상세페이지·카드뉴스에서는 **「AI로 만든 예시 사진이며 실제 아이가 아닙니다」**
  를 반드시 함께 적습니다. 적어 두는 자리는 `scripts/build-detail.py` 의
  `gal-note` 와 `scripts/make-carousel.mjs` 의 12번 카드입니다.
