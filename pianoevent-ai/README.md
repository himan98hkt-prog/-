# PianoEvent AI

피아노학원 **정기 연주회 · 시즌 특강 올인원 기획** 도구.
학생 명단 하나로 연주 순서표 → 사회자 대본 → 모바일 초대장 → 참석 집계까지 한 번에 만듭니다.

> **처음이신가요?** 명령어를 칠 필요 없습니다. 배포 묶음의 `시작하기.bat`(맥은 `시작하기-맥용.command`)을
> 두 번 클릭하면 Node.js 설치·준비 작업·브라우저 열기까지 알아서 합니다. → [docs/LOCAL.md](docs/LOCAL.md)
>
> **판매를 고민 중이라면** 설치형으로 팔면 안 되는 이유와 대안을 [docs/SELLING.md](docs/SELLING.md) 에,
> 서비스 범위(악보는 제공하지 않습니다)와 경쟁 제품 비교를 [docs/SCOPE.md](docs/SCOPE.md) 에 정리했습니다.

```bash
npm install
npm run dev      # http://localhost:3000  (환경변수 없이 바로 전 기능 동작)
npm run reset    # 데모 데이터를 처음 상태로 되돌리기
npm run mobile   # 같은 와이파이의 휴대폰에서 열기 (주소 + QR 코드 표시)
npm run pack     # 배포용 ZIP 만들기 (실행기가 맨 위에 오도록 구성)
npm run carousel # 상품 캐러셀 15장 (1080×1080 PNG)
npm test         # 순수 로직 단위 테스트 231건
npm run build && npm run smoke   # 실제 서버를 띄워 원장 작업 흐름 145건 검증
npm run verify:stage             # 무대 화면 넘침 · 테마 전환 · PDF · 파워포인트 파일 검사
npm run verify:video             # 감동영상을 실제로 만들어 재생되는 파일인지 확인
```

> **인터넷도 AI 키도 없이 전부 동작합니다.** 인터넷이 필요한 건 학부모가 초대장 링크를 여는 것 하나뿐입니다.
> → [docs/OFFLINE.md](docs/OFFLINE.md)
>
> 환경변수를 하나도 설정하지 않아도 됩니다. Supabase 가 없으면 로컬 데모 저장소로, Gemini 키가 없으면
> 내장 규칙 엔진으로 자동 전환되어 **모든 화면이 그대로 동작**합니다.

## 1. 무엇이 자동으로 되는가

| 원장이 하던 일 | 이 도구에서 |
|---|---|
| 엑셀로 순서를 짜고 러닝타임을 손으로 계산 | 명단 붙여넣기 → **오프닝·초급·중급·앙상블·피날레 자동 배치 + 종료 시각 계산** |
| 곡 해설과 학생 소개 멘트를 밤새 작성 | 곡·작곡가·학생 특징을 엮은 **사회자 대본 곡별 자동 생성** |
| 순서표를 워드로 다시 옮겨 인쇄 | **A4 인쇄용 순서표** (브라우저 인쇄 → PDF 저장) |
| 초대장 이미지를 만들어 단톡방에 배포 | **모바일 초대장 링크 `/e/{id}`** + 카카오톡 공유 + 참석 회신 |
| 참석 인원을 카톡 답장으로 세기 | **실시간 참석 집계** (가정 수·총 인원·응원 메시지) |
| 시즌 특강 자료를 사서 짜깁기 | 테마 선택 → **주차별 계획서 + 인쇄용 활동지** 한 번에 |
| 곡마다 작곡가·연주시간을 찾아 적기 | **곡 사전 78곡** — 곡 제목만 적으면 작곡가·난이도·시간·해설이 따라 들어옴 |
| 자동 배치가 마음에 안 들면 손으로 다시 | **순서 직접 조정** — 위·아래 버튼으로 옮기면 시각과 인쇄물 40종이 함께 바뀜 |
| 매 행사마다 학생 12~30명을 다시 입력 | **지난 행사에서 명단 가져오기** — 이름·난이도는 그대로, 곡만 채우기 |
| 인쇄물마다 사진 주소를 다시 찾기 | **이미지 보관함** — 끌어다 놓으면 자동 축소, 인쇄물마다 클릭 한 번으로 적용 |
| 연주회장 스크린용 파워포인트를 해마다 다시 제작 | **무대 화면** — 명단에서 16:9 슬라이드 자동 생성, 전체화면 진행 · **.pptx** · PDF |
| 아이 사진을 슬라이드마다 붙여 넣기 | **아이 사진** — 명단에 한 번, 무대 화면·PPT·영상에 함께. 파일 이름으로 한꺼번에 짝짓기 |
| 무비메이커로 사진을 한 장씩 끌어다 감동영상 제작 | **감동영상** — 명단·사진에서 장면을 짜고 브라우저 안에서 MP4 로 뽑음 |

### 인쇄물 디자인 (`lib/design/`)

행사마다 필요한 종이가 다릅니다. 포스터 한 장으로 끝나지 않고 순서지·입장권·이름표·상장까지 이어집니다.
**테마 100종 × 양식 40종**을 조합해 쓰며, 하나의 테마를 고르면 모든 인쇄물이 같은 색과 서체를 입습니다.

테마는 성격으로 묶여 있고 이름으로 검색되므로 100종을 다 훑지 않아도 됩니다.
행사 달에 맞는 계절 테마를 먼저 보여 줍니다.

| 성격 | 종수 | 이런 자리에 |
|---|---|---|
| 고급 · 클래식 | 32 | 정기 연주회, 콩쿠르 입상 발표, 예고 입시 준비반 |
| 사랑스러운 | 20 | 유아·초등 저학년 발표회, 어머니 초청 연주 |
| 계절 · 시즌 | 26 | 봄·여름·가을·겨울, 크리스마스, 할로윈, 졸업·수료 |
| 모던 · 편집 | 14 | 사진을 크게 쓰는 포스터, SNS 홍보 |
| 아이들 · 활기 | 8 | 놀이형 특강, 저학년 시즌 발표회 |

색은 눈대중으로 고르지 않습니다. 100종 전부가 자동 검사를 통과해야 들어갑니다 — 본문 대비 7:1,
보조 글씨 3:1, 강조색 3:1, 제목 밴드 4.5:1 (`tests/design.test.ts`, `scripts/check-contrast.mjs`).

양식 40종은 다섯 갈래입니다.

| 갈래 | 양식 |
|---|---|
| 포스터 | 클래식 · 모던 · 사진 · 전면 사진 · 포스터+출연진 · **타이포** · **사진 2단** |
| 프로그램 | 표지 · 순서지 · 반접지 · **곡 해설 순서지** · **3단 접지** |
| 초대 · 홍보 | 입장권 3매 · SNS 카드 · **초대장 카드 2매** · **SNS 세로 스토리** · **X배너 시안** |
| 행사 당일 | 감사 카드 · 참가 상장 · 좌석 이름표 · **좌석 배치도** · **대기 순서판** · **포토존 보드** · **시상 명단** |
| 진행 문서 | 당일 진행표 · 준비 체크리스트 · **사회자 대본** · **리허설 시간표** · **접수 확인표** · **예산·정산표** · **학부모 안내문** · **학생 준비 안내문** |

**한 벌 인쇄** 다섯 묶음(관객용 · 당일 운영 · 안내문 · 사회자 · 접수처)으로 여러 장을 한 번에 뽑습니다.

### 감동영상 (`lib/video/`, `components/video/`)

연주회 전에 스크린에 틀거나 끝난 뒤 학부모에게 보내는 짧은 영상입니다.

- `storyboard.ts` — 명단·사진·추가 자료에서 **장면을 짠다** (순수 함수). 표지 → 연습 사진 →
  동영상 → 아이별 → 마무리. 15분이 넘으면 아이를 빼는 대신 **장면 시간을 줄여** 맞춘다
- `render.ts` — 한 프레임을 캔버스에 그린다. 켄 번스(천천히 확대)와 **겹쳐 넘기기**.
  미리보기와 실제로 뽑는 영상이 같은 함수를 쓴다
- 뽑기는 **브라우저 안에서** 한다 (`canvas.captureStream` + `MediaRecorder` + WebAudio).
  ffmpeg 도, 서버도, 업로드도 없다 — 아이들 사진이 컴퓨터 밖으로 나가지 않는다
- 형식은 **H.264 MP4 를 먼저** 고르고(파워포인트·카톡 가능), 안 되면 WebM 으로 내리며
  **무엇으로 만들어졌는지 화면에 그대로 적는다**
- **원장님이 직접 고친다** — 콘티에서 장면을 눌러 문구·순서·머무는 시간·글자 자리를 바꾼다.
  자동으로 짠 것은 시작점일 뿐이고, 고치지 않은 장면만 자동 쪽을 따라간다
- **차례는 파일 이름으로** — `01 입장.jpg` `02 리허설.jpg` 처럼 번호를 붙여 한꺼번에 고르면
  그 차례대로 들어간다 (브라우저가 파일을 넘겨주는 차례는 믿을 수 없다)
- **만들기 전에 전체가 보인다** — 장면마다 `renderFrame` 으로 실제 화면을 구워 콘티로 깐다.
  설명이 아니라 나올 그림 그대로다. 사진이 없는 장면은 `사진 없음` 으로 표시하고,
  누르면 그 장면으로 건너뛴다. 몇 분 기다릴 일을 마음 놓고 누르게 하는 장치다
- 넘어갈 때 **자막은 겹치지 않는다** — 그림만 겹쳐 넘기고 자막은 전환이 끝난 뒤 떠오른다.
  두 아이 이름이 함께 읽히면 잘못 찍힌 것처럼 보인다. 장면이 짧으면 겹치는 시간도 줄인다
- 한계도 숨기지 않는다: 화면을 그리면서 담으므로 **실제 길이만큼 시간이 걸리고**(누르기 전에
  "만드는 데 약 ○분"을 적어 둔다), 만드는 동안 창을 그대로 두어야 한다
- `scripts/verify-video.mjs` 가 브라우저를 띄워 **실제로 영상을 만들고**, 나온 파일이
  진짜 MP4/WebM 인지 바이트로 확인한 뒤 ffmpeg 로 한 장면을 풀어 본다

### 무대 화면 (`lib/stage/deck.ts`, `components/stage/`)

연주회장 스크린에 띄우는 16:9 슬라이드입니다. 원장이 해마다 다시 만들던 파워포인트를 대신합니다.

- 순서표에서 슬라이드를 **계산**합니다 — 대기 화면 · 오늘의 순서 · 부 전환 · 연주자별 · 휴식 · 폐회
- 순서를 바꾸면 슬라이드도 함께 바뀝니다. 손으로 옮길 것이 없습니다
- 인쇄물과 **같은 테마**를 씁니다. 포스터 · 순서지 · 스크린의 색과 서체가 어긋나지 않습니다
- **연주자 화면 모양 7종** (`lib/stage/layouts.ts`). 공연장에서 늘 문제였던 두 가지를 규칙으로 박았다 —
  **사진은 화면을 꽉 채우고**(둘레에 빈 자리를 남기지 않는다), **글자는 위쪽이나 오른쪽에만**
  놓는다(아래 24% 는 그랜드피아노 뚜껑이 가린다). `verify-stage` 가 모양마다 글자의 최하단과
  사진이 차지하는 넓이를 실제로 재서 이 두 규칙을 지키는지 확인한다
- **아이 사진**은 `.pptx` 에도 실제 그림(`ppt/media/`)으로 들어가고, `srcRect` 로 자리에 맞춰
  **잘라 넣어** 여백을 남기지 않는다. 사진이 없는 아이는 글자 모양으로 자동으로 내려간다
- 화면에서 **테마 100종**을 바로 바꾸고, 곡 해설·오늘의 순서·부 전환·아이 사진을 켜고 끕니다 (`components/design/theme-picker.tsx` 를 인쇄물 화면과 공유)
- 화살표 · 스페이스 · 클릭으로 넘기고 프레젠터(리모컨)도 그대로. **어두운 화면** 전환 지원
- **파워포인트(.pptx)로 받기** — `lib/stage/pptx.ts` 가 OOXML 을 짜고 `lib/stage/zip.ts` 가 묶습니다.
  **외부 라이브러리 없이** 서버에서 만들며, 슬라이드가 그림이 아니라 **글상자**라 파워포인트에서 바로 고칠 수 있습니다.
  글꼴은 윈도우에 늘 있는 바탕·맑은 고딕·궁서로 치환해 깨지지 않게 합니다
- **PDF로 저장**하면 16:9 슬라이드가 한 파일로 나옵니다 (`@page size: 1280px 720px`)
- `scripts/verify-stage.mjs` 가 슬라이드를 한 장씩 띄워 **화면 밖으로 넘친 요소가 없는지**,
  테마를 바꾸면 색이 실제로 바뀌는지, 뽑은 PDF 의 용지 비율·쪽수가 맞는지 확인하고,
  만들어진 `.pptx` 를 **리브레오피스로 실제로 열어** 글자가 그려지는지까지 봅니다
  (리브레오피스가 없으면 그 검사만 건너뜁니다)

### 원장이 손으로 하던 계산 (`lib/ops/`, `lib/program/diagnose.ts`)

| 원장이 하던 일 | 이 도구에서 |
|---|---|
| 당일 아침 30명 리허설 시각을 손으로 계산 | **조 단위 소집 시간표 자동 계산** — 조별 소집 문자까지 만들어 복사 |
| 참가비를 얼마 받을지 대관료 확정 전에 감으로 결정 | **항목별 예산표 → 1인당 원가 → 권장 참가비** 역산, 안내 문구 포함 |
| 참석 회신을 보며 좌석을 손으로 배정 | **가정 단위 좌석 배치** — 연주자석 확보, 여유석 계산, "3열 4~6번" 표기 |
| 순서표를 눈으로 훑으며 문제를 찾기 | **정밀 진단** — 곡 중복, 형제자매 분리, 어린 학생 후반 배치, 같은 작곡가 연속, 휴식 없는 장시간, 빈 멘트를 등급별로 |

## 2. 구조

```
app/
  page.tsx                        홈 · 진행 중인 행사
  events/                         행사 목록 · 생성 · 상세(명단/순서표 탭)
  events/[id]/program/print/      A4 인쇄용 순서표
  events/[id]/script/             사회자 대본 (전체 복사 · 인쇄)
  events/[id]/design/             인쇄물 디자인 스튜디오 (양식·테마·문구 선택 + 미리보기)
  events/[id]/design/print/       고른 양식을 실제 용지 크기로 인쇄
  events/[id]/stage/              무대 화면 — 연주회장 스크린용 16:9 슬라이드
  events/[id]/video/              감동영상 — 사진·동영상·음악을 한 편으로
    api/events/[id]/pptx/         무대 화면을 파워포인트(.pptx) 파일로 내려받기
  events/[id]/invite/             초대장 공유 + 참석 집계 + 미리보기
  e/[id]/                         공개 모바일 초대장 (로그인 불필요)
  seasons/                        시즌 특강 팩 (계획서 + 활동지 인쇄)
  settings/                       학원 정보 · 연결 상태 · 계정 삭제
  privacy/                        개인정보처리방침 (Play Console 등록용 URL)
  api/
    generate-program/             무상태 순서표 API (개발 지시서 Step 2 형태)
    events/[id]/program/          순서표 생성 + DB 확정 저장
```

## 3. 설정

`.env.example` 을 `.env.local` 로 복사해 필요한 값만 채웁니다.

| 변수 | 없을 때 동작 |
|---|---|
| `GEMINI_API_KEY` | 내장 규칙 엔진으로 순서표·대본 생성 (품질은 낮지만 항상 동작) |
| `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` | `.data/store.json` 로컬 데모 저장소 사용 |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | 링크 복사 · 기기 공유 시트로 대체 |
| `NEXT_PUBLIC_OPERATOR_NAME` / `NEXT_PUBLIC_CONTACT_EMAIL` | 개인정보처리방침에 안내 문구로 표시 |

### Supabase 붙이기

1. 프로젝트 생성 → SQL Editor 에서 `supabase/schema.sql` 실행
2. Project URL · anon key · service_role key 를 `.env.local` 에 입력
3. 재시작하면 설정 화면의 **데이터 저장소** 배지가 `Supabase PostgreSQL` 로 바뀝니다

`SUPABASE_SERVICE_ROLE_KEY` 는 RLS 를 우회하므로 **서버에만** 둡니다. 클라이언트에는 anon key 만 전달됩니다.

### 모델 이름에 대한 참고

개발 지시서는 `gemini-1.5-pro` / `gemini-1.5-flash` 를 명시하지만, 이 모델들은 신규 프로젝트에서
더 이상 제공되지 않을 수 있습니다. 그래서 기본값을 `gemini-2.5-pro` / `gemini-2.5-flash` 로 두고
`GEMINI_MODEL_PRO` · `GEMINI_MODEL_FLASH` 로 언제든 되돌릴 수 있게 했습니다.

## 4. 검증

```bash
npm test       # 104건 — 순서 배치, 시간 계산, 날짜 표기, 파서, 대본, AI 응답 방어 파싱, 집계, 디자인 레지스트리
npm run smoke  # 48건 — 실제 서버에 요청해 원장·학부모 흐름 전체를 밟는다
npm run shots  # 주요 화면을 screenshots/ 에 캡처 (Playwright)
```

스모크와 캡처는 `.data` 를 임시로 옮겨 두고 돌기 때문에 실제 작업 데이터를 건드리지 않습니다.
시스템에 설치된 Chromium 을 쓰려면 `CHROMIUM_PATH` 를 지정하세요.

### 시간대

순서표의 예상 시각은 서버(대개 UTC)와 브라우저(원장의 로컬)에서 같은 값이 나와야 하므로,
표기와 입력 해석을 모두 **고정된 학원 시간대**에서 수행합니다 (기본 `Asia/Seoul`,
`NEXT_PUBLIC_APP_TIME_ZONE` 으로 변경). `lib/format.ts` 한곳에만 모여 있습니다.
