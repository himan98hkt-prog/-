# 어떻게 팔 것인가

결론부터 적습니다.

> **ZIP 파일을 파는 건 상품이 아닙니다.**
> 원장님들에게 파는 것은 **주소 하나**여야 합니다.

지금 만든 `시작하기.bat` 은 사장님과 사모님, 그리고 체험판을 위한 것입니다.
실제 판매는 아래 A안으로 가야 합니다.

---

## 왜 설치형은 팔면 안 되는가

이번에 직접 겪으신 것이 그대로 답입니다.

| 단계 | 설치형에서 벌어지는 일 |
| --- | --- |
| 다운로드 | "ZIP을 풀어야 한다"를 모르는 분이 절반 |
| 실행 | "Windows의 PC 보호" 파란 경고창에서 이탈 |
| 준비 | 인터넷·방화벽·백신에 따라 실패 가능 |
| 사용 | 학원 컴퓨터에서 만든 걸 집에서 못 봄 |
| 문의 | 원장님 100명 = 컴퓨터 100대 = 환경 100가지 |

환불 사유가 프로그램이 아니라 **설치**에서 나옵니다.
그리고 그 문의를 받는 건 전부 사장님입니다.

---

## A안 — 웹 서비스 (권장 · 실제 상품)

원장님은 아무것도 설치하지 않습니다.

```
아첼쌤에서 결제
   ↓
안내 메일 도착 ("여기로 들어오세요")
   ↓
piano.accelssam.com 접속 → 로그인
   ↓
바로 사용
```

**이게 되면 달라지는 것**

- 학원 컴퓨터에서 만든 순서표를 집에서 이어서 고칩니다.
- 아이패드로 무대 옆에서 진행표를 봅니다.
- 초대장 링크가 진짜 링크가 됩니다. 지금은 `localhost:3000` 이라 단톡방에 못 올립니다.
  **이게 제일 큽니다.** 이 프로그램의 핵심 기능이 설치형에서는 반쪽입니다.
- 사장님이 고치면 전원이 즉시 최신 버전입니다. 재배포가 없습니다.
- 문의가 "제 컴퓨터에서 안 돼요" 에서 "이 버튼이 뭐예요" 로 바뀝니다.

**필요한 것**

| 항목 | 용도 | 비용 |
| --- | --- | --- |
| Vercel | 프로그램이 도는 곳 | 무료 시작 / Pro $20·월 |
| Supabase | 데이터 저장 | 무료 시작 / Pro $25·월 |
| 도메인 | `piano.accelssam.com` | 기존 도메인 하위주소, 추가비용 0 |
| Gemini API | AI 순서표·대본 | 사용한 만큼, 행사 1건당 수십 원 수준 |

**원장 100명 기준 월 6~7만원 안팎**입니다. 연 198,000원짜리를 100명에게 팔면
매출 1,980만원, 인프라는 연 80만원 정도. 나머지는 사장님 몫입니다.

**준비 상태**: 코드는 이미 웹 서비스로 만들어져 있습니다.
Supabase 테이블 정의(`supabase/`)와 배포 문서(`docs/DEPLOY.md`)가 들어 있습니다.
남은 건 계정 만들기와 결제 연동뿐이고, 반나절이면 됩니다.

## C안 — 진짜 설치 프로그램 (.exe)

Tauri 나 Electron 으로 감싸면 `설치.exe` 두 번 클릭으로 끝납니다.
Node.js 설치도 필요 없어집니다.

- 만드는 데 2~3일
- 코드서명 인증서 연 30~50만원 (없으면 파란 경고창이 계속 뜹니다)
- 그래도 **초대장 링크 문제는 여전히 해결되지 않습니다**

A안 다음에 "오프라인도 되게 해달라"는 요청이 실제로 쌓이면 그때 하십시오.
지금은 순서가 아닙니다.

## 판매 퍼널

가장 큰 전환 레버는 가격이 아니라 **눌러볼 수 있는 링크**입니다.

```
상세페이지 (아첼쌤)
   │
   ├─ [체험해보기] ──→ demo.piano.accelssam.com
   │                     로그인 없이 데모 학원으로 바로 입장.
   │                     순서표 만들기·인쇄물 고르기까지 다 됨.
   │                     매일 새벽 초기화.
   │
   └─ [구매하기] ────→ 결제 → 계정 자동 발급 → 안내 메일
                          └→ 첫 행사 만들기 3분 가이드
```

**체험 링크는 이미 만들어 배포했습니다.**

- 주소: https://claude.ai/code/artifact/f2def9cb-d28e-4cb0-beee-a315c02828bb
- 만들기: `npm run demo:build` → `배포/demo/artifact.html`
- 검사: `npm run demo:verify` (실제 브라우저로 12가지 동작 확인)

서버도 데이터베이스도 없이 **브라우저 하나에서 실제 로직이 돕니다.** 순서 배치 엔진,
사회자 대본 생성, 순서표 진단, 리허설·예산·좌석 계산, 인쇄물 75종 × 테마 108종 렌더가
모두 앱과 같은 코드입니다. 명단을 고치면 그 자리에서 전부 다시 계산됩니다.

기본은 비공개이며, 페이지의 공유 메뉴에서 링크를 열어야 외부에서 열립니다.
상세페이지의 [체험해보기] 버튼에 이 주소를 걸면 됩니다.

상세페이지에 스크린샷만 있는 것과, 눌러볼 수 있는 것은 전환율이 다릅니다.
