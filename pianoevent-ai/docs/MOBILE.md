# 휴대폰에서 테스트하기

두 가지 방법이 있습니다. **① 같은 와이파이**는 5분이면 되고, **② 인터넷 배포**는 학부모에게
링크를 보내 실제로 회신까지 받아 볼 수 있습니다.

---

## ① 같은 와이파이에서 열기 (가장 빠름)

컴퓨터에서 프로그램을 켜고, 휴대폰으로 그 컴퓨터에 접속하는 방식입니다.

### 1. 컴퓨터에서 실행

`pianoevent-ai` 폴더에서 명령창을 열고:

```bash
npm run mobile
```

그러면 이런 상자가 뜹니다.

```
┌──────────────────────────────────────────────┐
│ 📱  휴대폰에서 열어 보기                     │
│                                              │
│ 휴대폰을 컴퓨터와 같은 와이파이에 연결한 뒤, │
│ 휴대폰 브라우저 주소창에 아래를 입력하세요.  │
│                                              │
│     http://192.168.0.5:3000                  │
│                                              │
│ 이 컴퓨터에서는  http://localhost:3000       │
│ 끄려면 이 창에서 Ctrl + C                    │
└──────────────────────────────────────────────┘
```

아래에 **QR 코드**도 함께 나옵니다. 휴대폰 카메라로 비추면 바로 열립니다.

### 2. 휴대폰에서 접속

- 휴대폰이 **컴퓨터와 같은 와이파이**에 연결돼 있어야 합니다. (휴대폰 데이터로는 안 됩니다)
- 주소창에 `http://192.168.0.5:3000` 처럼 상자에 나온 주소를 그대로 입력합니다.

### 안 열릴 때

| 증상 | 해결 |
|---|---|
| 연결할 수 없다고 나옴 | 휴대폰이 **같은 와이파이**인지 확인. 5GHz/2.4GHz가 갈려 있으면 같은 쪽으로 맞추세요 |
| 윈도우에서 안 됨 | 처음 실행할 때 뜨는 **방화벽 허용** 창에서 "개인 네트워크" 를 체크하고 허용 |
| 주소가 여러 개 나옴 | 상자에 나온 주소를 위에서부터 하나씩 시도 |
| 회사·학원 와이파이 | 기기 간 통신이 막힌 곳이 있습니다. 휴대폰 핫스팟을 켜고 컴퓨터를 거기에 연결한 뒤 다시 시도 |

> 컴퓨터를 끄거나 `Ctrl + C` 를 누르면 휴대폰에서도 접속이 끊깁니다. 잠깐 보여 주는 용도입니다.

## ② 인터넷에 올려서 열기 (학부모 테스트까지)

주소 하나로 어디서든 열립니다. **초대장을 실제로 카톡으로 보내 참석 회신까지 받아 볼 수 있습니다.**

### 1. Vercel 가입 (무료)

1. https://vercel.com 접속 → **Continue with GitHub** 로 가입
2. 오른쪽 위 **Add New → Project**
3. 이 저장소(`himan98hkt-prog/-`)를 선택하고 **Import**

### 2. 설정에서 딱 하나만 바꾸기

- **Root Directory** 를 `pianoevent-ai` 로 지정합니다. **이것만 하면 됩니다.**
  (프로젝트가 저장소 하위 폴더에 있어서입니다)
- Framework 는 Next.js 로 자동 인식됩니다.
- **Deploy** 를 누르고 2~3분 기다립니다.

### 3. 주소 받기

`https://무언가.vercel.app` 주소가 나옵니다. 휴대폰에서 이 주소를 열면 끝입니다.

### ⚠️ 데이터 저장에 대한 주의

Supabase를 연결하지 않은 상태에서는 **입력한 내용이 유지되지 않습니다.**
(인터넷 서버는 파일에 저장할 수 없어서, 새로고침하면 데모 상태로 돌아갈 수 있습니다)

- **화면만 둘러보기** → 이대로도 충분합니다
- **학생을 넣고 초대장을 보내 회신까지 받기** → Supabase 연결이 필요합니다

Supabase 연결은 [DEPLOY.md](DEPLOY.md) 를 보세요. 무료 플랜으로 충분하고,
SQL 한 번 붙여넣고 주소·키 세 개를 Vercel에 넣으면 끝납니다.
