# 연주회 운영 분석과 반영 내역

대형 학원에서 연주회를 여러 번 치러 보면, 시간을 잡아먹는 곳은 늘 같은 자리다.
아래는 실제로 반복되는 병목과, 이 제품이 그것을 어떻게 없앴는지 정리한 것이다.

## 1. 시간을 가장 많이 먹는 다섯 가지

| 병목 | 왜 오래 걸리나 | 반영 |
|---|---|---|
| **연주 순서 짜기** | 난이도·길이·형제 관계를 머릿속으로 조합하고, 한 명 바뀌면 처음부터 다시 | 명단만 넣으면 배치·러닝타임·종료 시각이 즉시 나오고, 학생을 고쳐도 다시 계산됨 |
| **사회자 대본** | 곡 해설을 검색해 옮기고 학생마다 문장을 새로 씀 | 곡·작곡가 지식 + 학생 특징 메모를 엮어 곡마다 멘트 자동 생성 |
| **인쇄물 만들기** | 포스터·순서지·입장권·상장을 매번 새 파일로 | 테마 하나를 고르면 50종 양식이 같은 옷을 입고, 한 벌 인쇄로 한 번에 |
| **학부모 안내 문자** | 초대·리마인드·당일·감사 네 통을 매번 새로 씀 | 행사 정보로 채워진 네 통을 복사만 하면 됨 |
| **당일 진행표** | 도착·리허설·개장·시상 시각을 엑셀로 역산 | 개회 시각과 순서표만 있으면 큐시트가 자동 계산됨 |

## 2. 매번 빠뜨리는 것들

경험상 사고는 늘 같은 곳에서 난다. **준비 체크리스트**에 ★로 표시해 두었다.

- **피아노 조율 예약** — 당일 조율은 리허설과 겹친다. 1~2일 전으로 잡아야 한다.
- **상장 이름 오타** — 가장 많이 나는 실수. 명단과 대조하는 항목을 따로 뒀다.
- **사진·영상 담당자** — 학부모에게 맡기면 반드시 놓친다. 한 명을 지정해야 한다.
- **프로그램 인쇄 부수** — 참석 회신 인원 + 20%. 모자라면 그날 대안이 없다.
- **참석 회신 마감** — 좌석과 인쇄 부수가 여기서 나온다.
- **2시간 전 도착** — 피아노 위치, 의자 높이, 조명, 마이크는 직접 봐야 안다.
- **사진 공유 시점** — 이틀이 지나면 감흥이 식는다.

## 3. 진짜 초보자를 위한 설계

컴퓨터가 어려운 원장이 멈추는 지점은 정해져 있다. 그 지점마다 손을 잡아 준다.

- **무엇부터 할지 모른다** → 행사 화면 맨 위에 `① 명단 → ② 순서표·대본 → ③ 인쇄물·초대장`
  3단계를 두고, 끝난 단계는 표시된다. 세 단계가 끝나면 안내가 사라진다.
- **엑셀을 다룰 줄 모른다** → 표를 복사해 붙여넣기만 하면 된다. 헤더 순서가 달라도,
  `3:20`·`3분 20초`·`200` 어떻게 적어도 읽는다. 못 읽은 줄은 몇 번째 줄인지 알려 준다.
- **PDF 만드는 법을 모른다** → 인쇄 화면에서 "인쇄 · PDF 저장" 버튼 하나. 브라우저 인쇄
  대화상자에서 대상만 PDF로 고르면 된다는 문구를 화면에 적어 두었다.
- **양식을 하나씩 고르기 번거롭다** → **한 벌 인쇄**. 관객용(포스터·표지·순서지·입장권),
  당일 운영용(진행표·체크리스트·이름표)을 한 번에 뽑는다.
- **AI 키가 없거나 인터넷이 느리다** → 내장 규칙 엔진이 항상 결과를 낸다. 화면에 어느
  쪽으로 만들어졌는지 표시된다.
- **실수가 두렵다** → 계정 삭제만 되돌릴 수 없고, 그 하나는 "삭제"를 직접 입력해야 한다.

## 4. 자동으로 계산되는 것들

- **연주 순서** — 오프닝(짧고 안정적인 중급) → 초급 → 중급 → 듀엣·앙상블 → 피날레(최고 난이도)
- **러닝타임** — 곡 시간 합계 + 곡 사이 전환 40초 + 50분 초과 시 중간 휴식 10분
- **곡별 예상 시각** — 개회 시각 기준 누적. 학원 시간대 고정이라 서버·브라우저가 같은 값
- **경고** — 러닝타임 초과, 한 학생 3회 이상 출연, 연속 출연, 10분 초과 곡, 작곡가 누락
- **리허설 시간** — 1인당 2분 + 여유 10분 (최대 2시간)
- **체크리스트 날짜** — 행사일 기준 D-30 / D-14 / D-7 / D-1 / 당일 / 종료 후 이틀
- **상장·이름표 장수** — 상장 1인 1장, 이름표 8개/장

## 5. 아직 사람이 해야 하는 것

자동화하지 않은 것도 적어 둔다. 판단이 필요한 일이기 때문이다.

- **곡 선정** — 아이의 상태를 아는 사람은 선생님이다.
- **좌석 배치** — 가족 구성과 관계를 시스템이 알 수 없다.
- **문자 발송** — 문구는 만들어 주되 보내는 것은 원장이 직접 한다.
  (누구에게 보낼지는 학원마다 다르고, 잘못 보내면 되돌릴 수 없다)
- **사진 선택** — 아이 얼굴이 나오는 사진은 학부모 동의를 받은 것만 써야 한다.
