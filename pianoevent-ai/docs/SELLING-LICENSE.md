# 파는 절차 — 퍼널모아에 올리고 인증키로 여는 법

**연주회 매니저**를 accelssam.com(퍼널모아)에서 파실 때의 흐름을 그대로 적었습니다.
사모님의 「피아노학원 관리노트」와 같은 방식입니다 — 받으시고, 까시고, 키를 넣으시면 끝.

```
원장님이 결제  →  받는 자리(설치 파일 주소)  →  두 번 클릭해 설치
             →  프로그램이 인증키를 물음  →  붙여넣기  →  그때부터 계속 쓰심
```

### 팔기 전에 이것만 되어 있으면 됩니다

- [ ] 깃허브 Secrets 에 `RECITAL_LICENSE_SECRET` 을 넣었다
- [ ] 그 비밀값을 넣고 설치본을 **다시 뽑았다** (Actions → Run workflow)
- [ ] `npm run keygen:build` 로 `배포/인증키-발급기.html` 을 만들어 두었다
- [ ] 발급기로 만든 키가 실제 설치본에서 열리는지 한 번 해 봤다
- [ ] `npm run pack:web` 으로 나온 압축을 `public_html/download` 안에서 풀었다
- [ ] 상품 상세페이지·커리큘럼에 코드를 붙여 넣었다

---

## 한 번만 해 두시는 것 (처음 한 번)

### 1. 인증키 비밀 정하기

키를 만들고 확인하는 데 쓰는 **비밀 문장**입니다. 한 번 정하면 바꾸지 마세요 —
바꾸면 **이미 파신 키가 전부 안 열립니다.**

```bash
# 아무도 못 맞힐 긴 문장이면 됩니다. 예:
openssl rand -base64 32
```

정하신 값을 두 곳에 넣습니다.

| 어디에 | 이름 | 왜 |
|---|---|---|
| 깃허브 저장소 Secrets | `RECITAL_LICENSE_SECRET` | 설치본을 뽑을 때 프로그램 안에 담깁니다 |
| 사장님 컴퓨터(키 만들 때) | 같은 값 | 키를 찍어 낼 때 씁니다 |

> 저장소 코드에는 절대 적지 마세요. 저장소가 공개돼 있어, 적어 두면 **누구나 키를 찍어 낼 수 있습니다.**
> 비밀을 안 넣고 뽑은 설치본은 **파실 키를 열지 못합니다** (뽑을 때 크게 경고가 뜹니다).

### 2. 인증키 발급기 한 부 만들기

키는 **브라우저에서 여는 HTML 한 장**으로 찍어 냅니다. 명령창을 여실 일이 없습니다.

```bash
RECITAL_LICENSE_SECRET='정하신값' npm run keygen:build
#  →  배포/인증키-발급기.html
```

이 파일을 사장님 컴퓨터(또는 USB)에 두시고 **두 번 클릭**하시면 열립니다. 인터넷이 없어도 됩니다.

> ⚠️ **절대 홈페이지에 올리지 마세요.** 이 파일 안에는 비밀값이 들어 있어서,
> 남이 열면 키를 마음대로 찍어 냅니다. `배포/` 폴더는 저장소에 올라가지 않습니다.

> 「피아노학원 관리노트」의 발급기와는 **규칙이 다릅니다.** 그쪽 키(`XXXX-XXXX-XXXX`)는
> 연주회 매니저가 받지 않습니다. 반드시 이 발급기로 만드셔야 합니다.

### 3. 설치본 뽑기

깃허브 → **Actions → 연주회 매니저 설치본 만들기 → Run workflow**.
끝나면 Releases 의 `installer-latest` 에 올라옵니다.

- 윈도우 — `RecitalManager-Setup-Windows.exe`
- 맥 — `RecitalManager-Mac.dmg`

### 4. 홈페이지에 받는 자리 올리기

```bash
npm run pack:web        #  →  web/recital-upload.zip
```

워드프레스 **파일 관리자 → `public_html/download` 폴더 안에서** 이 압축을 푸십시오.
폴더가 들어 있지 않아 푼 자리에 그대로 나옵니다.

| 나오는 파일 | 주소 |
|---|---|
| `index.html` | `accelssam.com/download/` — 받는 자리 |
| `guide.html` | `accelssam.com/download/guide.html` — 사용설명서 |
| `recital-manager-detail.html` | 상품 상세페이지 (아이프레임으로 부릅니다) |
| `.htaccess` | 설치 파일이 열리지 않고 내려받아지게 함 |

설치 파일(`.exe`/`.dmg`)은 올리셔도 되고 안 올리셔도 됩니다. 안 올리시면 깃허브 Releases 것을 씁니다.

### 5. 퍼널모아 상품 만들기

- **상품명** — 연주회 매니저 (피아노학원 연주회 준비 프로그램)
- **판매 형태** — 다운로드형(파일 또는 링크 제공)
- **제공 파일** — 위 `.exe` / `.dmg` 를 올리시거나, Releases 주소를 그대로 안내하셔도 됩니다
- **자동 안내 문구** — 아래 「보내 드릴 문구」를 그대로 붙이시면 됩니다

> 파일을 직접 올리시면 판올림할 때마다 다시 올리셔야 합니다.
> **Releases 주소로 안내**하시면 늘 최신판이 내려갑니다. 이쪽을 권합니다.

## 결제가 들어올 때마다 (한 건에 1분)

### 1. 키 만들기

`배포/인증키-발급기.html` 을 두 번 클릭해 여십시오. 탭이 셋입니다.

| 탭 | 언제 쓰나 |
|---|---|
| **학원명으로 발급** | 결제가 한 건 들어왔을 때. 학원 이름을 넣고 「키 만들기」 → 「안내 문자 통째로 복사」 |
| **키 미리 만들기** | 여러 개를 미리 찍어 둘 때. 「장부로 내려받기(.csv)」로 엑셀 장부까지 나옵니다 |
| **키 확인하기** | 원장님이 「키가 안 맞는다」고 하실 때. 그 키를 붙여넣으면 이용 형태·만료일·일련번호가 나옵니다 |

학원 이름으로 만드시면 **같은 이름은 언제 만들어도 같은 키**가 나옵니다.
문자를 잃어버리셨다는 문의가 와도 이름만 다시 넣으시면 됩니다.

장부 CSV 는 `일련번호 · 이용형태 · 만료일 · 인증키 · 판매일 · 받으신 분` 으로 나옵니다.
엑셀에서 바로 열립니다.

> 명령창이 편하시면 `RECITAL_LICENSE_SECRET='정하신값' npm run key:new -- --plan year --count 1` 도
> 그대로 됩니다. 같은 규칙이라 나오는 키가 같습니다.

### 2. 보내 드릴 문구

```
[연주회 매니저] 결제해 주셔서 감사합니다.

1) 아래 주소에서 설치 파일을 받으세요.
   https://accelssam.com/download/
   (여시면 윈도우용·맥용 단추가 나옵니다)

2) 두 번 클릭 → 다음 · 다음 · 설치
   (「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행)

3) 바탕화면의 「연주회 매니저」 아이콘을 누르시면
   인증키를 넣는 화면이 나옵니다. 아래 키를 붙여넣어 주세요.

   인증키: RM-XXXXX-XXXXX-XXXXX-XXXXX

한 번만 넣으시면 그 컴퓨터에서 계속 쓰십니다.
인터넷이 없어도 열리고, 아이 명단과 사진은 원장님 컴퓨터를 벗어나지 않습니다.

설치부터 첫 연주회까지 사용설명서:
https://accelssam.com/download/guide.html

— 아첼쌤
```

## 자주 오는 문의와 답

| 문의 | 답 |
|---|---|
| 「키가 안 맞는다고 나와요」 | 키는 스무 글자입니다. 앞뒤 공백·줄바꿈이 함께 붙었을 수 있으니 다시 붙여넣어 달라고 안내해 주세요. 대소문자·하이픈은 상관없습니다 |
| 「컴퓨터를 바꿨어요」 | 새 컴퓨터에 설치하고 **같은 키**를 넣으시면 됩니다. 옛 컴퓨터의 자료는 [설정 → 자동 저장]에서 폴더째 옮기시면 그대로 열립니다 |
| 「명단이 사라졌어요」 | 프로그램을 지워도 자료는 남습니다. [연주회 매니저 → 학원 자료 폴더 열기] 로 확인해 주세요 |
| 「태블릿에서도 쓰고 싶어요」 | 메뉴에서 [태블릿에서 열기]를 켜고 프로그램을 다시 열면, [설정] 화면에 QR과 주소가 나옵니다 |
| 「환불하고 싶어요」 | 키는 오프라인으로 확인하므로 **원격으로 막을 수 없습니다.** 환불 정책을 상세페이지에 미리 적어 두세요 |

## 알아 두실 한계

오프라인 인증은 **유출된 키를 막을 수 없습니다.** 서버에 물어보지 않기 때문에
「이 키는 취소됐다」를 알릴 길이 없습니다.

대신 서버 운영비가 0원이고, 인터넷이 끊긴 학원에서도 열리며,
**학원 자료가 밖으로 나가지 않는다**는 약속을 인증 때문에 깨지 않습니다.
파시는 규모에서는 이쪽이 맞습니다.

키가 크게 새는 것이 확인되면 그때 **비밀을 바꾼 새 판**을 내고, 기존 구매자에게는
새 키를 보내 드리는 방법이 있습니다(이미 파신 분의 옛 키는 옛 판에서 계속 열립니다).

[docs/PRICING.md](PRICING.md) 에 정리해 두었습니다. 요약하면 —

| 판 | 값 | 누구에게 |
|---|---|---|
| 1년 이용 | 19.8만 원 | 해마다 연주회를 여시는 학원 |
| 평생 이용 | 39.8만 원 | 한 번 사고 계속 쓰고 싶으신 분 |
| 체험 (1개월) | 무료 | 상세페이지의 「체험해보기」로 충분하면 굳이 필요 없습니다 |

`--plan trial --months 1` 로 체험 키도 만드실 수 있습니다.
