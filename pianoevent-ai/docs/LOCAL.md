# 내 컴퓨터에서 실행해 보기

설치 후 **명령 세 줄**이면 브라우저에서 전부 확인할 수 있습니다.
Supabase 계정도, AI 키도 필요 없습니다. 데모 학원(하모니 피아노학원)과 학생 12명이 이미 들어 있습니다.

---

## 1단계 · Node.js 설치 (한 번만)

이미 설치돼 있으면 건너뜁니다.

1. https://nodejs.org 접속
2. 왼쪽의 **LTS** 버튼을 눌러 내려받고, 다음·다음으로 설치
3. 설치가 끝나면 컴퓨터를 한 번 재시작하지 않아도 됩니다

> 설치되었는지 확인하려면 아래 2단계에서 `node -v` 를 쳐 보세요. `v22.x.x` 같은 숫자가 나오면 됩니다.

## 2단계 · 명령창 열기

- **윈도우**: 시작 버튼 → `powershell` 입력 → **Windows PowerShell** 실행
- **맥**: `⌘ + 스페이스` → `터미널` 입력 → 실행

## 3단계 · 내려받아 실행

명령창에 아래를 **한 줄씩** 붙여넣고 각각 엔터를 칩니다.

```bash
git clone -b claude/piano-event-program-0nd8od https://github.com/himan98hkt-prog/-.git pianoevent
cd pianoevent/pianoevent-ai
npm install
npm run dev
```

`npm install` 은 1~3분쯤 걸립니다. 마지막 줄에 아래처럼 나오면 성공입니다.

```
▲ Next.js 14.2.x
- Local:  http://localhost:3000
```

## 4단계 · 브라우저에서 열기

주소창에 **http://localhost:3000** 을 칩니다.

- **행사** → `제12회 정기 연주회` 를 누르면 학생 12명이 들어 있습니다.
- **순서표 · 대본** 탭 → `AI 순서표 만들기` 를 누르면 순서와 사회자 멘트가 만들어집니다.
- **인쇄물 디자인** → 양식 20종 × 테마 20종을 눌러 가며 미리보기 하고, `인쇄 · PDF` 로 뽑습니다.
- **진행 준비** 탭 → 준비 체크리스트, 학부모 안내 문구 4종, 당일 진행표.
- **초대장 · 참석 집계** → 학부모에게 보낼 링크를 확인합니다. 같은 컴퓨터에서는
  `http://localhost:3000/e/demo-event` 로 열립니다.

## 끄는 법

명령창에서 `Ctrl + C` 를 누릅니다. 다시 켜려면 같은 폴더에서 `npm run dev` 만 치면 됩니다.

## 자주 묻는 것

**Q. `git` 이 없다고 나옵니다.**
A. https://git-scm.com 에서 설치하거나, GitHub 페이지에서 초록색 `Code` → `Download ZIP` 으로
받아 압축을 푼 뒤 `pianoevent-ai` 폴더에서 3단계의 `npm install` 부터 하면 됩니다.

**Q. 휴대폰에서도 보고 싶습니다.**
A. 같은 와이파이에 있으면, 명령창에 `npm run dev -- -H 0.0.0.0` 을 치고 컴퓨터의 IP 주소
(예: `http://192.168.0.5:3000`)로 접속하면 됩니다.

**Q. 입력한 내용은 어디에 저장되나요?**
A. `pianoevent-ai/.data/store.json` 파일에 저장됩니다. 이 파일을 지우면 처음 데모 상태로 돌아갑니다.

**Q. 처음 상태로 되돌리고 싶습니다.**
A. 명령창에서 `Ctrl + C` 로 끄고, `.data` 폴더를 지운 뒤 다시 `npm run dev` 합니다.
(맥·리눅스: `rm -rf .data` / 윈도우: 탐색기에서 `.data` 폴더 삭제)

**Q. AI 멘트를 진짜 Gemini 로 만들어 보고 싶습니다.**
A. `pianoevent-ai` 폴더에 `.env.local` 파일을 만들고 아래 한 줄을 넣은 뒤 다시 실행하세요.

```
GEMINI_API_KEY=발급받은키
```

키가 없어도 내장 규칙 엔진이 순서표와 대본을 만들어 줍니다. 화면에 어느 쪽으로 만들어졌는지 표시됩니다.
