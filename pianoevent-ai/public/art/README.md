# 그림 자리

인쇄물·무대 화면에 들어가는 **그림**을 두는 곳입니다.
프로그램과 함께 깔리므로 인터넷 없이도 뜨고, 학원 밖으로 나가지 않습니다.

| 폴더 | 무엇 | 비율 |
|---|---|---|
| `poster/` | 포스터 주 그림 | 5:7 (A4) |
| `stage/` | 무대 화면·감동영상 배경 | 16:9 |
| `ornament/` | 상장·초대장 모서리 장식 | 1:1 |

만드는 법과 프롬프트는 [`docs/ART-PROMPTS.md`](../../docs/ART-PROMPTS.md) 에 있습니다.

## 넣을 때

- 이름은 프롬프트 번호 그대로 — `a1.png` `a2.png` …
- 포스터용은 긴 변 **2000px 이상**. 그보다 작으면 A4 인쇄에서 뭉갭니다
- 원본은 그대로 두고, 화면용으로 줄인 것은 빌드가 따로 만듭니다
