AutoShorts-Engine — 집 PC 설치 안내
====================================

롱폼 영상을 AI 로 분석해 자막이 박힌 9:16 쇼츠를 자동으로 만들고,
YouTube 에 예약 업로드까지 해 주는 프로그램입니다.


[1] 먼저 설치할 것 두 가지
--------------------------------------------------
  · 파이썬 3.10 이상   https://www.python.org/downloads/
      Windows 설치 시 "Add Python to PATH" 를 꼭 체크하세요.

  · FFmpeg (영상 편집에 필수)
      Windows   winget install Gyan.FFmpeg
      macOS     brew install ffmpeg
      Ubuntu    sudo apt install ffmpeg fonts-nanum


[2] 설치
--------------------------------------------------
  이 폴더에서 아래를 실행하세요.

  Windows (PowerShell 을 열고)
      powershell -ExecutionPolicy Bypass -File install.ps1

  macOS / Linux (터미널을 열고)
      bash install.sh


[3] 가상환경 켜기  ※ 새 창을 열 때마다 해 주세요
--------------------------------------------------
  Windows       .\.venv\Scripts\Activate.ps1
  macOS/Linux   source .venv/bin/activate


[4] API 키 입력
--------------------------------------------------
      autoshorts setup

  물어보는 대로 붙여 넣으면 이 PC 의 .env 파일에만 저장됩니다.
  둘 다 비워 두어도 로컬에서 쇼츠 제작은 됩니다.

    GEMINI_API_KEY    하이라이트 선정 품질 향상 (없으면 자체 분석)
                      발급: https://aistudio.google.com/apikey

    YOUTUBE_API_KEY   급상승 영상 탐색에 필요
                      발급: https://console.cloud.google.com
                            → YouTube Data API v3 사용 설정


[5] 업로드까지 쓰려면 (선택)
--------------------------------------------------
  업로드는 API 키가 아니라 구글 계정 로그인이 필요합니다.

  1) https://console.cloud.google.com 접속
  2) API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기
  3) 유형은 "데스크톱 앱" 선택 → JSON 파일 내려받기
  4) 그 파일을 아래 위치에 client_secret.json 이름으로 저장

       Windows   C:\Users\<사용자이름>\.autoshorts\client_secret.json
       macOS     ~/.autoshorts/client_secret.json

  5) 아래 명령 실행 (브라우저가 열립니다. 최초 한 번이면 끝)

       autoshorts login


[6] 확인
--------------------------------------------------
      autoshorts doctor

  빠진 게 있으면 무엇을 어떻게 설치할지 알려 줍니다.


[7] 사용하기
--------------------------------------------------
  웹 화면으로 (가장 쉬움)
      autoshorts ui
      → 브라우저에서 http://127.0.0.1:7860 접속

  명령으로
      autoshorts "https://www.youtube.com/watch?v=..."   영상 URL 로 쇼츠 만들기
      autoshorts trend "재테크"                            급상승 영상 찾기
      autoshorts trend "재테크" --run                      1위 영상으로 바로 제작


[8] 매일 자동 발행 예약
--------------------------------------------------
  매일 아침 9시에 급상승 영상을 찾아 쇼츠 2개를 만들어 비공개 업로드:

      autoshorts schedule add "재테크" --at 09:00 -- --upload --upload-count 2

  확인    autoshorts schedule show
  해제    autoshorts schedule remove

  ※ 예약 시각에 PC 가 켜져 있어야 합니다.
  ※ 미리 autoshorts login 을 해 두어야 무인 업로드가 됩니다.


[꼭 알아 두실 점]
--------------------------------------------------
  · 업로드 기본값은 "비공개" 입니다.
    남의 영상을 잘라 만든 쇼츠를 바로 공개하면 저작권 신고나 채널 경고를
    받을 수 있습니다. 비공개로 올려 두고 확인한 뒤 직접 공개하세요.

  · 업로드는 하루 6개가 한도입니다.
    YouTube 무료 할당량(하루 10,000)에서 업로드 1건이 1,600 을 씁니다.
    프로그램이 알아서 한도를 지키고 멈춥니다.

  · 자세한 설명은 README.md 에 있습니다.
