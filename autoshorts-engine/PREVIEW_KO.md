# Shorts Studio — 로컬 실행 안내

분석 쇼츠와 주제 기반 쇼츠의 작업 공간을 하나로 구성한 개발용 버전입니다.
분석 쇼츠는 제작까지 실행되며, shorts-factory는 기획 저장·복원·내보내기까지
연결되어 있습니다. 두 제작 엔진의 실행 통합과 판매용 서비스가 모두 완성된
버전은 아닙니다. shorts-factory 유료 생성과 YouTube 자동 게시는 연결하지 않았습니다.

## Windows에서 시작

1. Docker Desktop을 설치하고 Linux 컨테이너 모드로 실행합니다.
2. ZIP을 새 폴더에 풉니다. 기존 프로그램 폴더에 덮어쓰지 마세요.
3. autoshorts-engine 폴더의 `start-studio.cmd`를 더블클릭합니다.
4. 최초 설치가 끝나고 서버가 준비되면 브라우저가 열립니다.
5. 열리지 않으면 http://localhost:8765 에 접속합니다.

Windows 실행 스크립트는 Docker 명령과 서버 준비 확인을 묶은 것입니다.
Docker Desktop이 꺼져 있으면 자동으로 실행하고 최대 3분간 준비를 기다립니다.
실패하면 같은 폴더의 `studio-startup.log`에 원인이 저장됩니다.
자동 검증은 Linux Docker 환경에서 수행했으며 Windows PC에서 직접 실행한 것은 아닙니다.

더블클릭해도 아무 변화가 없으면 파일을 우클릭하여 **속성 → 차단 해제 → 적용**을
선택한 뒤 다시 실행하세요. `studio-startup.log`가 생겼다면 마지막 `ERROR:` 줄을
확인합니다. 로그가 전혀 생기지 않으면 Windows가 CMD/PowerShell 실행을 차단한 것입니다.

터미널로 실행할 수도 있습니다.

```sh
docker compose -f compose.preview.yml up --build -d
docker compose -f compose.preview.yml ps
```

## 분석 쇼츠 사용

가입 → 프로젝트 생성 → MP4 업로드 → 이용 권리 확인 → 길이·개수 선택 → 쇼츠 만들기.
첫 확인에는 음성이 또렷한 1~3분 영상을 사용하세요. 한국어가 기본이며 영어와
언어 자동 감지도 선택할 수 있습니다. 로컬 Whisper와 휴리스틱 구간 선정을 사용합니다.
최초 모델 다운로드는 인터넷이 필요합니다. PC 성능에 따라 처리 시간이 달라집니다.
이 버전은 화자 추적이나 인기·흥행 예측을 제공하지 않습니다.

좌측 프로젝트와 최근 분석 작업 목록에서 이전 작업을 다시 볼 수 있습니다.
같은 탭에서 새로고침하면 로그인을 복원합니다. 브라우저를 닫은 뒤에는 다시 로그인해
프로젝트를 선택하면 됩니다. PC와 Docker가 켜져 있어야 작업이 계속됩니다.

완료 후 '미리보기 및 다운로드 준비'를 누르면 영상 재생과 'MP4 저장'이 나타납니다.
실패·취소된 작업은 다시 시작할 수 있습니다. 취소는 현재 단계가 끝난 뒤 반영될 수 있습니다.
반복 제출은 같은 작업을 반환하며, 재시도는 별도 작업으로 한 번만 접수합니다.

## 주제 기반 쇼츠 사용

'주제 기반 쇼츠' 탭에서 주제·테마·대본을 작성해 저장합니다.
같은 프로젝트에서 다시 불러오거나 기획 JSON으로 내보낼 수 있습니다.
이 JSON은 스튜디오 기획 교환 형식이며 기존 shorts-factory의 완성 대본 파일과는 다릅니다.
자동 생성 버튼은 중지 상태이고 서버에서도 생성을 거부합니다.
기존 shorts-factory의 소스·예약·키·계정은 변경하거나 복사하지 않습니다.

## 비용 정책

기본값 `AUTOSHORTS_ALLOW_PAID_AI=0`은 분석 작업에서 Gemini 키를 사용하지 못하게 합니다.
다른 용도로 PC에 키를 등록해두었더라도 분석 서비스는 기본적으로 이를 사용하지 않습니다.
현재 Docker 구성에는 유료 API 키가 없습니다. 웹 화면에서 유료 기능을 켤 수 없습니다.
이 정책은 본 스튜디오에만 적용되며 별도로 실행 중인 Google AI Studio나 기존
shorts-factory 계정의 결제 정책을 변경하지 않습니다.

계정의 개발용 크레딧 장부는 작업 수 제한을 위한 내부 값이며 실제 결제와 연결되지 않았습니다.
현재 버전에는 크레딧 구매 기능이 없습니다. 로컬 PC 전기·인터넷 또는 외부 서버 비용까지
없어지는 것은 아닙니다.

## 종료·데이터·문제 확인

`stop-studio.cmd`를 실행하면 서비스를 중지하며 프로젝트와 결과는 보존합니다.
Docker 볼륨을 지우면 데이터가 사라집니다. 업데이트 시 기존 compose 프로젝트 이름과
볼륨을 유지해야 이전 데이터를 그대로 사용할 수 있습니다.

```sh
docker compose -f compose.preview.yml logs --tail 100 worker
docker compose -f compose.preview.yml logs --tail 100 api
docker compose -f compose.preview.yml stop
```

Whisper 모델 다운로드 실패는 인터넷·모델 서버 연결을 확인한 뒤 실패 작업을 다시 시작합니다.
권리 확인 필요는 영상의 실제 이용 권리를 확인한 후 새로 제출합니다.
조용한 영상이나 음악만 있는 영상은 분석 쇼츠 음성인식 대상에 적합하지 않습니다.

## 검증과 남은 범위

- PostgreSQL 계정·격리·큐·장부·기획·작업 이력 테스트.
- 합성 영상과 준비된 한국어 전사로 실제 FFmpeg 렌더링.
- 준비된 전사 없이 합성 영어 음성을 Whisper로 인식한 후 세로 MP4 생성·다운로드.
- API를 종료한 상태에서도 별도 워커가 제작하고, 재접속 후 결과 다운로드.
- Docker 빌드·기동·모델 캐시 쓰기 권한 및 Chromium 브라우저 가입·기획 복원.

한국어 실제 롱폼 영상의 결과 품질, 다양한 Windows PC, GPU, 장시간 대용량 입력,
상용 운영 보안·결제·YouTube 발행·shorts-factory 제작 워커는 추가 검증/개발이 필요합니다.
현재는 로컬 개발용 고정 DB 비밀번호를 쓰므로 인터넷 공개 서버에 그대로 배포하지 마세요.
