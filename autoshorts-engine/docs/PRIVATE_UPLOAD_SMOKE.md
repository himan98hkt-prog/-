# private 업로드 실기 검증 체크리스트

**이 문서의 절차는 자동으로 실행되지 않습니다.** 실제 OAuth 토큰과 YouTube 계정이
필요하고, 계정 상태를 바꾸는 작업이라 사람이 직접 해야 합니다. CI 에서 돌리지 마세요.

## 왜 수동인가

- 실제 credential 이 필요합니다. 테스트에 토큰을 넣으면 유출 경로가 생깁니다.
- 업로드는 되돌리기 어렵습니다(삭제해도 이력이 남습니다).
- 할당량을 실제로 소모합니다.

자동 테스트는 `tests/test_youtube_publisher.py` / `tests/test_uploader*.py` 가
**가짜 서비스 객체**로 요청 조립·오류 분류·재시도만 검증합니다. 네트워크를 타지 않습니다.

## 사전 준비

- [ ] Google Cloud 프로젝트에 YouTube Data API v3 활성화
- [ ] OAuth 클라이언트(데스크톱 앱) 생성 후 `client_secret.json` 확보
- [ ] `autoshorts login` 으로 브라우저 로그인 1회 — 토큰이 저장되는지 확인
- [ ] 토큰 파일 권한이 소유자만 읽기(`600`)인지 확인
- [ ] 업로드 테스트용 채널이 **본 채널이 아닌지** 확인 (경고가 남을 수 있음)
- [ ] `autoshorts quota` 로 현재 적용 중인 할당량 정책 확인

## A. 인증 경로

| # | 확인할 것 | 방법 | 기대 결과 |
|---|---|---|---|
| A1 | 토큰 없음 | 토큰 파일을 옮기고 `autoshorts upload <파일>` | `AuthRequiredError` — `autoshorts login` 안내 |
| A2 | 토큰 손상 | 토큰 파일에 아무 글자나 써 넣고 재시도 | 재로그인 안내 (스택트레이스 노출 없음) |
| A3 | client_secret 없음 | 파일을 옮기고 `autoshorts login` | 설치 안내 메시지 |
| A4 | 로그인 성공 | `autoshorts login` | 토큰 저장, 권한 `600` |
| A5 | 키 마스킹 | 위 과정의 로그 전체 | **토큰/키 문자열이 한 글자도 안 보여야 함** |

## B. dry-run (업로드하지 않음)

| # | 확인할 것 | 방법 | 기대 결과 |
|---|---|---|---|
| B1 | 요청 조립 | `autoshorts auto "<키워드>" --upload --dry-run-upload` | 제목·설명·태그·공개범위가 출력되고 **업로드는 일어나지 않음** |
| B2 | 제목 정리 | `<` `>` 와 100자 초과 제목 | 문자 제거, 100자로 절단, `#Shorts` 유지 |
| B3 | 쇼츠 적합성 | 3분 초과 / 가로 영상 | 경고 출력 |

## C. 실제 private 업로드 1건

> 여기서부터 실제로 올라갑니다. 공개범위를 확인하세요.

| # | 확인할 것 | 방법 | 기대 결과 |
|---|---|---|---|
| C1 | 기본 공개범위 | `autoshorts upload <파일>` (옵션 없이) | YouTube Studio 에서 **비공개(private)** |
| C2 | 재생 | Studio 에서 재생 | 9:16, 자막 번인, 소리 정상 |
| C3 | 쇼츠 인식 | 모바일에서 확인 | 쇼츠 플레이어로 재생 |
| C4 | 결과 기록 | 실행 출력 | `video_id`, URL, `quota_used` 가 남음 |
| C5 | 이력 저장 | `state` 이력 확인 | 업로드가 오늘 건수에 반영됨 |
| C6 | 정리 | Studio 에서 영상 삭제 | — |

**공개 전환은 이 체크리스트에 없습니다.** `--privacy public` 과 예약 공개는 아래
"공개 발행 전 조건"이 끝나기 전에는 검증 대상이 아닙니다.

## D. 실패 경로

| # | 확인할 것 | 방법 | 기대 결과 |
|---|---|---|---|
| D1 | 할당량 초과 | 한도까지 올린 계정으로 재시도 | `QuotaExceededError` — **API 응답 기준** 문구, 정책값은 추정치로 표기 |
| D2 | 잘못된 요청 | 태그를 500자 넘게 | `400` 을 읽을 수 있는 메시지로 |
| D3 | 중단 | 업로드 중 Ctrl+C | 부분 업로드가 성공으로 기록되지 않음 |
| D4 | 네트워크 끊김 | 업로드 중 네트워크 차단 | 재시도 후 실패 보고, 이력에 성공으로 남지 않음 |

D3·D4 는 Phase 8 의 idempotency / lost-response reconciliation 이 필요한 지점입니다.
**Phase 0 에서는 현재 동작을 기록만** 하고 고치지 않습니다.

## 공개 발행 전 조건 (아직 충족되지 않음)

Google 공식 `videos.insert` 문서 기준으로, 2020-07-28 이후 만든 **미검증 API 프로젝트**의
업로드는 private 으로 제한될 수 있고, 해제에는 API compliance audit 이 필요합니다.
따라서 다음이 끝나기 전에는 "공개 발행 / 예약 공개"를 상품 약속으로 쓰지 않습니다.

- [ ] OAuth consent 화면 정비
- [ ] 개인정보 처리방침 / 데이터 취급 문서 공개
- [ ] API compliance audit 신청 및 통과
- [ ] 원본 영상 권리 확인 흐름 (Phase 7)
- [ ] 사용자 검토·승인 게이트 (Phase 8)
