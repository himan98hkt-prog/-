# 무대 배경 이미지·영상

발표회 운영 화면(`program.html`)의 무대는 **CSS·SVG 로 그린다.** 이 폴더가 비어
있어도 화면은 그대로 뜬다 — 연주홀 와이파이는 믿을 수 없다는 것이 지시서 모듈
⑤-1 의 전제다. 여기 있는 것은 **배경 장식**이고, 없다고 기능이 빠지지 않는다.

여기에 파일을 넣으면 서버(`/api/stage`)가 알아서 찾아 무대 위에 얹는다. 없는 파일을
찔러 보지 않으므로 콘솔에 404 가 남지 않는다.

| 파일 | 쓰임 |
|---|---|
| `hall.mp4` | 무대 배경 영상 (있으면 **이게 우선**, 이미지는 안 쓴다) |
| `hall.jpg` | 무대 배경 이미지 |
| `keys.jpg` | 예비 — 건반 클로즈업 |
| `curtain.jpg` | 예비 — 벨벳 커튼 텍스처 |

## 지금 들어 있는 것

| 파일 | 무엇 |
|---|---|
| `hall.mp4` | 무대 배경 영상 — 격식 있는 대강당 · 1904×1088 · 10초 · 무음 |
| `hall.jpg` | 같은 홀의 정지 사진 · 2400×1350 |
| `keys.jpg` | 건반 클로즈업 (아직 화면에서 안 쓴다) |
| `curtain.jpg` | 벨벳 커튼 (아직 화면에서 안 쓴다) |

**영상과 사진은 같은 홀이어야 한다.** 영상이 안 뜨는 기기는 사진으로 되돌아가는데,
거기서 전혀 다른 홀이 나오면 같은 발표회로 안 보인다.

`hall.mp4` 가 있으면 `hall.jpg` 는 **안 쓰인다.** 서버가 영상을 먼저 본다.

어디서 왔고 다른 안으로 바꾸려면 어떻게 하는지는
[`docs/MR-IMAGES.md`](../../../../docs/MR-IMAGES.md) 에 있다. 목록을 두 군데 적으면
반드시 어긋나므로 여기서는 적지 않는다.

## 넣은 뒤

```bash
cd mr && python3 tools/player_check.py     # 11항목이 그대로 통과해야 한다
```

무대 화면은 제작 서버에서 뜨므로 용량이 비교적 자유롭지만, `hall.mp4` 가 수십 MB 가
되면 발표회장 노트북에서 첫 재생이 늦는다. **10초 · 720p · 5 MB 안쪽**이 적당하다.
