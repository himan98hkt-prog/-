# 무대 배경 이미지·영상

발표회 운영 화면(`program.html`)의 무대는 **CSS·SVG 로 그린다.** 이 폴더가 비어
있어도 화면은 그대로 뜬다 — 연주홀 와이파이는 믿을 수 없다는 것이 지시서 모듈
⑤-1 의 전제다. 여기 있는 것은 **배경 장식**이고, 없다고 기능이 빠지지 않는다.

여기에 파일을 넣으면 서버(`/api/stage`)가 알아서 찾아 무대 위에 얹는다. 없는 파일을
찔러 보지 않으므로 콘솔에 404 가 남지 않는다.

| 파일 | 쓰임 |
|---|---|
| `hall.mp4` | 무대 배경 영상 (있으면 **이게 우선**, 이미지는 안 쓴다) |
| `hall.jpg` | 무대 배경 이미지 |
| `keys.jpg` | 예비 — 건반 클로즈업 |
| `curtain.jpg` | 예비 — 벨벳 커튼 텍스처 |

## 무엇을 만들어 뒀고 어떻게 받나

**[`docs/MR-IMAGES.md`](../../../../docs/MR-IMAGES.md) 한 곳에 모아 두었다** — 생성해 둔
것의 목록, 내려받을 주소, 웹용으로 줄이는 명령까지. 목록을 두 군데 적으면 반드시
어긋나므로 여기서는 적지 않는다.

요약만: **이 세션의 컨테이너는 조직 egress 정책상 힉스필드 CDN 과 결과가 놓이는
CloudFront 에 접근할 수 없다**(프록시가 CONNECT 에 403). 정책 거부는 우회하지 않는
것이 원칙이라 파일을 받아 커밋하지 못했다. 네트워크가 되는 곳에서 받아 이 폴더에
넣으면 바로 붙는다.

## 넣은 뒤

```bash
cd mr && python3 tools/player_check.py     # 11항목이 그대로 통과해야 한다
```

무대 화면은 제작 서버에서 뜨므로 용량이 비교적 자유롭지만, `hall.mp4` 가 수십 MB 가
되면 발표회장 노트북에서 첫 재생이 늦는다. **10초 · 720p · 5 MB 안쪽**이 적당하다.
