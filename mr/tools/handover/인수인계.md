# 인수인계 — 피아노학원 자동 반주(MR)

집 PC 에서 이어서 개발하시려고 빼낸 묶음입니다. **관리노트는 한 조각도
들어 있지 않습니다.**

새 대화를 이 폴더에서 여시면 `CLAUDE.md` 를 먼저 읽습니다. 거기에 **절대 하지
말 것**과 **손대면 안 되는 것**이 있으니, 이 문서보다 그쪽이 먼저입니다.

---

## 5분 안에 돌려 보기

```bash
python3 -m pytest                  # 전부 초록인지 먼저
python3 seed_catalog.py            # 연습곡 29곡 넣기 (처음 한 번)
python3 serve.py                   # http://127.0.0.1:8765
```

두 번 눌러 까는 길도 있습니다 — `install-windows.bat` · `install-mac.command`.
설치기는 `mr/.venv` 를 만들어 시스템 파이썬을 안 건드립니다.

들어만 보시려면 설치가 아예 필요 없습니다.

```bash
python3 catalog_cli.py package /tmp/pkg
python3 tools/single_file.py /tmp/pkg -o 들어보기.html   # 두 번 누르면 열림
```

## 제일 먼저 하실 일 — 악보

**이게 지금 유일하게 막혀 있는 자리입니다.**

콩쿨에서 실제로 많이 쓰는 곡 **54개**의 목록·저작권 검사·출처 검사·일괄
가져오기가 전부 돼 있는데 **악보 파일만 없습니다.** 이전 작업 환경이 바깥
통신을 허용 목록으로 막아 두어서 받아올 수 없었습니다. **집 PC 에서는 그
제약이 없습니다.**

```bash
python3 catalog_cli.py repertoire        # 54곡 중 무엇이 준비됐는지
python3 catalog_cli.py repertoire --scores ~/악보 \
    --score-source OpenScore --score-license cc0
```

받는 곳과 각각의 조건은 `docs/MR-SCORES.md` 와 설명서 13-6 에 있습니다. 요점만:

- **OpenScore** — 입력한 사람이 권리를 포기한 것들이라 가장 깨끗합니다
- **Mutopia** — 곡마다 조건이 적혀 있습니다. 보고 고르세요
- **IMSLP** — 스캔 PDF. 체르니·바이엘·부르크뮐러 **원판이 다 있습니다**
- **kernScores / craigsapp** — 385곡이 있고 music21 이 바로 읽습니다. 그런데
  전부 `CC BY-NC-SA` 라 **팔 수 없습니다.** 학원 자체용(`--personal`)으로만

교재류는 IMSLP 원판 PDF 를 **직접 인식**하는 것이 제일 깨끗합니다 — 인식한
결과물은 인식한 쪽 것이라 남의 조건이 안 붙습니다.

```bash
export MR_OMR_PROVIDER=local MR_OMR_LOCAL_CMD=/경로/audiveris
python3 catalog_cli.py omr               # 쓸 수 있는 상태인지 먼저
```

> **Audiveris 를 실제로 돌려 본 적이 없습니다.** 명령줄 규약은 소스
> (`CLI.java` · `BookManager.java`)에서 확인했고 그 규약대로 움직이는 대역으로
> 검사했지만, **집 PC 에서 한 번 돌려 보셔야 확정됩니다.** 설치 파일이 JRE 를
> 품고 있어 자바는 따로 안 깔아도 되고, 윈도는 파일 이름에 `windowsConsole` 이
> 든 것을 받으세요.

## 그 밖에 남은 일

- **`share` 를 집 와이파이에서 확인** — 이전 환경이 `0.0.0.0` 바인딩을 막아
  `127.0.0.1` 로만 검사했습니다. 윈도 방화벽이 처음 한 번 물어봅니다,
  「개인 네트워크」에 허용하셔야 폰에서 열립니다
- **웹호스팅에 실제로 올려 보기** — 압축·풀기·하위 폴더·오프라인은 브라우저로
  다 확인했지만 실제 호스팅의 https 와 캐시 설정은 그 자리에서 보셔야 합니다
- **검수 20분 목표의 실측** — 화면이 시간을 기록하는데 아직 사람이 써 본 적이
  없습니다
- **설명서의 문의처·환불 규정** — 파는 쪽이 정하는 값이라 비워 두었습니다
- **약관 문구** — 법률 자문 영역이라 만들지 않았습니다
- **OMR 공급사 실호출** — 유료 경로. 무료 로컬 경로가 있으니 급하지 않습니다

### 알려진 한계 (고장이 아니라 성질입니다)

- **플레이어 음색은 서버 렌더와 다릅니다.** 브라우저는 SoundFont 를 못 씁니다.
  발표회 영상에 붙일 음원은 **서버에서 내보내기로 구워야** 합니다
- **아이패드 사파리에서는 카운트인만 이어폰으로 빼는 기능이 안 됩니다**
  (`setSinkId` 가 없습니다). 없으면 없다고 화면이 말합니다
- **`http://192.168…` 로 열면 오프라인 저장이 안 됩니다.** 보안 컨텍스트가
  아니어서 서비스워커가 안 켜집니다. 재생은 됩니다

## 크게 틀렸다가 고친 것들 — 다시 밟지 마시라고

브라우저에서만 드러나는 고장이 유난히 많았습니다. **파이썬 테스트가 전부
초록이어도 화면이 고장나 있을 수 있습니다.**

| 무엇이 | 어떻게 드러났나 |
|---|---|
| 고친 화성이 아이 폰에 안 갔다 | 원장님은 고친 반주를 듣는데 아이는 옛것. 오류 0건. 지금은 `.rev` 표식과 `?v=해시` 로 막혀 있다 |
| 하위 폴더 배치가 증명된 적이 없었다 | 앱은 멀쩡했는데 **검사기**가 도메인 루트를 박아 두고 있었다. 「상대경로다」를 문자열로만 보고 있었다 |
| 무대 영상이 영영 안 떴다 | `preload="none"` 이라 `loadeddata` 가 안 온다. 파일은 붙었는데 투명한 채로 |
| 오프라인 검사가 거짓말을 했다 | Playwright 의 `set_offline` 은 서비스워커 안의 `fetch` 를 안 막는다. 지금은 **서버를 죽이고** 본다 |
| 설명서에서 두 문단이 사라졌다 | 원고에 `body2` 를 썼는데 빌더에 렌더링을 안 넣었다. 빌드도 검사도 통과했다 |
| 박자표 없는 MIDI 가 3/4 를 4/4 로 | 화성이 통째로 틀리는데 오류가 안 난다. 지금은 거절한다 |

`tests/test_freshness.py` 의 머리말이 앞의 두 개를 실측값과 함께 적어 두었습니다.

## 이 묶음은 어떻게 만들어졌나

원래는 학원 관리노트와 한 저장소에 있었고, 아래 명령이 반주만 빼냅니다.

```bash
python3 tools/standalone.py ../dist/피아노반주 --zip          # 파는 꾸러미
python3 tools/standalone.py ../개발 --handover                # 이 묶음
```

`tests/test_standalone.py` 10건이 분리를 지킵니다 — 관리노트 파일이 섞였는지,
제품 안의 파이썬이 **제품 밖을 import 하는지**, 개발용이 파는 꾸러미에
들어갔는지.

설명서도 반주만 따로 나옵니다. 원고의 `only` 표시를 빌더가 보고 고릅니다.

```bash
npm run manual:mr        # 원래 저장소에서 (2부 · 30절 · 그림 9장)
```
