왜 안 팔렸는지를 제품을 처음 받는 원장님 입장에서 따라가며 찾고, 찾은 것을 고쳤습니다. 결제 전, 체험, 결제, 첫 사용 순서로 막히는 자리 열세 곳을 바꿨고, 결제되면 인증키가 메일로 바로 나가는 퍼널모아 플러그인을 만들었습니다.

01

한 장 요약

기능이 모자라서가 아니라 사 보기 전에 써 볼 길이 없었고, 써 보다가 살 길도 없었습니다. 주소를 받아 들어오면 인증키 입력 칸만 있었고, 체험을 시작하면 빈 화면이었고, 앱 어디에도 구매 버튼이 없었습니다. 결제한 뒤에는 판매자가 키를 만들어 보낼 때까지 기다려야 했습니다.

먼저 해 주셔야 할 일이 하나 있습니다. GitHub 저장소가 공개 상태라 검색에 그대로 나옵니다. 안에 인증키를 만드는 규칙과 발급기가 들어 있어 누구나 키를 만들 수 있습니다. Settings → General → Danger Zone → Change visibility 에서 비공개로 바꿔 주세요.

02

첫 화면이 자물쇠였습니다

예전 첫 화면에는 무엇을 해 주는 프로그램인지, 어디서 사는지가 한 줄도 없었습니다. 이제는 제품을 세 줄로 소개하고, 가장 큰 버튼이 “14일 무료로 써 보기”입니다.

03

처음 온 사람이 지나가는 길

1
무료로 써 보기가입·카드 등록 없이 버튼 하나
2
샘플 학원 둘러보기원생 24명·출결·수강료·교재 진도가 들어 있는 연습용 학원
3
내 학원으로 시작샘플을 지우고 이름·종류·색만 정함
4
시작 가이드반 → 원생 → 출석 → 수강료를 하나씩 짚어 줌

예전에는 체험을 시작하면 빈 화면이었습니다. 반과 원생을 직접 넣기 전에는 볼 것이 없었고, 넣은 뒤에도 다음에 뭘 해야 하는지 알려 주지 않았습니다.

  • 혼자 쓰는 원장님에게는 잠금 번호를 묻지 않습니다. 공용키가 Pro로 열리면서 1인 학원도 앱을 열 때마다 0000을 눌러야 했습니다.
  • 새 원생 등록 창이 모든 반이 선택된 채로 열리던 버그를 고쳤습니다. 그대로 저장하면 전 반 출석부에 들어갔습니다.
  • 원생 등록 창은 이름·학부모 번호·반만 보이고, 나머지 여덟 칸은 “더 적기”에 접어 두었습니다.
  • 전문용어를 바꿨습니다. custom 필드 → 학습 기록 항목, CSV → 엑셀 파일, 키오스크 → 등원 체크 화면, 미수금 → 아직 못 받은 돈, PIN → 잠금 번호.
04

결제되면 인증키가 메일로 나갑니다

퍼널모아는 코스모스팜의 워드프레스 호스팅이라, 워드프레스 플러그인으로 만들었습니다. 결제가 끝나면 키를 만들어 구매자에게 보내고, 누구에게 어떤 키가 나갔는지 남깁니다. 기존 발급기와 같은 규칙으로 만들기 때문에 발급기로 만든 키와 섞여도 됩니다.

결제 방식연결확인
우커머스 주문완료됨 / 처리 중이 될 때점검 통과
코스모스팜 회원관리첫 결제 성공 뒤실결제 확인 필요
그 밖의 결제 도구웹훅 주소점검 통과
  • 같은 주문에는 키가 한 번만 나갑니다. 결제 알림이 여러 번 와도 같습니다.
  • 메일이 못 나가면 키는 발급 내역에 남고 판매자에게 알림이 갑니다. 주소를 고쳐 다시 보낼 수 있습니다.
  • 계좌이체 건은 “직접 보내기”에 메일 주소만 넣으면 됩니다.
  • 메일의 버튼을 누르면 키를 입력하지 않아도 인증된 채로 앱이 열립니다. 메일을 통째로 붙여 넣어도 키만 골라냅니다.

코스모스팜 회원관리 결제는 공개된 개발자 문서와 포럼의 훅 이름에 맞춰 만들었고, 실제 사이트에서는 아직 돌려 보지 못했습니다. 주문·상품 정보를 읽는 방법을 여러 가지로 시도하고 무엇을 읽었는지 “최근 기록”에 남기게 해 두었으니, 설치 후 결제 1건으로 메일과 상품명이 제대로 찍히는지 확인해 주세요.

05

교재·진도와 새 화면

피아노 관리노트에는 있고 여기에는 없던 기능입니다. 원생 카드나 출결 화면에서 교재 옆 칸에 “12번”이라고 적고 다른 곳을 누르면 저장됩니다. 적어 둔 진도는 학부모 리포트와 레슨 안내 문자에 그대로 들어갑니다. 처음 설정에서도 피아노·음악을 맨 앞에 두었습니다.

07

직접 해 주셔야 하는 것

할 일이유
저장소를 비공개로공개 상태면 누구나 인증키를 만들 수 있습니다.
구매 주소 넣기앱의 구매 버튼은 지금 accelssam.com 첫 화면을 엽니다. 실제 상품 주소를 넣어 빌드해야 합니다 (VITE_BUY_URL).
플러그인 설치 후 결제 1건코스모스팜 결제 연결은 실제 사이트에서 확인이 필요합니다.
메일이 스팸함으로 가는지 확인워드프레스 기본 메일은 스팸으로 잘 갑니다. WP Mail SMTP 로 네이버·구글 메일을 연결하면 됩니다.
상품 페이지 맨 위에 “무료로 써 보기”앱 주소로 바로 연결하면 샘플 학원이 열립니다. 결제 전에 써 볼 수 있다는 것이 가장 강한 설득입니다.
08

확인하지 못한 것

  • 판매 페이지와 퍼널모아 관리 화면. 이 작업 환경에서 accelssam.com과 cosmosfarm.com이 열리지 않아 직접 보지 못했습니다. 상품 페이지에 무엇이 있고 없는지는 모릅니다.
  • 어느 단계에서 가장 많이 빠지는지. 방문·체험·결제 수치를 받은 것이 없어, 위의 원인은 제품을 따라가며 찾은 것이지 숫자로 확인한 것이 아닙니다.
  • Pro 실환경. Supabase 프로젝트가 없어 기기 두 대 동시 사용은 여전히 확인하지 못했습니다.
  • 아이폰 홈 화면 앱. 사파리와 저장 공간이 달라 메일 링크로는 인증되지 않습니다. 앱 안의 “인증키 입력”에 메일을 붙여 넣어야 합니다.
