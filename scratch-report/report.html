이전 상태는 “기능은 다 있지만 아무나 그냥 쓸 수 있고, 원장이 손으로 하던 일은 그대로 남아 있는” 앱이었습니다. 이번에 바꾼 것은 두 가지입니다. 첫째, 인증키 없이는 앱이 열리지 않습니다. 둘째, 매일 반복하던 확인·안내·계산·정리 작업을 앱이 대신합니다.

02

인증키로 여는 제품

첫 실행에서 인증 화면이 뜹니다. 구매한 키를 넣거나 14일 체험을 시작해야 앱으로 들어갑니다. 체험이 끝나도 자료는 그대로 남고, 키를 넣으면 하던 작업을 이어서 씁니다.

AP7W–DZYP–1TY7C
A제품 — A는 피아노 관리노트와 공용인 통합키. M은 학원 전용, K는 피아노 전용.
P플랜 — L은 Lite(기기 1대·완전 오프라인), P는 Pro(여러 기기 실시간 동기화).
6자랜덤 — 받아 적을 때 헷갈리는 I·L·O·U는 쓰지 않습니다.
4자검증번호 — 한 글자만 틀려도 앱이 거부하고 이유를 알려 줍니다.

피아노 관리노트와 키를 함께 쓰는 방법

두 제품이 같은 발급 규칙을 쓰면 됩니다. 이 저장소의 src/core/license.js를 피아노 앱에 그대로 넣고 PRODUCT_CODE만 'K'로 바꾸면, 통합키(A)는 양쪽에서 열리고 전용키는 각자 제품에서만 열립니다. 잘못된 키를 넣으면 “피아노 관리노트 전용 키입니다”처럼 이유가 표시됩니다.

피아노 관리노트와 실제로 연결했습니다. 발급기(pambookkey.html)의 규칙을 그대로 이식해 피아노 키가 이 앱에서 Pro 로 열리고, 앱 파일(v3.9)에는 스크립트 한 블록을 덧붙여 학원 관리노트 키가 피아노 앱에서 열리는 것까지 브라우저로 확인했습니다. 기존에 판 키는 회수할 필요가 없습니다.

라이선스가 사라지지 않는 자리

  • 인증 정보는 기기의 것으로 취급합니다. 데모 데이터 넣기·초기화·백업 복원에도 인증이 유지됩니다.
  • 반대로 백업 파일에는 인증키가 담기지 않습니다. 백업을 복사해 다른 기기에서 라이선스를 복제할 수 없습니다.
  • 기기마다 6자리 기기번호가 표시되어 재발급·문의 대응에 씁니다.
  • 제품 구분이 없던 초기 발급분(첫 자리 L/P)도 계속 인정합니다. 회수할 필요가 없습니다.
03

화면을 다시 짰습니다

기능은 있어도 "열었을 때의 인상" 이 약했습니다. 피아노 관리노트를 기준선으로 놓고, 같은 제품군으로 보일 만큼 화면을 다시 세웠습니다. 색을 요란하게 쓰는 대신 종이·잉크·얇은 선으로 뼈대를 만들고, 학원마다 다른 브랜드 색은 강조에만 씁니다. 어떤 색을 골라도 화면이 무너지지 않습니다.

이전파란 띠 헤더, 이모지 아이콘, 하단에 9개 탭이 눌려 있음. 버튼은 42px 회색 상자 — 무엇을 눌러야 하는지 알기 어려움.
지금흰 헤더 + 브랜드 라인, 선 아이콘 통일, 넓은 화면은 사이드바 / 휴대폰은 5탭+더보기. 주 버튼은 브랜드 색 그라데이션으로 하나만.
바꾼 것왜
따뜻한 종이 바탕학원 사무실에서 하루 종일 켜 두는 화면입니다. 채도가 높으면 눈이 아픕니다. 글자도 완전한 검정 대신 잉크색을 씁니다.
글씨 16px부터선생님 연령대가 넓습니다. 기본을 키우고, 설정에서 보통 / 크게 / 아주 크게 3단계로 더 키울 수 있습니다.
버튼 46~56px손가락으로 눌러야 합니다. 주 동작은 한 화면에 하나만 두고 그라데이션과 그림자로 분명히 구분합니다.
이모지 → 선 아이콘이모지는 기기마다 모양이 달라 화면이 들쭉날쭉해집니다. 굵기가 같은 아이콘 세트로 통일했습니다.
하단 탭 9개 → 5개탭이 아홉 개면 아무것도 눈에 들어오지 않습니다. 매일 쓰는 다섯 개만 남기고 나머지는 "더보기" 로 옮겼습니다. PC에서는 사이드바에 전부 펼칩니다.
날짜를 읽히게브라우저 기본 날짜 칸은 08/27/2026 처럼 나옵니다. 8월 27일 목요일 로 크게 보여 주고, 누르면 달력이 열립니다.
안내 상자·번호 절차설명을 그냥 흘려 두면 읽지 않습니다. 왼쪽 굵은 선과 색으로 "읽어야 하는 것" 을 먼저 알립니다.
금액 정렬수납 표의 숫자를 오른쪽 정렬 + 고정폭으로 맞춰 자리수가 눈으로 비교됩니다.

컴퓨터가 익숙하지 않아도 되도록

  • 첫 실행 안내 3장 — "이 화면만 보시면 됩니다 / 이름을 한 번 누르면 출석 / 문자는 한 번에". 오른쪽 아래 동그란 버튼으로 언제든 다시 봅니다.
  • 화면마다 한 줄 설명 — 제목 아래에 "여기서 무엇을 하는 곳인지" 를 적었습니다.
  • 되돌리기 — "전체 출석" 을 잘못 눌러도 15초 안에 한 번에 되돌립니다.
  • 중복 발송 방지 — 일괄 안내 목록에 "오늘 보냄" 표시가 붙습니다.
  • 홈 화면에 설치 도우미 — 안드로이드·아이폰·PC 각각의 절차를 번호로 안내합니다. 설치되면 주소를 외울 필요가 없습니다.
  • 빈 화면에도 다음 할 일 — "원생이 없습니다" 로 끝내지 않고 바로 가는 버튼을 답니다.
04

원장의 반복 업무를 어디까지 줄였나

학원 현장에서 시간을 가장 많이 먹는 일은 “기록”이 아니라 확인·안내·계산·정리입니다. 기존 앱은 기록은 잘 받아 주지만 나머지를 원장에게 남겨 두고 있었습니다. 그 일곱 가지를 화면 안으로 옮겼습니다.

매일·매달 하던 일지금상태
오늘 뭘 해야 하는지 머릿속으로 점검 오늘 탭 — 출결 미체크 반, 결석 안내 대상, 미납 독촉, 방치된 후속 상담, 백업 경과를 한 화면에. 각 줄에 처리 버튼이 붙습니다. 신규
결석한 학생 학부모에게 한 명씩 문자 일괄 안내 — 대상 선택 → 이름·금액이 각자 값으로 채워진 문구 생성 → 전체 복사 / 번호만 복사 / CSV / 문자앱 열기. 누구에게 보냈는지 이력이 남습니다. 신규
미납자 뽑아 개별 독촉 수납 탭 미납자 일괄 안내. 납부 기준일이 지나야 독촉 대상이 되고, 연체 일수가 표에 표시됩니다. 신규
형제 할인·개인 할인 계산기로 두드리기 설정에 규칙을 한 번 정하면 청구 생성이 자동 계산합니다. 미리보기로 “누가 얼마”를 먼저 보고 만들고, 할인 내역이 청구서와 영수증에 그대로 남습니다. 신규
엑셀 명단을 손으로 옮겨 적기 엑셀 가져오기 — 표를 그대로 붙여넣거나 CSV 업로드. 열 이름 자동 인식, 이미 등록된 원생 표시, 없는 반 자동 생성. 신규
출석부·수납대장 손으로 정리, 영수증 손으로 쓰기 A4 인쇄(월간 출석부·수납대장)와 영수증 이미지 발행. 내보내기는 원생 명단·수납 12개월·출결 3개월 CSV. 신규
백업을 잊어버림 마지막 백업 경과일을 오늘 탭이 경고합니다. 7일이 지나면 주의, 14일이 지나면 경고 단계로 올라갑니다. 신규
출결 체크·원생 관리·수납·시간표·상담·현황 기존 기능 유지. 형제 자동 묶기는 이제 앱을 열 때 자동 재계산되어, 엑셀로 들여온 명단에도 할인이 바로 붙습니다. 개선
이전미납자 25명에게 문자 보내기 = 명단 확인 → 한 명씩 이름·금액 바꿔 쓰기 → 보낸 사람 따로 표시. 30~40분.
지금오늘 탭 → 미납 줄의 “일괄 안내” → 대상 확인 → 전체 문구 복사 → 붙여넣기. 발송 이력 자동 기록.

  • 체험판 파일 하나 — 학원관리노트-체험판.html을 더블클릭. 인증 화면에서 “14일 무료 체험 시작”을 누르면 바로 씁니다.
  • 정식 배포본 — lite.html(단일 기기) / index.html(Pro)은 웹호스팅에 올리거나 npx serve .로 확인합니다. 더블클릭으로는 열리지 않습니다(브라우저 보안 정책).
  • 인증키 발급 — tools/keygen.html. 판매자 전용이므로 고객 서버에 올리지 마세요.
  • 화면 캡처 — 인증 화면부터 각 탭·리포트·키오스크·모바일까지 화면캡처/ 폴더에 있습니다.
