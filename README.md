# 학원 관리노트

전 계열 학원·공부방(교과·어학·예체능·체육·공부방)을 위한 원생/출결/수납 관리 PWA.
피아노 전용이던 기존 제품을 **계열 무관 범용 + 대형 학원(원생 1,000명)** 규모까지 감당하도록 새로 설계했습니다.

> **함께 들어 있는 별도 앱:** [`cardscan/`](cardscan/README.md) — 명함을 찍으면 자동 인식해 휴대폰 연락처·구글 시트·HubSpot·ERP 웹훅·슬랙에 저장하는 모바일 앱(Expo) — 안드로이드 APK·아이폰 홈 화면 웹앱. 개발 인수인계(집 PC 개발 환경): [`cardscan/HANDOVER.md`](cardscan/HANDOVER.md)

| | **Lite** (`lite.html`) | **Pro** (`index.html`) |
|---|---|---|
| 저장소 | IndexedDB (Dexie) | Supabase(PostgreSQL) + 로컬 미러 |
| 동시 사용 | 1대 | 강사·데스크 여러 명 실시간 |
| 오프라인 | 완전 오프라인 | 오프라인 큐잉 후 자동 동기화 |
| 인증키(시디키) | 둘째 자리 `L` | 둘째 자리 `P` |

## 빠른 시작

```bash
npm install
npm run dev       # http://localhost:5173/lite.html (Lite) · /index.html (Pro)
npm test          # 단위·통합 테스트
npm run build     # dist/ 정적 산출물 — 웹호스팅에 그대로 업로드
npm run perf      # 원생 1,000명·출결 20만 건 실제 브라우저 성능 측정
npm run smoke     # 브라우저 시나리오 84건 (첫 화면·바로 시작 링크·체험→구매·교재 진도·백업·청구)
npm run plugin    # dist-plugin/academy-note-keys.zip — 퍼널모아(워드프레스) 자동 발급 플러그인
npm run test:plugin  # 플러그인 점검 61가지 (PHP 필요)
npm run demo      # dist-demo/학원관리노트-체험판.html — 파일 하나로 도는 체험판
```

빌드 산출물은 `dist/index.html`(Pro), `dist/lite.html`(Lite), `dist/tools/keygen.html`(판매자용 키 발급기)입니다.
`base: './'` 상대 경로 빌드라 하위 디렉터리에 올려도 동작합니다.

## 처음 온 사람이 지나가는 길

```
첫 화면  ──  "14일 무료로 써 보기"  ──▶  샘플 학원 둘러보기  ──▶  내 학원으로 시작  ──▶  시작 가이드(4단계)
   │                                         (체험 안내 띠: 남은 날 · 구매하기 · 인증키 입력)
   └──  구매  ──▶  결제 즉시 메일  ──▶  "눌러서 바로 시작하기"  ──▶  인증된 채로 앱이 열림 (입력 없음)
```

- **첫 화면** — 무엇을 해 주는 프로그램인지 세 줄 + 무료 체험 + 인증키 입력 + 구매 링크
- **샘플 학원** — 원생 24명·출결·수강료·교재 진도가 들어 있는 연습용 학원(피아노·미술·영어·수학·태권도). 다 보면 버튼 하나로 지우고 내 학원을 만듭니다
- **시작 가이드** — 빈 학원에서 "다음에 할 일"을 하나씩 짚어 줍니다 (반 만들기 → 원생 등록 → 출석 → 수강료)
- **도움말** — "하고 싶은 일"로 찾는 순서 안내가 앱 안에 있습니다
- **잠금 번호** — 혼자 쓰는 원장님에게는 묻지 않습니다. 번호를 정하거나 선생님 계정을 추가하면 그때부터 묻습니다

판매가 부진했던 원인과 바꾼 내용은 [docs/SALES.md](docs/SALES.md) 에 정리했습니다.

## 결제 → 인증키 자동 발송 (퍼널모아)

`integration/funnelmoa/academy-note-keys` 는 퍼널모아(코스모스팜 워드프레스 호스팅)에 설치하는 플러그인입니다.
결제가 끝나면 인증키를 만들어 구매자에게 메일로 보내고, 누구에게 어떤 키가 나갔는지 남깁니다.

- 우커머스 주문 · 코스모스팜 회원관리 결제 · 웹훅(그 밖의 결제 도구) 지원. 같은 주문에는 키가 한 번만 나갑니다
- 메일의 **"눌러서 바로 시작하기"** 를 누르면 키 입력 없이 인증됩니다 (`…/lite.html#key=XXXX-XXXX-XXXX`)
- 메일이 못 나가면 판매자에게 알리고, 발급 내역에서 다시 보낼 수 있습니다
- 키 규칙은 앱과 같은 것을 PHP 로 옮겼고, `npm test` 가 **PHP 로 뽑은 키를 앱 검증기에 넣어** 매번 확인합니다

설치는 [integration/funnelmoa/README.md](integration/funnelmoa/README.md) 를 따라가면 5분입니다.

## 전 계열 범용의 작동 방식

계열마다 다른 것은 **"원생에게 무엇을 기록하는가"** 뿐입니다.
설정 > 학습 항목에서 원장이 항목을 직접 정의하면 원생 카드와 학부모 리포트에 자동으로 나타납니다.

| 계열 | 예시 항목 |
|---|---|
| 교과 | 진도 교재, 진도(단원), 최근 시험 점수 |
| 어학 | 레벨, 레벨 테스트 점수, 교재 |
| 음악 | 급수·단계, 콩쿨·발표회, 연습 메모 (+ 교재·진도는 따로) |
| 예체능(미술) | 진도 곡/작품, 교재, 대회·발표회 |
| 체육 | 띠 급수, 최근 승급일, 목표 |

설정 > 고급에서 **피아노 / 미술 / 영어 / 수학 / 태권도** 샘플 학원을 바꿔 가며 확인할 수 있습니다.

교재와 진도는 따로 다룹니다. 원생 카드나 출결 화면의 "자세히"에서 교재 옆 칸에 `12번` 처럼 적으면
학부모 리포트와 레슨 안내 문자(`{진도}`)에 그대로 들어갑니다.

## 성능

기준은 원생 1,000명 · 반 80개 · 출결 20만 건에서 **모든 화면 1초 내**입니다. 이를 위해:

- 출결·수납은 절대 전체 로드하지 않고 **월/반 단위 복합 인덱스 범위 질의**만 사용
- 원생 목록은 **가상 스크롤**(보이는 행만 DOM) + 메모리 필터 검색(입력 디바운스 200ms)
- 현황 통계는 **월별 집계 캐시 테이블**(`monthlyStats`)에서 읽고 마감 시 갱신
- `npm run perf` 가 실제 Chromium + 실제 IndexedDB 로 더미를 만들고 화면별 렌더 시간을 측정해
  `perf-report.json` 을 남깁니다 (하나라도 기준 초과 시 종료 코드 1)

측정 결과(원생 1,000 · 반 80 · 출결 20만): 오늘 68ms · 출결 64ms · 원생 51ms · 수납 72ms · 시간표 57ms ·
현황 31ms(집계 캐시가 전혀 없는 최악 상태에서도 21ms) · 앱 콜드 스타트 200ms — **전 항목 1초 이내**.
(회차마다 수십 ms 씩 흔들립니다. 가장 느리게 나온 회차도 오늘 209ms · 콜드 스타트 377ms 였습니다.)
자세한 표는 [docs/PERF.md](docs/PERF.md) 참고.

## 인증키(시디키)

앱은 **인증키 없이는 열리지 않습니다.** 첫 실행에서 첫 화면이 뜨고, 키를 넣거나 14일 무료 체험을 시작해야 진입합니다.
구매 메일의 버튼으로 들어오면 키를 입력하지 않아도 인증되고, 메일을 통째로 붙여 넣어도 키만 골라냅니다.

```
A P 7 W D Z Y P 1 T Y 7      →  표기: APBC-DEFG-1234
│ │ └──────┬──────┘ └─┬─┘
│ │        │          └── 체크섬 4자 (오타·위조 검출)
│ │        └───────────── 랜덤 6자
│ └────────────────────── 플랜   L=Lite · P=Pro
└──────────────────────── 제품   A=통합(피아노+학원) · M=학원 전용 · K=피아노 전용
```

- **피아노학원 관리노트에서 발급한 키가 이 앱에서 그대로 열립니다.** 그쪽 발급 규칙(salt·문자표·해시)을
  `src/core/license-piano.js` 에 그대로 이식했기 때문에, 피아노 앱은 손대지 않아도 한 키로 두 제품을 씁니다.
  자기검증 방식 키는 그냥 입력하면 되고, 학원명 방식 키는 인증 화면에서 학원명을 함께 넣습니다.
  피아노 관리노트 발급 키는 **Pro(여러 기기·실시간 동기화)** 로 인정합니다.
- **통합키(A)** 는 학원 관리노트 방식의 공용키입니다. 이 키를 피아노 앱에서도 받으려면
  `integration/piano/` 의 패치 파일을 피아노 앱에 붙여 넣으면 됩니다(3분, 기존 키는 그대로 동작).
- 검증은 100% 오프라인(서버 왕복 없음)이며, 발급은 퍼널모아 플러그인(자동) 또는 `tools/keygen.html`(수동 · 판매자 전용)에서 합니다.
- 키 원문 대신 해시를 저장하고, **백업 파일에는 인증키가 들어가지 않습니다**(복원으로 라이선스를 복제할 수 없음).
- 기기마다 6자리 기기번호가 표시되어 재발급·문의 대응에 씁니다.
- 제품 구분이 없던 초기 발급분(첫 자리 L/P)도 계속 인정합니다.

> ⚠️ 출시 후에는 `LICENSE_SALT` 를 절대 변경하지 마세요. 이미 판매된 키가 모두 무효가 됩니다.
>
> ⚠️ **이 저장소는 비공개로 두세요.** 키를 만드는 규칙과 발급기가 들어 있어, 공개 상태면 누구나 인증키를 만들 수 있습니다.

자세한 판매·발급 운영은 [docs/LICENSE-KEYS.md](docs/LICENSE-KEYS.md) 참고.

## 원장의 반복 업무를 줄이는 기능

| 매일 하던 일 | 이 앱에서 |
|---|---|
| 오늘 뭘 해야 하는지 머릿속으로 점검 | **오늘 탭** — 미체크 반, 결석 안내 대상, 미납 독촉, 후속 상담, 백업 경과를 한 화면에 |
| 결석생 학부모에게 하나씩 문자 | **일괄 안내** — 대상 선택 → 문구 자동 생성 → 전체 복사 / 번호만 복사 / 문자앱 열기, 발송 이력 자동 기록 |
| 미납자 명단 뽑아 개별 독촉 | 수납 탭 **미납자 일괄 안내** (금액이 사람마다 자동으로 들어감) |
| 형제 할인·개인 할인 계산기 두드리기 | 설정 > 수납 정책에 규칙을 한 번 정하면 **청구 생성이 자동 계산**하고 영수증에 내역을 남김 |
| 엑셀 명단을 손으로 옮겨 적기 | 원생 탭 **엑셀 가져오기** — 붙여넣기/CSV, 중복 자동 감지, 없는 반 자동 생성 |
| 출석부·수납대장 손으로 정리 | **A4 인쇄**(월간 출석부·수납대장) + CSV 내보내기(원생·수납 12개월·출결 3개월) |
| 영수증 손으로 써 주기 | 수납 내역에서 **영수증 이미지 발행**(브랜드 로고·색상 반영) |
| 백업을 잊어버림 | 마지막 백업 경과일을 오늘 탭에서 경고 |
| "우리 아이 지금 어디 해요?" 전화 | **교재·진도** — 레슨 끝에 한 줄 적으면 리포트·레슨 안내 문자에 자동으로 들어감 |
| 결제 확인하고 인증키 만들어 메일 쓰기 (판매자) | **퍼널모아 플러그인** — 결제 즉시 자동 발급·발송 |

## Pro 설정 (Supabase)

1. Supabase 프로젝트 생성 → SQL Editor 에서 `supabase/schema.sql` 실행
2. Authentication > Providers 에서 **Anonymous sign-in** 활성화
3. 앱 설정 > Pro 동기화에 Project URL 과 anon key 입력
4. 원장 기기에서 "학원 만들기" → 표시되는 **초대 코드 6자리**를 강사 기기에서 입력해 합류
5. Lite 백업 파일(JSON)을 업로드하면 그대로 Pro 로 마이그레이션됩니다

RLS 정책상 `academy_id` 가 내 소속 학원인 행만 읽고 쓸 수 있어, 다른 학원 데이터는 조회 자체가 되지 않습니다.

## CI

- `.github/workflows/ci.yml` — push·PR 마다 테스트(218건) + 프로덕션 빌드 + 산출물 3종(Pro·Lite·키 발급기)과 플러그인 zip 확인.
  빌드 결과는 `dist` 아티팩트로 7일간 보관됩니다.
- `.github/workflows/verify.yml` — 브라우저가 필요한 검증(스모크 + 성능)은 시간이 걸려
  Actions 탭에서 **수동 실행**합니다. 원생 수·출결 건수를 입력으로 조절할 수 있고,
  `perf-report.json` 을 아티팩트로 남깁니다. 릴리스 전 점검용입니다.
