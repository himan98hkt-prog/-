# 피아노학원 관리노트 앱에 붙이는 패치

학원 관리노트에서 발급한 인증키를 **피아노 앱에서도 열리게** 하는 패치입니다.
(반대 방향 — 피아노 키를 학원 관리노트에서 여는 것 — 은 이미 되어 있어 아무 작업도 필요 없습니다)

## 지금 상태

| 키 | 학원 관리노트 | 피아노 관리노트 |
|---|---|---|
| 피아노 자기검증 키 (미리 만들어 둔 키) | ✅ Pro 로 열림 | ✅ 원래 열림 |
| 피아노 학원명 키 | ✅ 학원명 함께 입력하면 Pro 로 열림 | ✅ 원래 열림 |
| 학원 관리노트 통합키 `A…` | ✅ 열림 | **이 패치를 붙이면 열림** |
| 피아노 전용 키 `K…` | ❌ (의도됨) | **이 패치를 붙이면 열림** |
| 학원 전용 키 `M…` | ✅ 열림 | ❌ (의도됨 — 학원용으로 판 키) |

## 붙이는 법 (3분)

1. 피아노 관리노트 앱 HTML 을 엽니다.
2. `licSelfValid` / `licKey` 가 들어 있는 `<script>` **바로 아래**에
   `학원관리노트-키-인정-패치.js` 내용을 그대로 붙여 넣습니다.
   (파일로 두고 `<script src="...">` 로 불러도 됩니다. 기존 스크립트보다 뒤에만 오면 됩니다)
3. 키를 확인하는 자리에서 함수 이름만 바꿉니다.

```diff
- if (licSelfValid(key)) { ...통과... }
+ if (licAnyValid(key, 학원명)) { ...통과... }
```

`학원명` 인자는 **학원명 방식 키를 쓰던 화면에서만** 필요합니다. 없으면 생략해도 됩니다.
어떤 키인지 화면에 표시하고 싶으면 `licDescribe(key, 학원명)` 이 `{ok, source, plan}` 을 돌려줍니다.

## 안전장치

- 기존 함수(`licSelfValid`, `licKey`)를 **덮어쓰지 않습니다.** 먼저 기존 규칙으로 판정하고,
  거기서 통과하지 못한 키만 학원 관리노트 규칙으로 한 번 더 봅니다.
- 기존 라이선스 코드가 없는 페이지에 붙여도 오류 없이 동작합니다(학원 관리노트 키만 판정).
- `AN_SALT`, `AN_CHARS` 는 학원 관리노트가 쓰는 값입니다. **한 글자도 바꾸지 마세요.**

## 검증

`tests/piano-app-patch.test.js` 가 이 패치 파일을 그대로 실행해 10가지를 확인합니다
(통합키 Lite/Pro, 피아노 전용키, 학원 전용키 거부, 초기 발급분, 기존 피아노 키 유지,
오타 거부, 표기 관대함, 위 확인용 키 4개, 기존 코드가 없을 때).

> 다만 **피아노 앱 실물에 적용해 본 것은 아닙니다.** 앱 소스를 주시면 정확한 위치에 넣고
> 브라우저에서 실제로 열리는 것까지 확인해 드리겠습니다. 지금 검증은 발급기에서 확인한
> 피아노 규칙(`src/core/license-piano.js`)을 기준으로 한 것입니다.
