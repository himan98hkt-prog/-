# 피아노학원 관리노트 앱에 붙이는 패치

학원 관리노트에서 발급한 인증키를 **피아노 앱에서도 열리게** 하는 패치입니다.
(반대 방향 — 피아노 키를 학원 관리노트에서 여는 것 — 은 이미 되어 있어 아무 작업도 필요 없습니다)

## 지금 상태

| 키 | 학원 관리노트 | 피아노 관리노트 |
|---|---|---|
| 피아노 자기검증 키 (미리 만들어 둔 키) | ✅ Pro 로 열림 | ✅ 원래 열림 |
| 피아노 학원명 키 | ✅ 학원명 함께 입력하면 Pro 로 열림 | ✅ 원래 열림 |
| 학원 관리노트 통합키 `A…` | ✅ 열림 | **이 패치를 붙이면 열림** |
| 피아노 전용 키 `K…` | ❌ (의도됨) | **이 패치를 붙이면 열림** |
| 학원 전용 키 `M…` | ✅ 열림 | ❌ (의도됨 — 학원용으로 판 키) |

## 붙이는 법 (1분) — 기존 코드는 한 글자도 고치지 않습니다

`index.html` 의 `</body>` **바로 위**에 이 패치를 넣기만 하면 됩니다.

```html
  <script>
  … 학원관리노트-키-인정-패치.js 내용 …
  </script>
</body>
```

패치는 앱의 `licSelfValid` 를 감싸서 "원래 규칙으로 먼저 보고, 아니면 학원 관리노트 규칙으로 한 번 더" 보게 만듭니다.
앱이 쓰는 `licValid(학원명, 키)` 가 내부에서 `licSelfValid` 를 부르기 때문에, **인증 화면과 실행 중 재검증 양쪽에 한 번에 적용**됩니다.

> 인라인으로 붙일 때는 주석 안의 `</script>` 표기 때문에 HTML 파싱이 끊기지 않도록
> 아래 자동화 스크립트를 쓰는 편이 안전합니다.

### 자동으로 붙이고 검증까지

```bash
node scripts/verify-piano-patch.mjs <피아노앱 index.html> [출력 경로]
```

패치본을 만들고 실제 브라우저로 8가지를 확인합니다 — 원본 거부 → 패치 후 통과, 전용키 구분,
기존 피아노 키 유지, 학원명 방식 키 계산 불변, **인증 화면에서 실제로 잠금이 풀리는지**까지.

`licAnyValid(key, 학원명)` / `licDescribe(key, 학원명)` 도 전역에 함께 올라가므로,
직접 판정하거나 "어떤 키인지" 를 화면에 표시하고 싶을 때 쓸 수 있습니다.

|---|---|

| `AP9R-3TQX-71C3` | 열림 (통합 Pro) |
| `KL5M-8VNC-41GX` | 열림 (피아노 전용) |
| `ML6Q-2WJD-7PG7` | **거부** (학원 전용 키) |
| 기존에 판 피아노 키 | 이전과 똑같이 열림 |

## 안전장치

- 기존 함수(`licSelfValid`, `licKey`)를 **덮어쓰지 않습니다.** 먼저 기존 규칙으로 판정하고,
  거기서 통과하지 못한 키만 학원 관리노트 규칙으로 한 번 더 봅니다.
- 기존 라이선스 코드가 없는 페이지에 붙여도 오류 없이 동작합니다(학원 관리노트 키만 판정).
- `AN_SALT`, `AN_CHARS` 는 학원 관리노트가 쓰는 값입니다. **한 글자도 바꾸지 마세요.**

## 검증

`tests/piano-app-patch.test.js` 가 이 패치 파일을 그대로 실행해 10가지를 확인합니다
(통합키 Lite/Pro, 피아노 전용키, 학원 전용키 거부, 초기 발급분, 기존 피아노 키 유지,
오타 거부, 표기 관대함, 위 확인용 키 4개, 기존 코드가 없을 때).
