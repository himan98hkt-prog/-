# 퍼널모아 자동 발급 — 결제되면 인증키가 메일로 바로 나갑니다

`academy-note-keys` 는 퍼널모아(코스모스팜 워드프레스 호스팅)에 설치하는 워드프레스 플러그인입니다.
발급기를 열어 키를 만들고 메일을 쓰는 일을 대신합니다.

```
고객이 결제  →  플러그인이 인증키 생성  →  고객 메일로 발송  →  고객이 메일의 버튼을 누르면 앱이 인증된 채로 열림
```

| 지금까지 | 이제 |
|---|---|
| 결제 알림 확인 → 발급기 열기 → 키 복사 → 메일 작성 → 발송 | 아무것도 하지 않음 (자동) |
| 고객은 판매자가 볼 때까지 기다림 | 결제 직후 메일 도착 |
| 고객이 12자리 키를 직접 입력 | 메일의 **눌러서 바로 시작하기** 버튼 한 번 |
| 누구에게 어떤 키를 줬는지 엑셀로 따로 정리 | 발급 내역에 자동 기록 · 다시 보내기 · 엑셀 내려받기 |

## 설치 (5분)

1. `npm run plugin` 으로 `dist-plugin/academy-note-keys.zip` 을 만듭니다. (이미 받은 zip 이 있으면 그걸 씁니다)
2. 워드프레스 관리자 → **플러그인 → 새로 추가 → 플러그인 업로드** → zip 선택 → **지금 설치** → **활성화**
3. 왼쪽 메뉴에 생긴 **관리노트 인증키 → 설정** 에서 두 가지만 정합니다.
   - **① 어떤 상품을 팔 때 키를 보낼까요** — 왼쪽 칸에 `관리노트` 라고 적으면, 이름에 "관리노트"가 들어간 상품이 결제될 때마다 키가 나갑니다. (상품 번호를 적어도 됩니다)
   - **② 앱 주소** — 학원 관리노트를 올려 둔 주소 (예: `https://내사이트.com/note/lite.html`). 넣어야 메일에 시작 버튼이 생깁니다.
4. **직접 보내기 → 내 메일로 시험 발송** 을 눌러 메일이 오는지, 버튼이 열리는지 확인합니다.
5. 실제로 상품을 한 번 결제해 보고 **발급 내역** 과 **연결 상태 → 최근 기록** 에 한 줄이 생기는지 봅니다.

> 퍼널모아 요금제에 따라 플러그인 업로드가 막혀 있을 수 있습니다. 메뉴가 보이지 않으면 퍼널모아 고객센터에
> "직접 만든 플러그인 zip 을 설치하고 싶다" 고 문의해 주세요.

## 어떤 키를 보내나요

| 설정의 "보낼 키" | 열리는 앱 | 플랜 |
|---|---|---|
| **공용키** (기본값 · 권장) | 피아노 관리노트 + 학원 관리노트 **둘 다** | Pro |
| 학원 관리노트 통합키 Pro / Lite | 학원 관리노트 (+ 패치한 피아노 앱) | Pro / Lite |
| 학원 관리노트 전용 Pro / Lite | 학원 관리노트만 | Pro / Lite |
| 피아노 관리노트 전용 Pro / Lite | 패치한 피아노 앱만 | Pro / Lite |

상품마다 다른 키를 줄 수 있습니다. 예) `Lite` 가 이름에 들어간 상품 → 전용 Lite, 그 밖의 `관리노트` → 공용키.
위에서부터 먼저 맞는 줄을 쓰므로 **더 구체적인 줄을 위에** 적습니다.

기존 발급기(`pambookkey.html`, `tools/keygen.html`)와 **같은 규칙**으로 만듭니다. 그래서 플러그인이 보낸 키와
발급기로 만든 키가 섞여도 문제없고, 앱은 고칠 필요가 없습니다.

## 결제가 연결되는 길

| 결제 방식 | 연결 | 확인 상태 |
|---|---|---|
| 우커머스 주문 | 주문이 "완료됨" / "처리 중" 이 될 때 | 흐름 전체를 점검 스크립트로 확인 |
| 코스모스팜 회원관리의 결제 상품 | 첫 결제가 성공한 뒤 (`cosmosfarm_members_subscription_request_pay`) | 훅 이름과 인자는 코스모스팜 공개 문서·포럼 기준. **실제 사이트에서 결제 1건으로 확인 필요** |
| 그 밖의 결제 도구 | 연결 상태 탭의 **웹훅 주소**를 부르게 함 | 점검 스크립트로 확인 |

코스모스팜 쪽은 플러그인 버전마다 주문·상품 객체의 모양이 조금 다를 수 있어, 메서드·속성·글 메타를 차례로 읽도록
만들었고 **무엇을 읽었는지 "최근 기록"에 남깁니다.** 첫 결제 때 그 줄에 메일과 상품명이 제대로 찍혔는지만 보면 됩니다.
`(없음)` 으로 찍힌다면 그 화면을 캡처해 알려 주세요 — 한 줄 고치면 됩니다.

## 걱정될 만한 것들

- **같은 주문에 키가 두 번 나가지 않나요?** 주문 번호에 유일 제약을 걸어 한 번만 발급합니다. PG 가 알림을 여러 번 보내도 같습니다.
- **메일이 안 가면요?** 키는 발급 내역에 남고, 판매자에게 "보내지 못했다"는 메일(키 포함)이 갑니다. 발급 내역에서 주소를 고쳐 **다시 보내기** 를 누르면 됩니다. 다음 결제 신호 때도 자동으로 다시 시도합니다.
- **고객이 메일을 지웠어요.** 발급 내역에서 메일·이름·키로 찾아 다시 보냅니다. 페이지에 `[academy_note_keys]` 를 넣어 두면 회원이 마이페이지에서 직접 볼 수도 있습니다.
- **스팸함으로 가요.** 워드프레스 기본 메일은 스팸으로 잘 분류됩니다. `WP Mail SMTP` 같은 플러그인으로 네이버·구글 SMTP 를 연결하면 해결됩니다.
- **계좌이체로 받은 건?** 직접 보내기 탭에서 메일 주소만 넣으면 됩니다.
- **플러그인을 지우면 기록도 사라지나요?** 아니요. 발급 내역은 판매 기록이라 남겨 둡니다.

## 점검

```bash
npm run test:plugin     # 결제 신호 → 발급 → 메일 → 관리 화면 61가지
npm test                # 그중 "플러그인이 만든 키가 앱에서 열리는지" 교차 검증 포함
php integration/funnelmoa/tests/run.php --mail 미리보기.html   # 실제로 나가는 메일을 파일로 저장
```

워드프레스 없이 도는 점검입니다(워드프레스 함수는 흉내, DB 는 SQLite 로 실제 SQL 실행).
**진짜 퍼널모아 사이트에서의 결제 1건 확인은 설치 후 직접 해 주셔야 합니다.**

## 꼭 지킬 것

- `includes/class-ank-keys.php` 의 `SALT` · `PIANO_SALT` · 문자표는 **이미 팔린 키를 여는 열쇠**입니다. 한 글자도 바꾸지 마세요.
- 이 플러그인은 키를 찍어 낼 수 있습니다. zip 파일과 웹훅 비밀값을 고객이나 외부에 주지 마세요.
