=== 관리노트 인증키 자동 발급 ===
Requires at least: 5.8
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.0.0

학원 관리노트 · 피아노학원 관리노트가 결제되면 인증키를 만들어 구매자에게 메일로 바로 보냅니다.

== 하는 일 ==

1. 결제가 끝나면(코스모스팜 회원관리 / 우커머스 / 웹훅) 인증키를 새로 만듭니다.
2. 구매자 메일로 인증키와 "눌러서 바로 시작하기" 버튼을 보냅니다.
3. 누구에게 어떤 키가 나갔는지 발급 내역에 남깁니다. 다시 보내기, 엑셀 내려받기가 됩니다.

같은 주문에는 키가 한 번만 나갑니다.

== 설치 ==

1. 워드프레스 관리자 > 플러그인 > 새로 추가 > 플러그인 업로드 에서 zip 파일을 올리고 활성화합니다.
2. 관리자 메뉴의 "관리노트 인증키" > 설정 에서 상품과 앱 주소를 정합니다.
3. "직접 보내기" 탭의 "내 메일로 시험 발송" 으로 메일이 오는지 확인합니다.

== 마이페이지에 내 인증키 보여 주기 ==

페이지에 [academy_note_keys] 를 넣으면 로그인한 회원이 자기가 받은 인증키를 다시 볼 수 있습니다.
