# 비공개 테스트 (12명 × 14일) 준비물

## 1. 테스터 모집 문구 (카카오톡·문자에 그대로 복사)

```
[부탁] 제가 만든 명함 앱 테스트를 2주만 도와주세요 🙏

명함을 찍으면 자동으로 읽어서 휴대폰 연락처에 저장해 주는 앱(명함스캔)입니다.
구글 플레이에 정식 출시하려면 테스터 12명이 14일 동안 설치해 두어야 해요.

✔ 안드로이드폰만 가능 (아이폰 X)
✔ 구글 계정(Gmail) 주소만 알려 주시면 됩니다
✔ 설치 후 명함 한두 장 찍어 보고, 14일 동안 앱만 지우지 않고 두시면 끝!
✔ 비용·회원가입 없음, 명함 정보는 본인 폰에만 저장됩니다

참여 가능하시면 Gmail 주소를 답장으로 보내 주세요. 감사합니다!
```

## 2. 참여 링크 보낼 때 안내문

(콘솔 → 비공개 테스트 → 테스터 탭의 "웹에서 참여" 링크를 아래 [링크] 자리에 붙여 넣기)

```
명함스캔 테스트 참여 방법 (3분)

1) 휴대폰에서 이 링크를 엽니다 (알려 주신 Gmail 계정으로 로그인된 상태)
   [링크]
2) "테스터 되기" 버튼을 누릅니다
3) 아래 "Google Play에서 다운로드" 를 눌러 설치합니다
4) 앱을 열고 명함 1~2장을 찍어 봐 주세요
5) ⭐ 14일 동안 앱을 지우지 말고 그대로 두세요 (가끔 열어 보면 더 좋아요)

불편한 점이나 잘못 읽힌 부분이 있으면 편하게 알려 주세요. 출시에 큰 도움이 됩니다!
```

## 3. 테스터에게 받을 의견 (7단계 설문에 씀)

카톡으로 아래 질문을 보내 답을 모아 두세요.

```
1. 명함 인식이 정확했나요? 틀린 칸이 있었다면 어떤 칸이었나요?
2. 연락처에 잘 저장됐나요?
3. 쓰기 어렵거나 헷갈린 화면이 있었나요?
4. 있었으면 하는 기능이 있나요?
5. 돈을 낸다면 얼마까지 낼 의향이 있나요? (선택)
```

## 4. 테스트 기간 체크리스트

- [ ] 테스터 15~20명 확보 (12명 + 여유)
- [ ] 콘솔 대시보드에서 참여 인원 12명 이상 확인
- [ ] 1주차: 받은 의견 반영해 업데이트 1회 (새 AAB → 비공개 테스트 트랙에 새 버전)
- [ ] 2주차: 업데이트 1회 더 (작은 수정도 OK)
- [ ] 14일 동안 탈퇴자 없도록 중간에 한 번 안내 메시지
- [ ] 받은 의견·고친 내용 메모 (아래 설문에 사용)

## 5. 프로덕션 액세스 신청 설문 — 답변 예시

질문 문구는 콘솔에서 조금씩 바뀔 수 있습니다. 아래를 **실제 테스트 내용에 맞게 숫자·사례만 바꿔서** 쓰세요. 구체적일수록 잘 통과합니다.

**테스터를 어떻게 모집했나요?**
```
지인과 업무상 명함을 자주 주고받는 영업·구매 담당자 위주로 15명을 직접 모집했습니다. 실제로 매주 명함을 받는 사람들이라 실사용 환경에서 테스트할 수 있었습니다.
```

**테스터들이 앱을 어떻게 사용했나요? / 테스트 중 사용 경험은?**
```
테스터들은 업무 중 받은 실제 명함을 촬영해 연락처 저장, 앞·뒷면 촬영, 여러 장 한 번에 등록, 팔로업 알림, 내 명함 QR 기능을 사용했습니다. 삼성·LG·픽셀 등 여러 기기와 안드로이드 12~16 버전에서 사용했습니다.
```

**어떤 피드백을 받았고, 어떻게 반영했나요?**
```
1) 하단 메뉴가 일부 삼성폰의 3버튼 내비게이션 바와 겹친다는 의견 → 기기별 하단 여백을 자동으로 맞추도록 수정했습니다.
2) "+82 10-" 형식과 아이콘만 있는 전화번호가 잘못 분류된다는 의견 → 국가번호·아이콘 처리 규칙을 개선했습니다.
3) (테스트 중 받은 다른 의견과 수정 내용을 적으세요)
```

**앱의 대상 사용자는 누구인가요?**
```
명함을 자주 주고받는 영업·구매·마케팅 담당자, 자영업자, 프리랜서 등 직장인입니다. 받은 명함을 빠르게 연락처와 업무 시스템(구글 시트·CRM)에 정리하려는 사람을 위한 앱입니다.
```

**앱이 사용자에게 주는 가치는 무엇인가요?**
```
명함을 찍기만 하면 휴대폰 안에서 글자를 읽어 연락처와 구글 시트·HubSpot 등에 자동으로 입력해 주어, 손으로 옮겨 적는 시간을 없애고 고객 정보를 놓치지 않게 합니다. 사진이 외부 서버로 나가지 않아 고객 정보를 안전하게 다룰 수 있습니다.
```

**출시 준비가 되었다고 판단한 근거는?**
```
14일 이상 테스트하며 받은 의견을 반영해 2회 업데이트했고, 마지막 버전에서는 인식·저장 관련 오류 보고가 없었습니다. 플레이 콘솔 사전 출시 보고서에서도 비정상 종료가 확인되지 않았습니다.
```
