# 명함스캔 경쟁력·판매 전략 (1만 다운로드 목표)

## 솔직한 평가: "유료로 하면 살까?"

**처음부터 돈을 내야 받을 수 있는 유료 앱(예: 3,900원 선결제)이라면 1만 다운로드는 어렵습니다.**
- 이 분야에는 이미 무료로 쓰는 대형 앱이 있고, 이용자는 써 보지 않은 명함 앱에 먼저 돈을 내지 않습니다.
- 플레이스토어 검색 상위에 오르려면 설치 수·리뷰·평점이 쌓여야 하는데, 선결제 앱은 이 속도가 매우 느립니다.

**그래서 권장 구조: 무료 다운로드 → 써 보고 → 저렴한 Pro(평생 이용권)로 업그레이드.**
- 무료 사용자가 늘어야 검색 순위와 리뷰가 올라가고, 그중 업무에 본격적으로 쓰는 일부가 결제합니다.
- 일반적으로 무료 이용자 중 결제하는 비율은 몇 % 수준입니다. 1만 다운로드에 2~5% 가 3,900원 Pro 를 사면 약 80만~200만 원(수수료 15% 제외 전) 규모입니다. 판매 수익을 키우려면 다운로드 수가 가장 중요합니다.

## 우리 앱만의 확실한 경쟁력 (소구 포인트)

| 소구점 | 왜 먹히나 | 앱에 있는 기능 |
|---|---|---|
| **① 명함 사진이 밖으로 나가지 않는다** | 사람이 대신 입력해 주는 방식의 앱은 정확하지만 명함 사진이 회사 서버로 갑니다. 고객 정보를 다루는 영업·금융·보험·B2B 담당자, 보안 규정이 있는 회사에는 큰 장점 | 폰 안에서 오프라인 인식, 회원가입 없음, 서버 없음 |
| **② 내가 쓰는 업무 도구로 바로 들어간다** | 대부분의 명함 앱은 자기 앱 안에 가둬 둡니다. 소상공인·스타트업은 구글 시트·CRM 에 다시 옮겨 적는 게 일 | 구글 시트, HubSpot, 웹훅(ERP·Zapier·n8n), 슬랙, 고객/거래처별 전송 |
| **③ 전시회·세미나에 최적** | 행사에서 받은 명함 수십 장 정리가 가장 큰 고통 | 행사 태그 자동, 연속 촬영, 앨범 50장 일괄 등록, '확인필요' 모아 보기 |
| **④ 전화 올 때 누군지 안다** | 기본 전화 앱에 "홍길동 (한빛상사 팀장)" 으로 표시 | 연락처 이름 형식 선택 |
| **⑤ 다시 연락할 날을 챙겨 준다** | 명함을 받고 끝나는 게 아니라 영업으로 이어지게 | 팔로업 알림, 메모 타임라인, 경력 이력 |
| **⑥ 받은 명함 그대로** | 명함 디자인이 곧 회사의 얼굴 — 원본이 가장 빨리 알아보는 방법 | 원본 앞·뒷면 보관, 목록에 실제 명함, 원본 보며 수정, 사진 그대로 공유 |
| **⑦ 구독 아닌 1회 결제** | 월 구독에 지친 사용자에게 "커피 한 잔 값으로 평생" | (Pro 결제 추가 예정) |

**한 문장 포지셔닝**: *"명함 사진이 서버로 가지 않는, 업무용 명함 앱 — 찍으면 연락처와 구글 시트·CRM 까지."*

## 약점과 보완 계획 (우선순위)

| 약점 | 영향 | 보완 |
|---|---|---|
| 자동 인식은 사람 입력보다 덜 정확함 | 리뷰 평점 | 원본 고정 수정 화면(완료), '확인필요' 모아 보기(완료), 선택형 고정밀 인식(Claude, 완료). 테스트 기간에 틀리는 명함 유형을 모아 규칙 개선 |
| 휴대폰 바꾸면 데이터 이동이 번거로움 | 이탈 | 백업 파일(완료) → **구글 드라이브 자동 백업** 추가 권장 |
| 팀 공유 없음 | 법인 판매 | 구글 시트·HubSpot 연동으로 우회(완료). 수요 확인 후 팀 기능 |
| 결제 기능 없음 | 수익 | **Pro 평생 이용권 (Google Play 결제)** — 다음 작업 |

## 무료 / Pro 구성 제안

| 무료 | Pro 평생 이용권 (예: 3,900원) |
|---|---|
| 명함 촬영·인식, 연락처 저장 | 명함 **무제한** (무료는 50장) |
| 검색·그룹·메모·팔로업 | 구글 시트·HubSpot·웹훅·슬랙 연동 |
| 내 명함 QR | 엑셀 내보내기·백업, 앨범 일괄 등록, 연속 촬영 |

무료로도 "찍으면 연락처" 핵심 가치는 충분히 경험하게 하고, 업무용으로 많이 쓰는 사람이 결제하게 만드는 구조입니다.

## 1만 다운로드를 위한 출시 계획

1. **비공개 테스트(2주) 동안 리뷰 씨앗 만들기**: 테스터 15~20명에게 실제 명함으로 쓰게 하고, 출시 직후 솔직한 리뷰를 부탁 (리뷰 대가 지급·조작은 정책 위반이니 금지)
2. **스토어 검색 최적화 (ASO)**
   - 제목에 핵심어: "명함", "명함 인식", "연락처 자동 저장" (이미 반영)
   - 설명 앞부분에 자주 찾는 말: 명함 스캔, 명함 관리, 명함첩, 명함 저장, 명함 인식 앱, 전시회 명함, 구글 시트, CRM
   - 스크린샷 첫 3장에 핵심 메시지(연락처 자동 저장 → 전시회 모드 → 원본 그대로) — 반영 완료
3. **타깃을 좁혀서 시작**: 전시회 참가 기업(박람회 시즌 전), 보험·부동산·금융 영업, B2B 스타트업, 협회·상공회의소 모임
   - 박람회 직전 "전시회 명함 30장, 5분 만에 엑셀로" 같은 짧은 영상(쇼츠·릴스)
   - 영업인 커뮤니티·네이버 카페·링크드인에 사용 후기형 글
4. **입소문 장치**: 내 명함 QR 화면에 앱 이름이 보이게(완료) — 상대가 "이거 무슨 앱이에요?" 하게
5. **평점 관리**: 출시 초기 1~2주는 리뷰에 모두 답글, 인식 오류 제보는 다음 업데이트에 반영하고 출시 노트에 명시
6. **업데이트 주기**: 2주에 한 번 작은 개선이라도 꾸준히 — 플레이 알고리즘과 이용자 신뢰 모두에 좋음

> 다운로드 수는 시장 상황·마케팅에 크게 좌우되므로 1만 회를 보장할 수는 없습니다. 위 계획은 가능성을 높이는 방법입니다.
