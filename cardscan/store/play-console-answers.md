## 6. 데이터 보안 (Data safety) — 가장 중요
구글 기준: **휴대폰 밖으로 전송되는 데이터만 "수집"** 입니다. 휴대폰 안에만 저장되는 명함·사진·연락처는 수집이 아닙니다.
이용자가 직접 켠 곳으로 보내는 것은 "공유"가 아니라 "수집(이용자 요청에 따른 전송)"으로 봅니다.

### 6-1. 개요 질문
| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** (선택 연동 + Google ML Kit 진단) |
| 전송 중 데이터가 암호화되나요? | **예** (모든 전송 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** — 앱에서 명함 삭제 / 앱 삭제 시 전체 삭제 (서버 보관 없음) |
| 계정 생성 | 앱에 계정이 없음 |

### 6-2. 데이터 유형별 답변
체크할 항목과 각 항목의 세부 답변입니다. **표에 없는 항목은 체크하지 않습니다.**

| 데이터 유형 | 수집 | 공유 | 처리 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 개인 정보 → **이름** | 예 | 아니요 | 일시적 아님 | **선택** | 앱 기능 |
| 개인 정보 → **이메일 주소** | 예 | 아니요 | 일시적 아님 | **선택** | 앱 기능 |
| 개인 정보 → **전화번호** | 예 | 아니요 | 일시적 아님 | **선택** | 앱 기능 |
| 개인 정보 → **주소** | 예 | 아니요 | 일시적 아님 | **선택** | 앱 기능 |
| 개인 정보 → **기타 정보** (회사·직책) | 예 | 아니요 | 일시적 아님 | **선택** | 앱 기능 |

근거
- 이름·이메일·전화·주소·회사/직책: 이용자가 켠 **구글 시트·HubSpot·웹훅·슬랙**으로 전송될 때만 → "선택"
- 사진: 기본 꺼짐인 **Claude 인식**(이용자 본인 API 키)을 켤 때만 Anthropic 으로 전송 → "선택"
- 비정상 종료 로그·진단: 앱에 포함된 **Google ML Kit / 문서 스캐너**가 기기·앱 정보와 성능·오류 지표를 Google 로 보냄 (명함 내용은 아님) → 참고: https://developers.google.com/ml-kit/android-data-disclosure
- 연락처(주소록): 휴대폰 안에서만 읽고 쓰며 전송하지 않음 → **체크하지 않음**
- 위치, 금융, 건강, 메시지, 웹 기록, 앱 활동, 기기 ID, 광고 ID: **해당 없음**

## 12. 권한 관련 선언
현재 앱은 **특별 선언이 필요한 권한(SMS·통화기록·위치·사진첩 전체 접근·정확한 알람·접근성·전체 파일 접근 등)이 없습니다.**

최종 권한: 카메라, 연락처 읽기·쓰기, 알림, 인터넷, 진동, 부팅 후 알림 복원 등 일반 권한.
