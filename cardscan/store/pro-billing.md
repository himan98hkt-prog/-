# Pro 평생 이용권 (인앱 결제) 등록·운영

앱에는 이미 구글 플레이 결제가 들어 있습니다. **콘솔에 상품 하나만 만들면** 바로 동작합니다.

| 항목 | 값 |
|---|---|
| 상품 종류 | **일회성 상품** (One-time product) — 구독 아님 |
| 상품 ID | **`pro_lifetime`** ← 정확히 이대로 (앱 코드와 같아야 함, 나중에 못 바꿈) |
| 이름 | `Pro 평생 이용권` |
| 설명 | `명함 무제한, 구글 시트·HubSpot·웹훅·슬랙 자동 입력, 엑셀 내보내기, 여러 장 한 번에·연속 촬영. 한 번 결제로 평생 이용.` |
| 무료 한도 | 명함 50장 (코드: `src/core/pro.ts` 의 `FREE_CARD_LIMIT`) |
| 정가 | 3,900원 |
| 출시 기념가 | 1,900원 (출시 후 약 한 달) |

## 1. 결제 프로필 만들기 (처음 한 번)
플레이 콘솔 → **설정 → 결제 프로필** → 판매자 정보·은행 계좌·세금 정보 입력. 이게 없으면 상품을 만들 수 없습니다.

## 2. 상품 만들기
> 콘솔은 결제 기능(BILLING)이 들어간 AAB 를 한 번 올린 뒤에야 상품 화면을 열어 줍니다. 비공개 테스트에 AAB 를 먼저 올리세요.

1. 콘솔 → 앱 선택 → **수익 창출 → 제품 → 일회성 상품** → **상품 만들기**
2. 상품 ID `pro_lifetime`, 이름·설명 위 표대로
3. **구매 옵션**: "구입"(Buy) 옵션 하나 → 가격 **1,900원** (출시 기념가로 시작) → 다른 나라 가격은 자동 환산 그대로
4. **활성화**(Activate)

앱은 스토어 가격을 그대로 보여 주고, 가격이 정가(3,900원)보다 낮으면 결제 화면에 **"출시 기념가 · 정가 3,900원"** 을 자동으로 표시합니다.

## 3. 출시 기념가 → 정가 바꾸기 (출시 약 한 달 뒤)
콘솔 → 같은 상품 → 구매 옵션 가격을 **3,900원**으로 변경 → 저장. 앱 업데이트는 필요 없습니다 (앱이 "출시 기념가" 문구를 알아서 뺍니다).

## 4. 결제 테스트 (돈 안 나가게)
1. 콘솔 **설정(앱 목록 화면 왼쪽) → 라이선스 테스트** → 본인·테스터 Gmail 추가 → 저장
2. 그 계정으로 **비공개 테스트 트랙에서 설치한 앱**에서 Pro 구매 → 결제 창에 "테스트 카드, 항상 승인" 이 보이면 정상 (실제 청구 없음)
3. 확인할 것
   - 구매 후 "평생 이용권이 적용되었습니다" → 설정 맨 위가 "Pro 평생 이용권 사용 중"
   - 앱을 지웠다 다시 설치 → 설정 → **구매 복원** → Pro 로 돌아오는지
   - 무료 계정으로 명함 50장 → 51장째에 Pro 안내가 뜨고, 읽은 내용이 확인 화면에 남아 있는지
4. 테스트 구매는 콘솔 **주문 관리**에서 환불해 다시 시험할 수 있습니다
